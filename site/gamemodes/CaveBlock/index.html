    CaveBlock#

    空はない。地表もない。どの方向も石ばかり、手にはツルハシ。

    CaveBlockはアイランドゲームを逆転させます：開かれた空へ向かって建てるのではなく、プレイヤーは堅い地中から自分の世界を掘り出します。鉱石を採掘し、家を掘り抜き、暗闇を通じて拡大します。同じ満足度の高いアイランド進行 — チャレンジ、レベル、チームメイト — しかし全てが地下で展開します。~ドワーフ~プレイヤーはみんな大好きです。

    作成・メンテナンス: BONNe

    • GitHub repository (Releases)

    インストール#

    1. BentoBoxをインストールし、データフォルダを生成するためサーバーを少なくとも1回起動します。
    2. このjarファイルをBentoBoxプラグインのaddonsフォルダに配置します。
    3. サーバーを再起動します。
    4. アドオンがワールドとデータフォルダを作成し、フォルダ内にconfig.ymlが生成されます。
    5. サーバーを停止します。
    6. config.ymlを希望通りに編集します。
    7. ワールドの生成に関わる設定を変更した場合は、初回起動で作成されたワールドフォルダを削除します。
    8. サーバーを再起動します。

    設定#

    メインのconfig.ymlファイルには、ゲームモードアドオンのセットアップに関する基本情報が含まれています。

    アドオンが正常にインストールされると、config.ymlファイルが作成されます。このファイルのすべての設定にはコメントが付いています。詳細はファイルをご確認ください。

    ワールド生成が1.21.0で再設計されました

    1.21.0以降、オーバーワールドはMinecraftの独自のバニラ1.18+ノイズジェネレーターで彫刻され、島は本物のチーズ、スパゲッティ、ラッシュ、鐘乳石、深暗洞窟 — バニラの鉱石、装飾、構造、地下バイオーム全てを備えています。各列の上にはワールドが堅い岩のままで空が開かないようにキャップされています。サーバーはいま彫刻、鉱石、バイオームを処理するため、古いブロック置換生成オプション（generation-tries、use-new-material-generator、次元別のblocksリスト、およびnatural-*トグル）は削除されました。ネザーとエンドは新しい鉱石脈ポピュレーターで充填・装飾アプローチを保持します。アップグレード前に、このページの下部の変更履歴を参照してください。

    説明

    ワールドの深さは、ワールドでブロックが生成される高さを示します。-64に設定すると、基本的な虚空ワールドが作成されます。

    洞窟の上に新鮮な空気を作ることができます。

    説明

    1.23.0で追加されました。 オーバーワールド洞窟ワールドで生成される可能性のあるバニラ構造のマップです。構造をfalseに設定して生成を停止します；ここにリストされていない構造は通常通り生成されます。バニラ構造キーを使用します。例えばancient_city、trial_chambers、mineshaft、mineshaft_mesa、stronghold、mansion、monument、pillager_outpost、ruined_portal、trail_ruins、village_plains、desert_pyramid、jungle_pyramid、igloo、swamp_hut。

    古代都市や試験の間のような大きな構造は堅い洞窟ワールドを満たしたり、バランスを崩す可能性があるため、デフォルトで無効化されています。新しく生成されたオーバーワールドチャンクのみに影響します。

    デフォルト: 

    structures:
  ancient_city: false
  trial_chambers: false
  mansion: false
  mineshaft: true
  stronghold: true

    説明

    1.23.0で追加されました。 オーバーワールド洞窟密度。バニラは密な1.18+洞窟ネットワーク（チーズとスパゲッティ洞窟）を生成します。堅い洞窟ワールドでは、「通路ばかり」のように感じられます。これは低周波ノイズフィールドを使用して生成後に洞窟空気の一部を再固化するため、ランダムな単一の穴を開けるのではなく、領域全体が独立したチャンバーに閉じます。

    • 0.0 すべてのバニラ洞窟を保持（最も密、元の動作）。
    • 1.0 ほぼすべての洞窟を埋める（ほぼ堅い）。
    • 0.4 – 0.6で薄くしてみてください。

    地下バイオーム、鉱石、装飾、構造は両方の方法で保持されます。新しく生成されたチャンクのみに影響します。

    デフォルト: 0.0

    説明

    1.23.0で追加されました。 オーバーワールドでバニラカーバー洞窟（大きな峡谷と長い丸いトンネル）を生成します。これらはノイズ洞窟の上に積み重ねられます。falseに設定してノイズ洞窟を保持しながら峡谷と広いトンネルを削除します。

    デフォルト: true

    コマンド#

    Tip

    [player_command]と[admin_command]は実行中のゲームモードによって異なるコマンドです。

    ゲームモードのconfig.ymlファイルにはこれらの値を変更するオプションがあります。

    例えば、CaveBlockでは、デフォルトの[player_command]はcave、デフォルトの[admin_command]はcbaです。

    このアドオンではアドオンのconfig.ymlファイルでプレイヤーコマンドのエイリアスを変更できることに注意してください。

    BentoBox GameModeアドオンには標準のサブコマンドセットが付属しており、CaveBlock固有のサブコマンドも追加されています。

    変更履歴#

    v1.23.1の新機能

    リリース日: 2026-07-09

    1.23.0で導入された構造抑制の穴を閉じるバグ修正リリース。バニラ構造を無効化する1.23.0を実行しているすべてのサーバーに推奨されます。

    • 🔺 無効化された構造はサーバーをフリーズさせなくなります。 構造を無効化すると、その配置のみがキャンセルされ、配置ルールではなく、構造検索（/locate、エンダーアイ、探検家/宝の地図、イルカ、村人の地図取引）は半径キャップまでスキャンし続け、メインスレッドをフリーズさせました。新しいStructuresLocateEventハンドラーは、無効化された構造を事前に検索から削除し、「見つかりません」を即座に返すようになりました。#116を修正します。
    • 🔺 構造はもうスポーン地域を通り抜けなくなります。 抑制リスナーは最初のスポーンチャンクが生成される前にcreateWorlds()の早い段階で登録されるため、無効化された構造はもうスポーンの近くに現れることができません。

    Release v1.23.1

    v1.23.0の新機能

    リリース日: 2026-07-07

    1.22.0生成作業に基づいて構築された、オーバーワールド洞窟ワールドを埋めるものへの直接的な管理者制御を提供します。

    • ⚙️ 設定可能なオーバーワールド構造。 config.ymlの新しいstructures:セクションが個々のバニラ構造（古代都市、試験の間、邸宅、鉱山、要塞など）を切り替えます。最大のワールドを満たす構造はデフォルトで無効化されています。#112を修正します。
    • ⚙️ オーバーワールド洞窟密度制御。 新しいoverworld-cave-fill設定（0.0–1.0、デフォルト0.0）は密なバニラ洞窟ネットワークの一部を再固化するため、ワールドは終わりのない通路のように感じられず、バイオーム、鉱石、装飾、構造は手つかずのままです。#111を修正します。
    • ⚙️ カーバー洞窟トグル。 新しいoverworld-carvers設定（デフォルトtrue）はバニラの峡谷と広いトンネルを削除しながらノイズ洞窟を保持します。これはゲーム中に変更することはできません。

    新しいオプションは初回実行時にconfig.ymlに自動的に書き込まれ、新しく生成されたチャンクのみに影響します；デフォルトは1.22.0の動作を保持します。最大の構造がデフォルトで無効になっていることを除いて。上記の設定セクションを参照してください。

    Release v1.23.0

    v1.22.0の新機能 — ネザー＆エンド生成が再設計

    リリース日: 2026-07-06

    ネザーとエンドの生成方法を再構築します。以前は両次元とも、ランダムな単一ブロックで散らばった堅い岩のブロックでした — ラグを引き起こす浮遊火を含む — そして本物の洞窟がありませんでした。

    • 🔺 ネザー＆エンド生成オーバーホール。 両方の次元は今堅く埋められ、3Dノイズ洞窟ジェネレーターで接続されたトンネルとチャンバーに彫刻され、床と屋根に対する堅い余白があります。
    • 🌋 ネザー溶岩の海。 最も低い洞窟の空洞は開かれた空気ではなく溶岩で埋まります；床と屋根は堅いままなので、ワールドは閉じたままです。
    • 🗺️ 天然ネザーバイオーム。 5つのネザーバイオームは天然で、ほぼ同じ面積の領域に分割されるため、単一アイランド内に複数のバイオームが現れます。
    • 🌿 バイオーム認識装飾。 クリムゾン/ワープドナイリウム、根、キノコとツル；魂の砂の谷に魂の火と骨；玄武岩デルタ列と溶岩火；グロウストーン天井パッチ；エンドロッドとエンドのコーラス。
    • ⚡ もうラグのある浮遊火はありません。 火は今疎らでネザーラック/溶岩に接地されています。

    🔺 ワールド生成が変更されました: 新しいジェネレーターは新しく生成されたチャンクのみに影響します。既存のネザー/エンドチャンクは古い外観を保持するため、古いものと新しいものが出会う場所に継ぎ目が見えるかもしれません。一貫した外観が必要な場合は、それらの次元を再生成（または新しいワールドを開始）してください。

    Release v1.22.0

    v1.21.0 の新機能 — Breaking: ワールド生成が再設計

    リリース日: 2026-06-27

    大規模な生成オーバーホール。CaveBlockはJava 21上のPaper 1.21.11とBentoBox 3.14 APIを対象としています。

    • 🔺 バニラ洞窟ワールド生成。 オーバーワールドはMinecraftの独自の1.18+ノイズジェネレーターに委譲されるため、島は本物のチーズ、スパゲッティ、ラッシュ、鐘乳石、深暗洞窟で彫刻され、バニラの鉱石、装飾、構造（鉱山、ダンジョン、試験の部屋、紫水晶地柱、古代都市）、地下バイオームが完備されています。空は石でキャップされるため、ワールドはベドロックから屋根まで堅い岩のままです。
    • 💎 再設計されたネザー＆エンド鉱石脈。 ネザーとエンドは充填と装飾アプローチを保持し、単一ブロックの代わりに適切にサイズ設定された鉱石塊（古代デブリ、クォーツ、黒曜石、グロウストーンなど）を配置する新しい脈ポピュレーターがあります。
    • ⚙️ 設定クリーンアップ。 ワールド生成設定が再設計され、無効なオプションが削除されました — generation-tries、use-new-material-generator、ディメンションごとのblocksリスト、natural-surface/natural-caves/natural-bedrockトグル、古いnetherBlocks/endBlocks/debug設定がなくなりました。アドオンに新しいデフォルトを書かせる前に、既存のconfig.ymlをバックアップしてください。
    • 🔡 MiniMessageロケール。 すべてのロケールファイルがレガシーカラーコードからMiniMessageに移行され、高さ制限メッセージキーはcaveblock.general.errors.cave-limit-reachedに改名されました。カスタマイズしたロケールファイルがある場合は、再生成してください。
    • 🧪 生成、高さ制限、アドオンのライフサイクルを保護するために、完全なJUnit 5 + MockBukkitテストスイートが追加されました。

    🔺 ワールド生成が変更されました: 新しく生成されたオーバーワールドチャンクはソリッド充填彫刻の代わりにバニラノイズ洞窟を使用するようになります。既に生成されたチャンクは変更されていませんが、ワールドのエッジの新しい地形は古い領域と異なります。これが重要な場合は、最初にコピーでテストしてください。

    Release v1.21.0

    翻訳#

    翻訳の改善にご協力ください

    BentoBoxとその拡張機能のほとんどの翻訳はAIの助けを借りて 生成されているため、作業の大部分はすでに完了しています — ただしAIは完璧ではありません。コミュニティに本当に必要なのは、 エラーの報告と修正です。

    • 誤りや不自然な表現を見つけた場合は、 bentobox.world（GitHubオーガニゼーションへの ショートリンク）からissueまたはPRを開くか、 Discordでご連絡ください。
    • 新しい言語を追加したい場合は、該当リポジトリの src/main/resources/locales/に新しいロケールファイルを追加する PRを開くか、Discordでご相談ください。
