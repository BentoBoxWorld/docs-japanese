# BentoBox

BentoBoxはPaperサーバーをアイランドアドベンチャーの遊び場に変えます。**SkyBlock**、**AcidIsland**、**OneBlock**、**CaveBlock**、**SkyGrid**、**Boxed**、**Poseidon**、**Stranger Realms**など、複数のゲームモードを同じサーバー上で同時に動かすことができます。それぞれに独自のワールド、ルール、進行があります。プレイヤーは自分だけのアイランドを持ち、仲間と建築し、チャレンジをこなし、レベルを上げ、ワープを自慢できます。管理者にとっても楽な仕組みです。プラグインを1つインストールするだけで、すぐに使える合理的なデフォルト設定が用意されており、Bank、Biomes、Border、Challenges、Greenhouses、Level、Limits、Warpsなど豊富なドロップインアドオンライブラリから選んで組み合わせるだけで、希望通りのサーバーを構築できます。コーディングは不要です。シンプルなクラシックSkyBlockワールド1つから、あらゆるアイランドゲームを揃えた大型ハブまで、BentoBoxは柔軟でテスト済みの基盤であり、すでに数千のサーバーに信頼されています。
