# アイランド保護、フラグ & ランク

[TOC]

## はじめに

BentoBoxゲームワールドでプレイヤー（およびピストン、モブ、火、爆発などの環境）ができることは、すべて**フラグ**によってコントロールされています。各フラグは1つのアクションの種類をカバーします。例えばブロックを壊す、チェストを開く、動物を傷つけるなど。ほとんどのフラグはBentoBoxで提供されています。[Greenhouses](https://github.com/BentoBoxWorld/Greenhouses)などのアドオンは独自のフラグを追加できます。

[フラグのリスト](Flags.md)ですべてのフラグ、アイコン、デフォルトを参照してください。

フラグには3つのタイプがあります：

| タイプ | 制御内容 | 変更者 |
| --- | --- | --- |
| **保護フラグ** | どの[ランク](#ranks)がアクションを行えるか。例：ブロックを壊す。アイランド上ではランクです。アイランド外ではオン/オフです。 | アイランド所有者が自分のアイランドで。管理者がワールドと新規アイランド用。 |
| **設定フラグ** | アイランド全体のオン/オフスイッチ。例：PVPまたは動物スポーン。 | アイランド所有者。 |
| **ワールド設定** | ゲーム全体のスイッチ。例：クリーパーダメージ。 | 管理者のみ。 |

### アイランド上、アイランド外、新規アイランド

最も一般的な混乱は、1つの保護フラグが**3つの異なる値**を持ちうることです。プレイヤーが立っている場所と対象のアイランドに応じて：

| 質問 | 設定場所 | パネルタブ |
| --- | --- | --- |
| このアイランド**上**でこのアクションを行えるのはどのランク？ | そのアイランドの設定 | `/[player_command] settings` → **保護フラグ** |
| このワールドの**アイランド外**のどこでも誰もができること？ | ワールドの保護フラグ（ゲームモードの`config.yml`の`world.flags`） | `/[admin_command] settings` → **ワールド保護** |
| **新規作成**されたアイランドがどのランクで開始するか？ | ゲームモードの`config.yml`の`world.default-island-flags` | `/[admin_command] settings` → **アイランドデフォルト** |

1つを変更しても他は変わりません。特に、**アイランドデフォルトはアイランド外では効果がなく**、**ワールド保護はアイランド上では効果がありません**。

### アイランドの終わり

アイランドの保護はそのグリッドスクエア全体をカバーしていません。アイランドは`distance-between-islands`間隔で配置されますが、各アイランドは**保護範囲**内でのみ保護されます。これはアイランドの中心から各方向に`protection-range`ブロックの正方形です。範囲は`/[admin_command] range`またはパーミッション`[gamemode].island.range.<number>`でアイランドごとに上げることができます。

保護範囲外のどこでもが**アイランド外**としてカウントされます。アイランドのグリッドスクエア内でも。ここには、アイランド間のボイド、アイランドでないワールドスポーン周辺、Boxedなどのゲームモードの荒地を含みます。アイランド外では、[ワールド保護](#world-protections)が適用されます。

## ランク { #ranks }

各プレイヤーは各アイランドでランクを持っています：所有者、メンバー、訪問者など。保護フラグは**そのアクションを行える最低ランク**を設定します。そのランク以上のすべてのプレイヤーが許可されます。ランクは番号なので、より高いほどより信頼できます：

| ランク | 値 | 誰が持つか |
| --- | --- | --- |
| バン済み | -1 | アイランドからバンされたプレイヤー。入ることはできません。 |
| ビジター | 0 | アイランドの一部ではないプレイヤー。 |
| Coop | 200 | `/[player_command] team coop`で追加されたプレイヤー。すべてのチームメンバーがログオフしたら削除されます。 |
| 信頼 | 400 | `/[player_command] team trust`で追加されたプレイヤー。ログイン間で保持されます。 |
| メンバー | 500 | チームメンバー。 |
| サブオーナー | 900 | `/[player_command] team promote`で昇進したチームメンバー。 |
| 所有者 | 1000 | アイランド所有者。 |
| モデ | 5000 | プレイヤーに与えられません。予約済み。 |
| 管理者 | 10000 | プレイヤーに与えられません。予約済み。 |

したがって、フラグが*メンバー*に設定されている場合、メンバー、サブオーナー、所有者はアクションを実行できますが、信頼できるプレイヤー、coops、訪問者はできません。フラグが*ビジター*に設定されている場合、誰でもできます。

アドオンはこれらの間にさらにランクを登録できます。

管理者は`/[admin_command] getrank <player>`と`/[admin_command] setrank <player> <rank>`でプレイヤーのランクを確認または変更できます。

## アイランド設定パネル { #island-settings-panel }

**設定パネル**はアイランド所有者がアイランドを設定する場所です。`/[player_command] settings`で開きます（パーミッション`[gamemode].island.settings`）。アイランド上のすべてのプレイヤーは表示できます。所有者のみが変更でき、また所有者が**設定を変更**フラグ（作業台、最上段）で許可したランクも変更できます。

パネルはプレイヤーが立っているアイランドを表示するか、他の場所にいる場合は自分のアイランドを表示します。管理者は`/[admin_command] settings <player_name>`で任意のプレイヤーのアイランドを開けます。

### 保護フラグタブ

**保護フラグ**タブが最初に表示され、アイランドの**保護フラグ**をリストします。

フラグを**左クリック**してそれが必要とするランクを上げて、**右クリック**して下げてください。ロアはランクをリストし、現在のランクをハイライトします。*所有者*を越えてラップアラウンドすると*ビジター*になり、反対もそうです。

新しいアイランドは[アイランドデフォルト](#island-defaults)タブで設定されたランクで開始します。ほとんどのフラグは*メンバー*で開始するため、訪問者は見ることができますが触ることはできません。一部は低く開始して訪問者が使用できるようにします。例えば、*ロック*は*ビジター*で開始するため、アイランドは訪問者に開かれています。

### 設定タブ

**設定**タブはアイランドの**設定フラグ**をリストします：PVP、火の蔓延、葉の腐食、モブスポーンなどのアイランド全体のオン/オフスイッチ。設定をクリックして切り替えてください。

各設定にはまた、パーミッション`[gamemode].settings.<FLAG_ID>`（または`[gamemode].settings.*`）が必要です。これによりサーバーは設定をプレイヤーから完全に取り去ることができます。例えば、PVPをオフにするのを止めるため。PVPなどの一部の設定には変更間のクールダウンがあります。

このタブには[コマンドランク](#command-ranks)アイコンもあります。

### ワールド保護ビュー { #world-protection-view }

!!! new "BentoBox 3.22.0で追加"
    アイランドを持たず、別のアイランドエリアに立っていないプレイヤーは、読み取り専用の**ワールド保護**タブを代わりに見ます。これは管理者が[ワールド保護](#world-protections)タブで設定した通り、アイランド外で誰が何をできるかを表示します。これは情報専用で、ここから変更することはできません。

### 表示モード

**表示モード**に応じて、設定パネルはより多くまたはより少ないフラグを表示します。モードは`BASIC`、`ADVANCED`、または`EXPERT`です。パネルの右上隅のインゴットをクリックしてモードを変更してください。

`BASIC`がデフォルトで、ほとんどのプレイヤーが必要とするフラグを表示します。

`ADVANCED`はより細かいコントロール用にさらにフラグを表示します。

`EXPERT`はすべてのフラグを表示し、追加ページが必要です。

!!! new "BentoBox 3.23.3で変更"
    設定パネルは各プレイヤーが最後に選択した表示モードを記憶し、次に開くときそれで開きます。1つのモードが保護と設定タブで共有されます。選択されたモードで表示するフラグがなければ、次のモードアップをプレイヤーの選択を変更することなく表示します。管理者設定パネルは常に`EXPERT`で開きます。

### フラグを隠す

オペレーターはフラグをプレイヤーから隠すことができます：設定パネルを開いてフラグアイコンを++shift+left-button++です。アイコンが「消滅の呪い」グリントを取得し、プレイヤーはフラグをもう見ません。もう一度同じことをしてフラグを表示してください。隠されたフラグはゲームモードの`config.yml`の`world.hidden-flags`に保存されます。

フラグを隠すことはそれをパネルから削除するだけです。フラグは現在の値を保持し、依然として適用されます。プレイヤーがフラグを変更できないようにするには、まず値を設定してからフラグを隠してください。

### 設定パネルのカスタマイズ { #customizing-the-settings-panel }

!!! new "BentoBox 3.23.0で追加"
    設定パネルはテンプレートファイルでレイアウトされます。他の[カスタマイズ可能なGUI](Tutorials/generic/Customizable-GUI.md)のように。

設定パネルのレイアウトは`plugins/BentoBox/panels/settings_panel.yml`から来ます。BentoBoxはそれを初回起動時に書き込みます。ゲームモードアドオンは自身の`panels`フォルダーに独自のコピーを配置でき（例：`plugins/BentoBox/addons/BSkyBlock/panels/settings_panel.yml`）、そのゲームモードではそれが代わりに使用されます。デフォルトファイルはパネルをまったく前のようにを再現するため、編集するまで何も変わりません。ファイルを読めない場合、BentoBoxはエラーをログし、組み込みパネルを表示します。

すべてのボタンは`data.type`で配置されます：

| タイプ | 表示内容 |
| --- | --- |
| `TAB` | タブボタン。`data.tab`は`PROTECTION`、`SETTING`、または`WORLD_PROTECTION`（アイランドに立っていないプレイヤーが取得する読み取り専用ビュー）。適用されないタブは表示されず、ボタンの`fallback`が代わりに使用されます。 |
| `FLAG` | ページ分けされたフラグリストの1スロット。1ページに必要なだけ多くの設定。`data.flag: <FLAG_ID>`を使用するとそのスロットは常にそのフラグを表示し、フラグはページリストを離れます。ロックと設定変更アイコンはこの方法で配置されます。 |
| `MODE` | 表示モードスイッチ。`data`内の`basic-icon`、`advanced-icon`、`expert-icon`でモードごとにアイコンを設定できます。 |
| `RESET` | すべてのフラグをデフォルトにリセット。アイランド所有者のみが見ます。 |
| `NEXT`、`PREVIOUS` | ページング。ページがあるときのみ表示されます。 |

**タイトルとタブ名は別です。** パネルタイトルはテンプレートの`title`で、デフォルトはロケールエントリー`panels.settings.title`。それは`[tab]`（表示中のタブの名前）と`[world_name]`で翻訳されます。デフォルトはちょうど`[tab]`です。各タブボタンには独自の`title`と`description`があり、デフォルトは`protection.panel.PROTECTION.title`などのエントリー。そのため、テンプレートとロケールのどちらでも、タイトルを1つの方法でスタイルでき、タブボタンを別の方法で。

**ロアレイアウト。** フラグのロアは`protection.panel.flag-item.description-layout`（保護フラグ）、`setting-layout`（設定）、またはロケール内の`menu-layout`（サブパネルを開くフラグ）から構築されます。3.23.0以降、これらのレイアウトは保護フラグのランクリストが挿入される`[ranks]`とテンプレート内のフラグボタンの`actions`のツールチップが挿入される`[tooltips]`を含むことができます。`[ranks]`なしでランクリストは前のようにレイアウト後に追加されます。`[tooltips]`なしでツールチップは空行の後に追加されます。ランクリストの下にクリックヒントを移動するには、レイアウトからそれらを削除して、`[ranks]`と`[tooltips]`を必要とする場所に置いて、テンプレートの`flag_button`でツールチップとしてヒントを宣言します。テンプレート内のフラグボタン自身の`title`と`description`は異なるロケールエントリーを指定して、そのパネルだけの名前とロアレイアウトとして使用できます。

### 保護タブ

**保護タブ**は設定パネルを開いた際に表示されるタブです。**保護フラグ**が含まれています。

**保護フラグ**は[ランク](#ランク)によって設定できるフラグです。フラグのアイコンを**左クリック**または**右クリック**することで、アイランドオーナーはさまざまなランクを循環させ、フラグが規定するインタラクションをプレイヤーのランクに応じて許可または拒否できます。

### 設定パネルのカスタマイズ { #customizing-the-settings-panel }

!!! new "BentoBox 3.23.0で追加"
    設定パネルは、他の[カスタマイズ可能なGUI](/en/latest/Tutorials/generic/Customizable-GUI/)と同様にテンプレートファイルでレイアウトされます。

設定パネルのレイアウトは`plugins/BentoBox/panels/settings_panel.yml`から読み込まれます。このファイルはBentoBoxの初回起動時に作成されます。ゲームモードアドオンは自身の`panels`フォルダーに独自のコピーを同梱でき（例：`plugins/BentoBox/addons/BSkyBlock/panels/settings_panel.yml`）、そのゲームモードではそちらが代わりに使用されます。デフォルトのファイルは以前のパネルをそのまま再現しているため、編集するまで何も変わりません。ファイルを読み込めない場合、BentoBoxはエラーをログに出力し、組み込みのパネルを表示します。

各ボタンは`data.type`で配置します：

| タイプ | 表示内容 |
| --- | --- |
| `TAB` | タブボタン。`data.tab`は`PROTECTION`、`SETTING`、または`WORLD_PROTECTION`（プレイヤーがアイランド上にいないときに表示される読み取り専用のビュー）です。該当しないタブは表示されず、代わりにボタンの`fallback`が使用されます。 |
| `FLAG` | ページ分けされたフラグ一覧の1スロット。1ページに表示したいフラグの数だけ配置します。`data.flag: <FLAG_ID>`を指定すると、そのスロットには常にそのフラグが表示され、そのフラグはページ一覧から外れます。ロックアイコンや設定変更アイコンはこの方法で配置されています。 |
| `MODE` | 表示モードの切り替え。`data`内の`basic-icon`、`advanced-icon`、`expert-icon`でモードごとにアイコンを設定できます。 |
| `RESET` | すべてのフラグをデフォルトに戻します。アイランドのオーナーにのみ表示されます。 |
| `NEXT`、`PREVIOUS` | ページ送り。移動先のページがある場合にのみ表示されます。 |

**タイトルとタブ名は別々です。** パネルのタイトルはテンプレートの`title`で、デフォルトはロケールエントリー`panels.settings.title`です。これは`[tab]`（表示中のタブの名前）と`[world_name]`を置き換えて翻訳されます。デフォルトは`[tab]`のみです。各タブボタンには独自の`title`と`description`があり、デフォルトは`protection.panel.PROTECTION.title`などのエントリーです。そのため、テンプレートまたはロケールのどちらでも、タイトルとタブボタンを別々のスタイルにできます。

**説明文（lore）のレイアウト。** フラグの説明文は、ロケールの`protection.panel.flag-item.description-layout`（保護フラグ）、`setting-layout`（設定）、または`menu-layout`（サブパネルを開くフラグ）から組み立てられます。3.23.0以降、これらのレイアウトには`[ranks]`（保護フラグのランク一覧が挿入される位置）と`[tooltips]`（テンプレートのフラグボタンの`actions`のツールチップが挿入される位置）を含めることができます。`[ranks]`がない場合、ランク一覧は従来どおりレイアウトの後に追加されます。`[tooltips]`がない場合、ツールチップは空行の後に追加されます。クリックのヒントをランク一覧の下に移動するには、レイアウトからヒントを削除し、`[ranks]`と`[tooltips]`を好きな位置に置き、テンプレートの`flag_button`でヒントをツールチップとして宣言します。テンプレート内のフラグボタン自身の`title`と`description`で別のロケールエントリーを指定すると、そのパネルでのみ名前と説明文のレイアウトとして使用されます。

### コマンドランク { #command-ranks }

設定タブの**コマンドランク**アイコンをクリックすると、パネルが開き、アイランドのオーナーが各チームコマンド（例えば、誰がメンバーを招待、キック、またはアイランドの名前を設定できるか）を使用するために必要な最小[ランク](#ranks)を選択できます。コマンドの**左クリック**と**右クリック**でランクを循環させます。保護フラグの場合と同じです。オペレーターは++shift+left-button++を使ってプレイヤーからコマンドを非表示にできます。これは[フラグを非表示にする](#hide-flags)場合と同じ方法です。

BentoBox 3.23.3以降、プレイヤーには自分が使用権限を持つコマンドのみが表示されます。サーバーでコマンドのパーミッションを拒否している場合（例えば`[gamemode].island.border`）、そのコマンドはこのパネルに表示されなくなります。以前は最上位レベルのコマンドのみが確認されていたため、プレイヤーが実行できないサブコマンドも一覧に表示されていました。

#### コマンドランクパネルのカスタマイズ { #customizing-the-command-ranks-panel }

!!! new "BentoBox 3.23.3で追加"
    コマンドランクパネルは、[設定パネル](#customizing-the-settings-panel)と同様にテンプレートファイルでレイアウトされます。

レイアウトは`plugins/BentoBox/panels/command_ranks_panel.yml`から読み込まれます。このファイルはBentoBoxの初回起動時に作成されます。ゲームモードアドオンは自身の`panels`フォルダーに独自のコピーを同梱でき、そのゲームモードではそちらが代わりに使用されます。デフォルトのファイルは以前のパネルをそのまま再現しているため、編集するまで何も変わりません。ファイルを読み込めない場合、BentoBoxは組み込みのパネルを表示します。

すべてのボタンは`data.type`で配置します：

| タイプ | 表示内容 |
| --- | --- |
| `COMMAND` | ページ分けされたコマンド一覧の1スロット。1ページに表示したいコマンドの数だけ配置します。デフォルトは45です。 |
| `NEXT`、`PREVIOUS` | ページ送り。移動先のページがある場合にのみ表示されます。 |

組み込みパネルは49個のコマンドで停止していたため、それ以上のコマンドは表示されていませんでした。テンプレートはページ分けの代わりに使用されます。

コマンドの描画方法は、テンプレートの`reusable`セクションの`command_button`で変更できます：

- `icon`はデフォルトの`MAP`を置き換えます。
- `title`はロケールエントリー（またはテキスト）で、`protection.panel.flag-item.name-layout`の代わりに名前レイアウトとして使用されます。`[name]`はコマンド（例: `/island sethome`）です。
- `description`はロケールエントリー（またはテキスト）で、`protection.panel.flag-item.description-layout`の代わりにloreレイアウトとして使用されます。`[description]`は`protection.panel.flag-item.command-instructions`からのコマンドのテキストです。ランク一覧がその後に追加されます。
- `actions`はツールチップのみを追加し、ランク一覧の後に追加されます。クリック自体は常に上記のように機能します。デフォルトのレイアウトにはクリックヒントが既に含まれています。

例えば、各コマンドを紙として表示し、空きスロットを埋めるには：

```yaml
command_ranks_panel:
  title: protection.flags.COMMAND_RANKS.name
  type: INVENTORY
  background:
    icon: LIGHT_BLUE_STAINED_GLASS_PANE
    title: "&b&r"
  force-shown: 6
  content:
    # ... rows of command_button, and the paging buttons, as in the default file
  reusable:
    command_button:
      icon: PAPER
      data:
        type: COMMAND
```

## 保護のバイパス

保護フラグはBentoBoxゲームワールド内でのみ、そして正当な方法がないプレイヤーに対してのみ適用されます。保護をバイパスする方法はいくつかあります。一部は意図されたもの（アイランドランク）、一部はスタッフ用（オペレーターステータスとモデレーターパーミッション）、一部は構造的な（ワールドまたはフラグタイプ）です。

!!! tip
    以下の権限における`[gamemode]`はゲームモードの小文字の名前です。BSkyBlockの場合、ノードは`bskyblock.mod…`で始まり、AcidIslandの場合は`acidisland.mod…`となります。

### アイランドランク — 本来の方法

保護フラグを「バイパス」する通常の設計された方法は、アイランドで十分に高い**ランク**を持つことです。すべての保護フラグに必要なランクがあり、そのランク以上のランクを持つメンバーはアクションが許可されます。これがオーナーはビルドでき、ビジターはできない理由です。本当はバイパスではなく、フラグが設定通りに機能しているだけです。上記の[ランク](#ランク)リストをご覧ください。

### オペレーター

サーバーオペレーター（`/op`）は最も広範なバイパスです。オペレーターはすべてのBentoBoxワールドのすべての保護フラグを通過でき、ロックされたアイランドとバンされたアイランドに入ることができ、バンまたは追放されることから免除されています。

重要な注意点が2つあります：

- **オペレーターはアイランド設定フラグをバイパスしません。** `SETTING`タイプフラグ（「PVPを許可」「モブスポーニング」など、アイランドトグル）はオペレーターチェックの前に評価されるため、オペレーターは他のプレイヤーと同じようにこれらの影響を受けます。オペレーターステータスは*保護*フラグのみをオーバーライドします。
- **管理スイッチは自分のアイランドでプレイヤーを完全に「un-op」することはできません。** スイッチがオンになっていても（下記参照）、オペレーターはそれでもアイランドが許可されます。これは、ランクチェックがオペレーターステータスを常に許可されるものとして扱うためです。保護を真の非オペレーターとしてテストするには、オペレーターステータスを削除してください。

### モデレーターバイパスパーミッション

完全なオペレーターではない必要があるスタッフの場合、代わりにパーミッションで保護をバイパスできます。これらは管理スイッチによってゲートされているため（下記参照）、モデレーターは独自のバイパスをオフにトグルして、通常のプレイヤーがそうするように世界を体験できます。

- `[gamemode].mod.bypassprotect` — ワールド内すべての保護フラグをバイパスします。
- `[gamemode].mod.bypass.<FLAG_ID>.everywhere` — 指定されたフラグ1つ（例：`BREAK_BLOCKS`）をワールド内すべてでバイパスします。
- `[gamemode].mod.bypass.<FLAG_ID>.island` — 指定されたフラグ1つをバイパスしますが、プレイヤーがアイランド上でブロックされているでのみです。

### 管理「スイッチ」 — 通常のプレイヤーとしてテスト

コマンド`/[admin_command] switch`（パーミッション`[gamemode].mod.switch`）はモデレーターのバイパスパーミッションのオンとオフを切り替えます。デフォルトではバイパスパーミッションは**アクティブ**（モデレーターは保護をバイパスしています）です。コマンドを1回実行するとバイパスが**オフ**になり、通常のプレイヤーのように保護の影響を受けます。もう一度実行するとバイパスが戻ります。これは上記の`mod.bypassprotect`と`mod.bypass.*`パーミッションに影響します—生のオペレーターステータスを無効にすることは**ありません**。

### ロック、バン、追放

アイランドのロック、バン、追放には、フラグシステムとは別の独自のバイパスパーミッションがあります：

- `[gamemode].mod.bypasslock` — ロックされたアイランドに入ります。
- `[gamemode].mod.bypassban` — バンされたアイランドに入ります。
- `[gamemode].mod.bypassexpel`と`[gamemode].admin.noexpel` — 追放されることができません。
- `[gamemode].admin.noban` — バンされることができません。

Bukkit `NPC`メタデータを持つエンティティ（例：Citizens NPCs）は、ロック、バン、PVP、不敗ビジターチェックを通過することも許可されるため、プラグインNPCはアイランド保護によってトラップされたり害を受けたりしません。

### クールダウンと遅延

コマンドクールダウンとテレポートウォームアップ遅延は次でスキップできます：

- `[gamemode].mod.bypasscooldowns` — コマンドクールダウンを無視します。
- `[gamemode].mod.bypassdelays` — 遅延テレポートコマンドのmovementウォームアップ遅延をスキップします。

### 保護されないもの

- **BentoBox以外のワールド。** 保護はゲームモードワールド（およびそのリンクされた標準ネザー/エンド）のみに存在します。サーバーのデフォルトワールドおよび他のプラグインのワールドはチェックされません。
- **「荒野」。** プレイヤーがゲームモードワールド内にいるが、どのアイランドにも立っていないとき、アイランドの設定ではなく、ワールドのデフォルトフラグ設定が適用されます。これらは下記の**管理者設定パネル**（またはゲームモードの`config.yml`）で設定されます。
- **削除されたアイランドは例外です：** 削除待機中のアイランドでは、デフォルトで何も許可されません。オペレーターと`mod.bypassprotect` / `mod.bypass.<FLAG_ID>.everywhere`パーミッションの保有者を除き、これらのバイパスが最初にチェックされます。

## 管理者設定パネル

**管理者設定パネル**は`/[admin_command] settings`（引数なし）でアクセスできます。3つのタブが含まれています：

!!! new "BentoBox 3.23.0で追加"
    管理者設定パネルは、[プレイヤーの設定パネル](#customizing-the-settings-panel)と同じ方法で`plugins/BentoBox/panels/admin_settings_panel.yml`によってレイアウトされます。タブタイプは`WORLD_SETTING`、`WORLD_DEFAULTS`、`ISLAND_DEFAULTS`です。後の2つには`[gamemode].admin.set-world-defaults`パーミッションが必要で、パーミッションがない場合は非表示になります。同じファイルで`/[admin_command] settings <player_name>`もレイアウトされます。各ワールドタブは`fallback`としてアイランドタブ（`PROTECTION`、`SETTING`）を指定しており、アイランドがある場合はそちらが表示されます。

### ワールド設定

ゲームワールド全体に適用されるワールドレベルの設定フラグを切り替えます。

!!! new "BentoBox 3.23.6で追加"
    **常に許可するエンティティタイプ**の項目（鉄インゴット）を開くと、すべての生物のエンティティタイプが一覧表示されます。緑色のタイプは、動物やモンスターのスポーンがオフでも、どのアイランドでもワールドでもスポーンします。アイアンゴーレムはデフォルトで緑色なので、村のアイアンゴーレムトラップは引き続き動作します。**グローバルなモブスポーン**のブロックリストが引き続き優先されます。このリストはゲームモードの`config.yml`ではなくBentoBoxが保存します。[モブスポーンの優先順位](About/Protections.md#mob-spawning-precedence)を参照してください。`[gamemode].admin.settings.ALLOW_MOBS`が必要です。

### ワールドデフォルト保護

アイランド境界外（荒野のビジター用）でアクティブな保護フラグを制御します。

### アイランドデフォルト

!!! new "BentoBox 3.14.0で追加"
    **アイランドデフォルト**タブは管理者設定パネルの新しいタブで、管理者が**新しく作成されるアイランド**に適用されるデフォルトフラグ値を設定できます。

以前は、これらのデフォルト値はゲームモードの`config.yml`でのみ変更できました。現在は`/[admin_command] settings`を開いて**アイランドデフォルト**タブ（タブ3）に移動することでゲーム内で直接変更できます。

各保護フラグは現在のデフォルトランクとともにリストされており、クリックするとランクのはしごを循環します。各アイランド設定フラグは現在のデフォルトの`true`/`false`状態を表示し、クリックするとトグルします。変更は即座にワールド設定に保存され、変更後に**新しく**作成されたすべてのアイランドに影響します。既存のアイランドには影響しません。
