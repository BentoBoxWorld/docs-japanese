# アイランド保護、フラグ & ランク

[TOC]

## はじめに
プレイヤー（さらに環境、エンティティ、ピストンなど）とアイランドとのインタラクションは、**アイランドで誰または何が何をできるかを決定する**一連の**フラグ**によって規定されています。これらのフラグはほとんどBentoBoxによって処理・提供されますが、アドオン（例：[Greenhouses](https://github.com/BentoBoxWorld/Greenhouses)）が独自のものを追加できます。

フラグのリストは[こちら](/en/latest/BentoBox/Flags)をご覧ください。

## 設定パネル

**設定パネル**はアイランドオーナーが自分のアイランドのフラグ設定を編集できるGUIです。アイランドメンバーを含む他のプレイヤーは確認のみできます。

このGUIは次のコマンドで開きます：`/[player_command] settings`（次のパーミッションが必要：`[gamemode].island.settings`）。

![設定パネルのデフォルトビュー](https://user-images.githubusercontent.com/20014332/80591492-1689c100-8a1e-11ea-9a59-c55f35ab6ad9.png)

*設定パネルのデフォルトビュー。*

管理者は管理者設定コマンドを使用してプレイヤーのアイランドの設定を変更できます：`/[admin_command] settings <player_name>`

### 保護タブ

**保護タブ**は設定パネルを開いた際に表示されるタブです。**保護フラグ**が含まれています。

**保護フラグ**は[ランク](#ランク)によって設定できるフラグです。フラグのアイコンを**左クリック**または**右クリック**することで、アイランドオーナーはさまざまなランクを循環させ、フラグが規定するインタラクションをプレイヤーのランクに応じて許可または拒否できます。

![保護フラグの例](https://user-images.githubusercontent.com/20014332/62974085-b31c1c80-be17-11e9-8b27-2fd4bf54ae87.png)

*保護フラグの例。*

デフォルトでは、ほとんどの保護フラグはアイランドメンバー（以上のランク）のみがインタラクションできるよう設定されています。ただし、一部は最初からビジターにも許可されています。[ゲームモードのconfig.yml]をご覧ください。

![デフォルトでビジターがインタラクションできる保護フラグの例](https://user-images.githubusercontent.com/20014332/62974359-553c0480-be18-11e9-8679-0033fd8bf8bd.png)

*デフォルトでビジターがインタラクションできる保護フラグの例。*

管理者は管理者設定コマンドを使用してアイランド境界外での保護の動作を設定できます：`/[admin_command] settings`

### フラグの非表示

[BentoBox 1.4.0](https://github.com/BentoBoxWorld/BentoBox/releases/tag/1.4.0)以降、管理者は設定パネルを開き、非表示にしたいフラグのアイコンを++shift+left-button++することでGUIのフラグを非表示にできます。
これにより、アイコンに「消滅の呪い」エンチャントが適用され、対応するフラグがプレイヤーに非表示になります。
管理者は同じ手順を繰り返すことで後でフラグを再表示できます。

### 設定パネルのカスタマイズ { #customizing-the-settings-panel }

!!! new "BentoBox 3.23.0で追加"
    設定パネルは、他の[カスタマイズ可能なGUI](/en/latest/Tutorials/generic/Customizable-GUI/)と同様にテンプレートファイルでレイアウトされます。

設定パネルのレイアウトは`plugins/BentoBox/panels/settings_panel.yml`から読み込まれます。このファイルはBentoBoxの初回起動時に作成されます。ゲームモードアドオンは自身の`panels`フォルダーに独自のコピーを同梱でき（例：`plugins/BentoBox/addons/BSkyBlock/panels/settings_panel.yml`）、そのゲームモードではそちらが代わりに使用されます。デフォルトのファイルは以前のパネルをそのまま再現しているため、編集するまで何も変わりません。ファイルを読み込めない場合、BentoBoxはエラーをログに出力し、組み込みのパネルを表示します。

各ボタンは`data.type`で配置します：

| タイプ | 表示内容 |
| --- | --- |
| `TAB` | タブボタン。`data.tab`は`PROTECTION`、`SETTING`、または`WORLD_PROTECTION`（プレイヤーがアイランド上にいないときに表示される読み取り専用のビュー）です。該当しないタブは表示されず、代わりにボタンの`fallback`が使用されます。 |
| `FLAG` | ページ分けされたフラグ一覧の1スロット。1ページに表示したいフラグの数だけ配置します。`data.flag: <FLAG_ID>`を指定すると、そのスロットには常にそのフラグが表示され、そのフラグはページ一覧から外れます。ロックアイコンや設定変更アイコンはこの方法で配置されています。 |
| `MODE` | 表示モードの切り替え。`data`内の`basic-icon`、`advanced-icon`、`expert-icon`でモードごとにアイコンを設定できます。 |
| `RESET` | すべてのフラグをデフォルトに戻します。アイランドのオーナーにのみ表示されます。 |
| `NEXT`、`PREVIOUS` | ページ送り。移動先のページがある場合にのみ表示されます。 |

**タイトルとタブ名は別々です。** パネルのタイトルはテンプレートの`title`で、デフォルトはロケールエントリー`panels.settings.title`です。これは`[tab]`（表示中のタブの名前）と`[world_name]`を置き換えて翻訳されます。デフォルトは`[tab]`のみです。各タブボタンには独自の`title`と`description`があり、デフォルトは`protection.panel.PROTECTION.title`などのエントリーです。そのため、テンプレートまたはロケールのどちらでも、タイトルとタブボタンを別々のスタイルにできます。

**説明文（lore）のレイアウト。** フラグの説明文は、ロケールの`protection.panel.flag-item.description-layout`（保護フラグ）、`setting-layout`（設定）、または`menu-layout`（サブパネルを開くフラグ）から組み立てられます。3.23.0以降、これらのレイアウトには`[ranks]`（保護フラグのランク一覧が挿入される位置）と`[tooltips]`（テンプレートのフラグボタンの`actions`のツールチップが挿入される位置）を含めることができます。`[ranks]`がない場合、ランク一覧は従来どおりレイアウトの後に追加されます。`[tooltips]`がない場合、ツールチップは空行の後に追加されます。クリックのヒントをランク一覧の下に移動するには、レイアウトからヒントを削除し、`[ranks]`と`[tooltips]`を好きな位置に置き、テンプレートの`flag_button`でヒントをツールチップとして宣言します。テンプレート内のフラグボタン自身の`title`と`description`で別のロケールエントリーを指定すると、そのパネルでのみ名前と説明文のレイアウトとして使用されます。

![消滅の呪い](https://user-images.githubusercontent.com/20014332/80591692-6799b500-8a1e-11ea-9ab8-e076f47d2220.png)

*フラグの1つに「消滅の呪い」が適用されています。*

![非表示フラグ](https://user-images.githubusercontent.com/20014332/80591757-839d5680-8a1e-11ea-8864-83b09252a7b9.png)

## 保護のバイパス

保護フラグはBentoBoxゲームワールド内でのみ、そして正当な方法がないプレイヤーに対してのみ適用されます。保護をバイパスする方法はいくつかあります。一部は意図されたもの（アイランドランク）、一部はスタッフ用（オペレーターステータスとモデレーターパーミッション）、一部は構造的な（ワールドまたはフラグタイプ）です。

!!! tip
    以下の権限における`[gamemode]`はゲームモードの小文字の名前です。BSkyBlockの場合、ノードは`bskyblock.mod…`で始まり、AcidIslandの場合は`acidisland.mod…`となります。

### アイランドランク — 本来の方法

保護フラグを「バイパス」する通常の設計された方法は、アイランドで十分に高い**ランク**を持つことです。すべての保護フラグに必要なランクがあり、そのランク以上のランクを持つメンバーはアクションが許可されます。これがオーナーはビルドでき、ビジターはできない理由です。本当はバイパスではなく、フラグが設定通りに機能しているだけです。上記の[ランク](#ランク)リストをご覧ください。

### オペレーター

サーバーオペレーター（`/op`）は最も広範なバイパスです。オペレーターはすべてのBentoBoxワールドのすべての保護フラグを通過でき、ロックされたアイランドとバンされたアイランドに入ることができ、バンまたは追放されることから免除されています。

重要な注意点が2つあります：

- **オペレーターはアイランド設定フラグをバイパスしません。** `SETTING`タイプフラグ（「PVPを許可」「モブスポーニング」など、アイランドトグル）はオペレーターチェックの前に評価されるため、オペレーターは他のプレイヤーと同じようにこれらの影響を受けます。オペレーターステータスは*保護*フラグのみをオーバーライドします。
- **管理スイッチは自分のアイランドでプレイヤーを完全に「un-op」することはできません。** スイッチがオンになっていても（下記参照）、オペレーターはそれでもアイランドが許可されます。これは、ランクチェックがオペレーターステータスを常に許可されるものとして扱うためです。保護を真の非オペレーターとしてテストするには、オペレーターステータスを削除してください。

### モデレーターバイパスパーミッション

完全なオペレーターではない必要があるスタッフの場合、代わりにパーミッションで保護をバイパスできます。これらは管理スイッチによってゲートされているため（下記参照）、モデレーターは独自のバイパスをオフにトグルして、通常のプレイヤーがそうするように世界を体験できます。

- `[gamemode].mod.bypassprotect` — ワールド内すべての保護フラグをバイパスします。
- `[gamemode].mod.bypass.<FLAG_ID>.everywhere` — 指定されたフラグ1つ（例：`BREAK_BLOCKS`）をワールド内すべてでバイパスします。
- `[gamemode].mod.bypass.<FLAG_ID>.island` — 指定されたフラグ1つをバイパスしますが、プレイヤーがアイランド上でブロックされているでのみです。

### 管理「スイッチ」 — 通常のプレイヤーとしてテスト

コマンド`/[admin_command] switch`（パーミッション`[gamemode].mod.switch`）はモデレーターのバイパスパーミッションのオンとオフを切り替えます。デフォルトではバイパスパーミッションは**アクティブ**（モデレーターは保護をバイパスしています）です。コマンドを1回実行するとバイパスが**オフ**になり、通常のプレイヤーのように保護の影響を受けます。もう一度実行するとバイパスが戻ります。これは上記の`mod.bypassprotect`と`mod.bypass.*`パーミッションに影響します—生のオペレーターステータスを無効にすることは**ありません**。

### ロック、バン、追放

アイランドのロック、バン、追放には、フラグシステムとは別の独自のバイパスパーミッションがあります：

- `[gamemode].mod.bypasslock` — ロックされたアイランドに入ります。
- `[gamemode].mod.bypassban` — バンされたアイランドに入ります。
- `[gamemode].mod.bypassexpel`と`[gamemode].admin.noexpel` — 追放されることができません。
- `[gamemode].admin.noban` — バンされることができません。

Bukkit `NPC`メタデータを持つエンティティ（例：Citizens NPCs）は、ロック、バン、PVP、不敗ビジターチェックを通過することも許可されるため、プラグインNPCはアイランド保護によってトラップされたり害を受けたりしません。

### クールダウンと遅延

コマンドクールダウンとテレポートウォームアップ遅延は次でスキップできます：

- `[gamemode].mod.bypasscooldowns` — コマンドクールダウンを無視します。
- `[gamemode].mod.bypassdelays` — 遅延テレポートコマンドのmovementウォームアップ遅延をスキップします。

### 保護されないもの

- **BentoBox以外のワールド。** 保護はゲームモードワールド（およびそのリンクされた標準ネザー/エンド）のみに存在します。サーバーのデフォルトワールドおよび他のプラグインのワールドはチェックされません。
- **「荒野」。** プレイヤーがゲームモードワールド内にいるが、どのアイランドにも立っていないとき、アイランドの設定ではなく、ワールドのデフォルトフラグ設定が適用されます。これらは下記の**管理者設定パネル**（またはゲームモードの`config.yml`）で設定されます。
- **削除されたアイランドは例外です：** 削除待機中のアイランドでは、デフォルトで何も許可されません。オペレーターと`mod.bypassprotect` / `mod.bypass.<FLAG_ID>.everywhere`パーミッションの保有者を除き、これらのバイパスが最初にチェックされます。

## 管理者設定パネル

**管理者設定パネル**は`/[admin_command] settings`（引数なし）でアクセスできます。3つのタブが含まれています：

!!! new "BentoBox 3.23.0で追加"
    管理者設定パネルは、[プレイヤーの設定パネル](#customizing-the-settings-panel)と同じ方法で`plugins/BentoBox/panels/admin_settings_panel.yml`によってレイアウトされます。タブタイプは`WORLD_SETTING`、`WORLD_DEFAULTS`、`ISLAND_DEFAULTS`です。後の2つには`[gamemode].admin.set-world-defaults`パーミッションが必要で、パーミッションがない場合は非表示になります。同じファイルで`/[admin_command] settings <player_name>`もレイアウトされます。各ワールドタブは`fallback`としてアイランドタブ（`PROTECTION`、`SETTING`）を指定しており、アイランドがある場合はそちらが表示されます。

### ワールド設定

ゲームワールド全体に適用されるワールドレベルの設定フラグを切り替えます。

### ワールドデフォルト保護

アイランド境界外（荒野のビジター用）でアクティブな保護フラグを制御します。

### アイランドデフォルト

!!! new "BentoBox 3.14.0で追加"
    **アイランドデフォルト**タブは管理者設定パネルの新しいタブで、管理者が**新しく作成されるアイランド**に適用されるデフォルトフラグ値を設定できます。

以前は、これらのデフォルト値はゲームモードの`config.yml`でのみ変更できました。現在は`/[admin_command] settings`を開いて**アイランドデフォルト**タブ（タブ3）に移動することでゲーム内で直接変更できます。

各保護フラグは現在のデフォルトランクとともにリストされており、クリックするとランクのはしごを循環します。各アイランド設定フラグは現在のデフォルトの`true`/`false`状態を表示し、クリックするとトグルします。変更は即座にワールド設定に保存され、変更後に**新しく**作成されたすべてのアイランドに影響します。既存のアイランドには影響しません。
