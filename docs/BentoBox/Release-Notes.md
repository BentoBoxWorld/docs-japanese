# BentoBox リリースノート { #bentobox-release-notes }

サーバー管理者向けの最近のBentoBoxリリースのハイライト。すべての変更については、[GitHubリリース](https://github.com/BentoBoxWorld/BentoBox/releases)を参照してください。ゲームモードとアドオンはそのページの下部で独自の変更をリストしています。

!!! note "v3.24.0 の新機能 — ブループリントの小型化、高速ペースト、招待の有効期限、アイランド外のPVP"
    **リリース:** 2026-11-22

    機能追加リリースです。互換性：Paper Minecraft 1.21.5 – 26.3、Java 25+。

    - 🔺 **ブループリントが小さくなりました。** ブループリントは空気（または水）をブロックごとに保存せず、「フィル」として1回だけ保存するようになったため、ブループリントファイルがずっと小さくなり、読み込みも速くなりました。古いブループリントはこれまでどおり読み込まれ、もう一度保存したときにだけ変換されます。[ブループリント](Blueprints.md)と[ファイル形式](Blueprint-Format.md#compact-blueprints-fill)を参照してください。
    - ⚙️ **アイランドのペーストが高速になりました。** ペーストとコピーは、1ティックに1バッチを配置する代わりに、各ティックで`island.paste-time-budget`ミリ秒（デフォルト10）のあいだ実行されるようになりました。そのため、サーバーに余裕があるときは大きなアイランドがずっと早く現れます。[ペースト速度](Blueprints.md#pasting-speed)を参照してください。
    - ⚙️ **ロックやバンされたアイランドから乗り物ごと押し戻すようになりました。** 入ることが許可されていないアイランドにボート、トロッコ、または騎乗できるモブに乗って入ろうとしたプレイヤーは、乗り物から放り出されて立ち往生するのではなく、乗り物ごと押し戻されます。ロックされたアイランドは、押し戻されたプレイヤーに境界を少しの間表示します。[ロック、バン、追放](Island-Protection,-Flags-&-Ranks.md#locks-bans-and-expels)を参照してください。
    - ⚙️🔡 **チーム招待の取り下げと有効期限。** `/island team uninvite <player>`でチーム、信頼、coopの招待を取り下げられるようになりました。また、招待はデフォルトで24時間後に期限切れになります。[チーム](About/Teams.md#what-players-can-do)を参照してください。
    - 🔡 **アイランド外のPVP。** 新しいワールド設定`PVP_OUTSIDE_ISLANDS`（デフォルトはオフ）で、アイランドがない場所でのPVPを許可できます。[ワールド設定](Island-Protection,-Flags-&-Ranks.md#what-each-world-setting-does)を参照してください。
    - 🔡 **アイランドごとのクリーパーのブロックダメージ。** 新しいアイランド設定`CREEPER_BLOCK_DAMAGE`です。管理者が表示しない限り非表示になっています。[設定タブ](Island-Protection,-Flags-&-Ranks.md#settings-tab)を参照してください。
    - **すべてのメニューでコマンドボタンと閉じるボタン。** BentoBoxでもすべてのアドオンでも、メニューテンプレートに、プレイヤーとしてコマンドを実行するボタンやメニューを閉じるボタンを置けるようになりました。[メニューのカスタマイズ](../Tutorials/generic/Customizable-GUI.md#command-and-close-buttons)を参照してください。
    - **訪問者リストのプレースホルダー。** `%[gamemode]_island_visitors_list%`と`%[gamemode]_visited_island_visitors_list%`は、アイランドを訪問しているプレイヤーの名前を返します。[プレースホルダー](Placeholders.md)を参照してください。
    - 🔡 アドオン開発者向けの**ダイアログフォーム、ページ付きパネル、値ピッカー**。[開発者ドキュメント](Developer-Documentation.md#dialog-forms)を参照してください。
    - **MythicMobsの名前を維持。** アドオンが名前を指定せずにスポーンさせたMythicMobsのモブは、MythicMobsの設定にある表示名を保つようになりました。
    - 🐛 **データコンポーネントを持つアイテム**（属性モディファイアなど）が、データベースから読み戻したときに空気に置き換えられなくなりました。
    - 🐛 **ハウスキーピングでサーバーが止まらなくなりました。** パージ対象のワールドだけを1ティックに1つずつ保存し、パージするものが無いときはメインスレッドで何もしません。
    - 🐛 **保護の修正。** 経験値瓶を投げるときは`EXPERIENCE_BOTTLE_THROWING`をチェックするようになりました。ブロックにアイテムを置くときはクリックされたブロックをチェックします。バンのチェックは、そのバンが適用されるアイランドのチームを確認します。ランク変更イベントは正しいプレイヤーと変更前のランクを示します。
    - 🐛 **`default`ブループリントバンドルが無い、または壊れている**場合は、起動時に修正すべきファイル名とともに報告されるようになりました。
    - 🐛 その他の修正：ブループリントのコピーサイズ、ペースト後にボートが沈む問題、パージ後に残るSlimefunのブロックデータ（実際のSlimefunサーバーではまだテストされていません）、古いマテリアル名`GRASS`が`SHORT_GRASS`として読み込まれるようになりました。起動時に表示される紛らわしい「Could not hook with Vault」エラーも修正されました。

    🔺 **このバージョンで保存したブループリントは古いサーバー向けではありません。** 3.24.0で保存したブループリントは古いBentoBoxでも読み込めますが、空気や水のフィルが無い状態でペーストされます。新しく保存したブループリントを、3.23.7以前を実行しているサーバーと共有しないでください。

    🔺 **チーム招待に有効期限ができました。** アップグレード時点で保留中の招待には、最初にチェックされた時点から丸ごと1回分の有効期限が与えられます。以前のように招待を無期限に有効にしておくには、`island.invite-expiry-hours`を`0`に設定してください。

    ⚙️ **設定に関する注意:** `config.yml`の`island`の下に4つの設定が追加されます。何もしなければ、それぞれデフォルト値が使われます。

    | 設定 | デフォルト | 動作 |
    | --- | --- | --- |
    | `invite-expiry-hours` | `24` | チーム、信頼、coopの招待が有効な時間（時間単位）。`0`にすると期限切れになりません。 |
    | `locked-border.show` | `true` | ロックされたアイランドから押し戻されたプレイヤーに、そのアイランドの境界を表示します。 |
    | `locked-border.color` | `RED` | その境界の色：`RED`、`GREEN`、`BLUE`のいずれか。 |
    | `paste-time-budget` | `10` | ブループリントのペーストとコピーに使う1ティックあたりのミリ秒数。アイランドの作成でラグが発生する場合は下げてください。`0`にすると従来の動作になります。 |

    🔡 **ロケールに関する注意:** uninviteコマンド、`CREEPER_BLOCK_DAMAGE`と`PVP_OUTSIDE_ISLANDS`のフラグ、値ピッカー（`panels.picker`）用の新しいキーが追加されました。これらは既存のロケールファイルに自動的に追加され、同梱のすべての言語に翻訳されています。

    [Release v3.24.0](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.24.0)

??? note "v3.23.7 の新機能 — 古いロケールファイルでのランクの色とクリックのヒント"
    **リリース:** 2026-11-11

    小規模な修正リリースです。`config.yml`とパネルテンプレートの変更はありません。互換性：Paper Minecraft 1.21.5 – 26.3、Java 25+。

    - 🔺 **保護フラグが変更できないように見えていました。** ロケールファイルがBentoBox 3.12以前で最初に書き出されたサーバーでは、保護フラグのツールチップのランクがすべて同じシアン色で表示されたため、許可・ブロック・最低ランクの区別がつかず、クリックしても何も起こらないように見えていました。古いロケールファイルでも、ランクが再び緑、赤、濃い緑で表示されます。この問題はチームメニューのランクフィルターとコマンドランクパネルにも影響していました。
    - 🔡 **9言語でクリックのヒントを復元しました。** チェコ語、ドイツ語、スペイン語、フランス語、イタリア語、日本語、ラトビア語、ポーランド語、トルコ語では、保護フラグの「左クリック / 右クリック」のヒントと、設定の「クリックで切り替え / 開く」のヒントが欠けていました。イタリア語のレイアウトと、トルコ語のブロックされたランクの行も修正されました。

    🔡 古いBentoBoxからアップグレードした場合は、**ロケールファイルを更新してください。** BentoBoxは既存のロケールテキストを上書きしないため、多くのバージョンをまたいでアップグレードしてきたサーバーには、最初にインストールしたときの文言が残っています。方法は[言語とメッセージ](About/Multilingual.md#troubleshooting)を参照してください。

    [Release v3.23.7](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.23.7)

??? note "v3.23.6 の新機能 — 常に許可するエンティティタイプとブループリント読み込みの修正"
    **リリース:** 2026-11-07

    `config.yml`の変更はありません。互換性：Paper Minecraft 1.21.5 – 26.3、Java 25+。

    - 🔡 **常に許可するエンティティタイプ（`ALLOW_MOBS`）。** 各ゲームモードの管理者設定パネルに新しいワールド設定（鉄インゴットのアイコン）が追加されました。動物やモンスターのスポーンがオフでも、ワールドとアイランドの両方でスポーンするエンティティタイプを一覧で指定します。アイアンゴーレムはデフォルトで一覧に含まれているため、村のアイアンゴーレムトラップは引き続き動作します。同じタイプが両方にある場合は、**エンティティタイプのスポーン制限**のブロックリストが優先されます。パーミッション：`[gamemode].admin.settings.ALLOW_MOBS`。[モブスポーンの優先順位](Island-Protection,-Flags-&-Ranks.md#mob-spawning-precedence)を参照してください。
    - 🔺 **「すべてのブループリントが読み込まれました」が発火しないことがありました。** 複数のゲームモードが同時にブループリントを読み込むと、BentoBoxが完了を取りこぼして準備完了状態に到達せず、アドオンの`allLoaded()`フック、準備完了を待つコマンド、`BentoBoxReadyEvent`が実行されないことがありました。関連する4つのメインスレッド／非同期の競合とあわせて修正されました。
    - 📊 **bStats:** 失敗したコマンドは、プレイヤーに表示されたロケールキーを理由として報告し、サーバー単位で集計するようになりました。新しい`worldSize`チャートは、アイランドワールドのディスク上のサイズを範囲で報告します。
    - 新しいコアワールド設定ストアが初回起動時に出力していた誤った`File not found`ログを修正しました。

    🔺 **アイアンゴーレムトラップ:** ゴーレムを止めるために動物のスポーンをオフにしていた場合、ゴーレムは再びスポーンするようになります。以前の動作に戻すには、「常に許可するエンティティタイプ」からアイアンゴーレムを外してください。

    🔺 **新しいデータストア:** 許可リストはゲームモードの`config.yml`ではなく、BentoBoxがゲームモードごとに保存します — フラットファイルでは`plugins/BentoBox/database/CoreWorldSettings/<GameMode>.json`、SQL/Mongoでは`WorldSettings`テーブルです。

    🔡 **ロケールに関する注意:** `protection.flags.ALLOW_MOBS`の下に新しいキー（`name`、`description`、`always`、`flags`）が追加されました。これらがないカスタムロケールファイルではキー名が表示されます。

    [Release v3.23.6](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.23.6)

??? note "v3.23.5 の新機能 — Sulfur Cube の TNT 保護と`/island go`のアンダースコア"
    **リリース:** 2026-10-31

    バグ修正リリースです。`config.yml`、ロケール、またはパネルテンプレートの変更はありません。互換性：Paper Minecraft 1.21.5 – 26.3、Java 25+。

    - 🔺 **Sulfur Cube の爆発が TNT フラグに従うようになりました。** TNT を吸収した Sulfur Cube は、着火した TNT ではなく Sulfur Cube 自身として爆発していたため、`TNT_DAMAGE`のチェックを受けず、TNT ダメージをオフにしたアイランドでも建築物を破壊できていました。現在は、ブロックとエンティティへのダメージの両方について、アイランド上では`TNT_DAMAGE`、アイランド外では`WORLD_TNT_DAMAGE`に従います。プレイヤーが火打石と打ち金やファイヤーチャージで Sulfur Cube に着火した場合は、TNT ブロックと同様に`TNT_PRIMING`でチェックされます。レッドストーン、ディスペンサー、他の爆発による着火にはプレイヤーがいないため`TNT_PRIMING`は適用できませんが、爆発自体は引き続き`TNT_DAMAGE`に従います。Minecraft 26.2 より古いサーバーには Sulfur Cube が存在しないため、何も変わりません。
    - 🐛 **`/island go`がアンダースコアをスペースとして扱うようになりました。** `/island go happy_place`で`Happy Place`という名前のホームが見つかります。完全一致が引き続き優先され、複数の行き先に一致する名前は推測せずに拒否されます。[正しいホームを見つける](About/IslandManagement.md#homes)を参照してください。

    **AOneBlock に関する注意:** AOneBlock はデフォルトで`TNT_DAMAGE: true`のため、`false`に設定しない限り、Sulfur Cube の爆発は引き続きダメージを与えます。

    [Release v3.23.5](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.23.5)

??? note "v3.23.4 の新機能 — 安全なエンド到着とパネル内でのインベントリ使用"
    **リリース:** 2026-10-17

    バグ修正リリースです。`config.yml`、ロケール、またはパネルテンプレートの変更はありません。互換性：Paper Minecraft 1.21.5 – 26.3、Java 25+。

    - 🐛 **エンドポータルがプレイヤーをボイドに落とさなくなりました。** `create-obsidian-platform: false`の場合、床があるかどうかに関わらずプレイヤーはポータルの目的地に直接送信されていました。安全でないエンド到着は最も近い安全なスポット、次に最も高いブロック、次にポッドに移動するようになりました。プレイヤーがポータルに立っている間のリピートポータルイベントはキャンセルされるため、バニラのエンドスポーンに送信されません。すでに安全な到着は引き続き瞬間移動し、プラットフォームがオンのときは何も変わりません。セーフスポットポッドはプレイヤーをブロックの中央に配置するようになりました。
    - ✨ **パネルを開きながら独自のインベントリを使用します。** プレイヤーは、`/island settings`などのBentoBoxパネルを開いている間、独自のインベントリのアイテムをピックアップ、配置、スワップ、ドロップ（Q / Ctrl+Q）し、バンドルを使用できます。Shift クリック、ダブルクリック収集、パネルスロットに触れるドラッグはブロックされたままなので、アイテムはパネルに入りません。
    - 🧩 **アドオン API:** `PanelListener`には新しいデフォルトメソッド`allowsPlayerInventoryClicks()`があり、`false`を返すため、リスナー（ChallengesやBiomesのアイコンピッカーなど）を持つパネルは以前と同じように動作します。`true`を返してオプトインします。[テンプレート駆動型パネル](../Tutorials/api/Templated-Panel.md#listener-method)を参照してください。`Addon.getConfig()`は、アドオンに`config.yml`がないときに`null`の代わりに空の設定を返すようになったため、`saveConfig()`は例外をスローしなくなりました。

    [Release v3.23.4](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.23.4)

??? note "v3.23.3 の新機能 — Obsidian スクープ複製バグ修正とコマンドランクパネル"
    **リリース:** 2026-10-03

    バグ修正とパネルのリリースです。`config.yml`とロケールの変更なし。互換性：Paper Minecraft 1.21.5 – 26.3、Java 25+。

    - 🐛 **Obsidian スクープ複製バグが修正されました。** OBSIDIAN_SCOOPINGでは、クリックの1ティック後に溶岩が配布され、再チェックなしでそのティックで黒曜石をマイニングすると、黒曜石と溶岩の両方が得られていました。またバケットから溶岩を移動させるとバケットなしで溶岩が得られていました。両方とも最初に再チェックされるようになりました。**OBSIDIAN_SCOOPINGが有効なすべてのサーバーでアップデートをお勧めします。**
    - ⚙️ **カスタマイズ可能なコマンドランクパネル。** 新しい`panels/command_ranks_panel.yml`（初回起動時に書き込み、ゲームモード独自のコピーが優先）でレイアウトされ、`COMMAND`、`NEXT`、`PREVIOUS`ボタンがあります。これで45個のコマンドでページングされるようになります — 旧パネルは49番目のコマンド以降をすべてサイレントにドロップしていました。[コマンドランクパネルのカスタマイズ](Island-Protection,-Flags-&-Ranks.md#customizing-the-command-ranks-panel)を参照してください。
    - ✨ **設定パネルの改善。** `/island settings`は、プレイヤーが最後に選択した基本/詳細/エキスパートモードで開き、保護と設定タブは1つのモード（管理パネルは引き続きエキスパートで開く）を共有します。コマンドランクは、プレイヤーが権限を持たないサブコマンドを隠します（ops はすべてを見ます）。ブレイクスポナーアイコンはバニラのスポーン卵ツールチップを表示しなくなります。
    - 🐛 **Multiverse `auto-load`が尊重されるようになりました。** 3.22.0以降、Multiverseフックは起動のたびにすべてのBentoBoxワールドの`auto-load: false`をリセットしていました。BentoBoxが最初にワールドをインポートするときのみ設定されるようになり、既存のMultiverseエントリは設定されたままになります。
    - 🧩 **アドオン API：** 管理者の`deaths set|add|remove|reset`コマンドは`PlayerDeathsChangedEvent`（ワールド、プレイヤー、アクション、数量、古い値と新しい値）を発火し、Levelが管理者の変更に従うことができます。自然な死には発火しません。

    [Release v3.23.3](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.23.3)
