# 同時アイランド

BentoBox 2.0.0以降では、管理者がプレイヤーにワールドあたり複数のアイランドを持つことを許可できます。このページでは仕組みと許可する際のいくつかの注意点について説明します。

## 有効にする方法

デフォルトでは、プレイヤーは1つのアイランドを持ちます。BentoBoxの`config.yml`の`island.concurrent-islands`設定でグローバルに数を増やすことができます。この値は個々のゲームモードのconfig設定でこの設定が提供されている場合に上書きされることがあります。

## 使い方

### 作成

プレイヤーが複数のアイランドを作成できる場合、`create`コマンドを使用できます。例：

`/island create`

これは通常のアイランド作成と同じように動作し、プレイヤーは通常アイランドが作成された後にテレポートされます。

### アイランドへの移動

プレイヤーが複数のアイランドを持つ場合、`go`コマンドを使ってそれらの間をテレポートできます。例：

`/island go`

このコマンドは、プレイヤーが設定した名前付きホームとプレイヤーが持つアイランドの名前を表示します。プレイヤーが`setname`コマンドでアイランドに名前を付けた場合はリストに表示されますが、名前を付けていない場合はデフォルトのアイランド名の後に番号が付いてリスト表示されます（例：「tastybento's island 2」）。アイランドの番号はサーバーが再起動すると変わる可能性があるため、プレイヤーにはアイランドに名前を付けることを勧めてください。

### ホームの設定

プレイヤーは`sethome`コマンドを実行することでアイランドのデフォルト位置を設定できます。プレイヤーが複数のホームを設定できる場合は、`sethome [home name]`コマンドで設定できます。ゲームワールドのconfigで許可されている最大ホーム数は、プレイヤーが所有するすべてのアイランドで共有されます。

### アイランドの移転

アイランドの所有権はチームの他のプレイヤーに`setowner`コマンドで移転できます。オーナーが既に許可された同時アイランドの最大数を持っている場合、所有権の移転はできません。

*新機能：* プレイヤーが所有権を移転するとチームから自動的に離脱するようになりました。

### チーム

- チームはアイランドベースであり、チームは複数のアイランドにまたがりません。
- BentoBox 2.3.0以降では、チームメンバーが独自のアイランドを持てるようにする設定があり、プレイヤーは異なるアイランド上の複数のチームのメンバーになれます。

## ゲームモードのサポート

すべてのゲームモードが同時アイランドをサポートする必要があります。
