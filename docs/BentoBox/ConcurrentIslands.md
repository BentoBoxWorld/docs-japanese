# 同時アイランド

BentoBox 2.0.0以降では、管理者がプレイヤーにワールドあたり複数のアイランドを持つことを許可できます。このページでは仕組みと許可する際のいくつかの注意点について説明します。

## 有効にする方法

デフォルトでは、プレイヤーは1つのアイランドを持ちます。BentoBoxの`config.yml`の`island.concurrent-islands`設定でグローバルに数を増やすことができます。この値は個々のゲームモードのconfig設定でこの設定が提供されている場合に上書きされることがあります。

## 使い方

### 作成

プレイヤーが複数のアイランドを作成できる場合、`create`コマンドを使用できます。例：

`/island create`

これは通常のアイランド作成と同じように動作し、プレイヤーは通常アイランドが作成された後にテレポートされます。

### アイランドへの移動

プレイヤーが複数のアイランドを持つ場合、`go`コマンドを使ってそれらの間をテレポートできます。例：

`/island go`

このコマンドは、プレイヤーが設定した名前付きホームとプレイヤーが持つアイランドの名前を表示します。プレイヤーが`setname`コマンドでアイランドに名前を付けた場合はリストに表示されますが、名前を付けていない場合はデフォルトのアイランド名の後に番号が付いてリスト表示されます（例：「tastybento's island 2」）。アイランドの番号はサーバーが再起動すると変わる可能性があるため、プレイヤーにはアイランドに名前を付けることを勧めてください。

### ホームの設定

プレイヤーは`sethome`コマンドを実行することでアイランドのデフォルト位置を設定できます。プレイヤーが複数のホームを設定できる場合は、`sethome [home name]`コマンドで設定できます。ゲームワールドのconfigで許可されている最大ホーム数は、プレイヤーが所有するすべてのアイランドで共有されます。

### アイランドの移転

アイランドの所有権はチームの他のプレイヤーに`setowner`コマンドで移転できます。受取人が既に許可された同時アイランドの最大数に達している場合、所有権の移転はできません。

BentoBox 3.16.0以降、この上限は`/island team setowner`と`/[admin] team setowner`の両方で強制されます。以前のバージョンでは管理者による移転後に警告を出すだけ（プレイヤーコマンドにはチェックがまったくありませんでした）で、プレイヤーが`concurrent-islands`の上限を超えて押し込まれる可能性がありました。受取人により多くのアイランドを許可するには、まず`[gamemode].island.number.<n>`権限を引き上げてください。

*新機能：* プレイヤーが所有権を移転するとチームから自動的に離脱するようになりました。

#### コンソールからの移転（管理者）

ゲーム内で実行する場合、`/[gamemode] admin team setowner <player>` は管理者が**立っている**アイランドを移転し、確認を求めます。

BentoBox 3.18.0以降では、アイランドの現在のオーナーを指定することもできます：

`/[gamemode] admin team setowner <newOwner> <islandOwner>`

このようにアイランドを指定すると、管理者はそのアイランド上に立っている必要がなくなるため、コマンドは**サーバーコンソール**から——したがってSkriptのような自動化から——実行できます。コンソールから実行した場合、コンソールは確認に応答できないため、確認プロンプトはスキップされます。

- `<newOwner>` — 新しいオーナーになるプレイヤー。オンラインである必要も、どこかに立っている必要も**ありません**。BentoBoxがすでに認識しているプレイヤー（または生のUUID）であれば機能します。
- `<islandOwner>` — 現在のオーナーで、**どの**アイランドを移転するかを特定するためだけに使用します。コマンドはそのプレイヤーが実際に所有するアイランドを移転します。そのプレイヤーのアクティブなアイランドが他人に属するチームアイランドである場合、移転は拒否されます。複数のアイランドを所有している場合は、その**プライマリ／アクティブ**なアイランドが使用されます。

同時アイランドの上限は引き続き適用されます：`<newOwner>`がすでにアイランドの最大数に達している場合、移転は拒否され、まずそのプレイヤーの`[gamemode].island.number.<n>`権限（またはワールドの`concurrent-islands`設定）を引き上げる必要があります。ゲーム内の形式と同様に、以前のオーナーはアイランドから削除されるのではなく、メンバーに降格されます。

### チーム

- チームはアイランドベースであり、チームは複数のアイランドにまたがりません。
- BentoBox 2.3.0以降では、チームメンバーが独自のアイランドを持てるようにする設定があり、プレイヤーは異なるアイランド上の複数のチームのメンバーになれます。

## ゲームモードのサポート

すべてのゲームモードが同時アイランドをサポートする必要があります。
