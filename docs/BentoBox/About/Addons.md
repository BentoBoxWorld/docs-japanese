# アドオン

BentoBox自体では何もしません。それはプラットフォームです。**アドオン**がそれを機能させるものです。2種類のアドオンがあります：

- **ゲームモードアドオン** — プレイヤーがプレイする実際のゲームワールドを作成します（Skyblock、CaveBlockなど）
- **フィーチャーアドオン** — 任意のゲームモードの上にオプションの追加機能を加えます

どのアドオンをインストールするかを正確に選択できるため、希望通りのサーバー体験を構築できます。

!!! info "アドオンはどこに置きますか？"
    アドオンはサーバーの`plugins/`フォルダには**置きません**。以下に置きます：
    ```
    plugins/BentoBox/addons/
    ```
    そこに配置してサーバーを再起動すると、自動的に設定ファイルが生成されます。

## ゲームモードアドオン

プレイヤーが実際にプレイするワールドを作成します。少なくとも1つインストールしてください。

| アドオン | 説明 |
|---|---|
| **BSkyBlock** | クラシックSkyblock — 空に浮かぶ島 |
| **AOneBlock** | 1つの魔法の再生ブロックからスタート |
| **ChunkBlock** | 壁に囲まれたチャンク内の1ブロック — アイランドレベルを使用して追加領土を獲得（Levelが必要） |
| **AcidIsland** | 海が酸のSkyblock |
| **CaveBlock** | 固い地下世界でのサバイバル |
| **SkyGrid** | 虚空に散らばった単一ブロック |
| **Boxed** | アドバンスメントを達成すると成長するボックス |
| **Poseidon** | 水中サバイバル |
| **StrangerRealms** | 危険なミラー次元でのサバイバル |
| **TradeWinds** | 果てしない外洋のNPC貿易港での海上交易（Vaultが必要） |

詳細な説明は[ゲームモード](GameModes.md)をご覧いただくか、[比較](../../gamemodes/Comparison.md)して選択にお役立てください。

## フィーチャーアドオン

任意のゲームモードで機能するオプションの機能を追加します。サーバーに合ったものを組み合わせてください。

### ほとんどのサーバーに必須

| アドオン | 追加する機能 |
|---|---|
| **Level** | 設置されたブロックに基づくアイランドスコアを計算します。プレイヤーが競えるリーダーボードを含みます。 |
| **Challenges** | プレイヤーが達成できるタスクリストとその報酬。プレイヤーの継続的な参加を促進するのに最適です。 |
| **Warps** | プレイヤーがアイランドにワープサインを設置し、他のプレイヤーが中央メニューからテレポートできます。 |
| **InvSwitcher** | 同じサーバー上の異なるゲームモード間でプレイヤーのインベントリ、経験値、体力を分離します。複数のゲームモードを実行する場合は強く推奨します。 |

### 利便性向上

| アドオン | 追加する機能 |
|---|---|
| **IslandFly** | プレイヤーが自分のアイランドで飛行できます。 |
| **Visit** | プレイヤーがワープサインなしでメニューからお互いのアイランドを訪問できます。 |
| **Border** | プレイヤーのアイランド保護エリア周辺に視覚的な境界を表示します。 |
| **Chat** | チームメンバーが非公開で話せるアイランド専用チャットチャンネルを追加します。 |
| **Bank** | 各アイランドに共有バンクアカウントを提供します。プレイヤーが一緒にお金をプールできます。 |
| **CheckMeOut** | プレイヤーが管理者レビューやコミュニティ投票のためにアイランドを提出できます。 |

### 上級者向け / 競争

| アドオン | 追加する機能 |
|---|---|
| **Biomes** | プレイヤーがアイランドのバイオームを変更できます。 |
| **Greenhouses** | プレイヤーがガラスの温室構造を建設して内部の特定のバイオームをシミュレートできます。 |
| **Limits** | 管理者がアイランド上で各ブロックやモブをプレイヤーが持てる上限を設定できます。 |
| **MagicCobblestoneGenerator** | 丸石ジェネレーターを設定された確率で異なるブロック（鉱石、素材）を生成するよう設定できます。 |
| **Upgrades** | プレイヤーがリソースを消費してアイランドのサイズやモブのスポーンなどをアップグレードします。 |
| **TopBlock** | アイランド上に設置された最も高い単一ブロックに基づくリーダーボード。 |
| **TwerkingForTrees** | プレイヤーがダンス（繰り返ししゃがむ）することで苗木を即座に成長させられる楽しいメカニクス。 |

### ユーティリティ / 管理

| アドオン | 追加する機能 |
|---|---|
| **VoidPortals** | プレイヤーが虚空に落ちることでネザーやエンドに移動できます。 |
| **DimensionalTrees** | 特定のディメンションで育てた木が特別なドロップを生み出します。 |
| **ExtraMobs** | 追加のモブ関連チャレンジとインタラクションを追加します。 |
| **FarmersDance** | プレイヤーが近くでダンスすることで作物を成長させられます。 |
| **ControlPanel** | 管理者がBentoBoxを管理するためのGUIコントロールパネルを提供します。 |
| **CauldronWitchery** | プレイヤーが効果やアイテムのためにカルドロンを使って特別なブリューを作れます。 |

## アドオンの検索とダウンロード

公式アドオンはBentoBoxWorldチームによってメンテナンスされており、以下で見つけられます：

**[github.com/BentoBoxWorld](https://github.com/BentoBoxWorld)**

各アドオンのリポジトリの**Releases**タブから`.jar`ファイルをダウンロードしてください。開発（テストなし）ビルドは[CodeMC CIサーバー](https://ci.codemc.io/job/BentoBoxWorld/)から入手できます。

!!! warning "バージョン互換性"
    各アドオンはサポートするBentoBoxのバージョンをリスト化しています。ダウンロード前に必ず確認してください。間違ったバージョンのBentoBoxでアドオンを使用すると、サーバーが正常に起動できなくなる場合があります。

---

## インストール済みのものを確認する

ゲーム内で以下を実行してください：
```
/bentobox version
```
これによりBentoBoxのバージョンと現在ロードされているすべてのアドオンとそのバージョンがリスト表示されます。バグを報告したり、サポートを求める際には必ずこの出力を含めてください。
