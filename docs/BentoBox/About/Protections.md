# 保護
BentoBoxはアイランドゲームモード用の完全な機能を持つワールドおよびアイランド保護システムを提供します。設定はゲーム内の管理者またはプレイヤー設定から行われ、パーミッションとconfigファイルからもゲーム外で設定できます。

## 保護とは何ですか？
マルチプレイヤーMinecraftは、スポーン周辺のエリアを除いてマップの組み込み保護は提供しません。その結果、ランダムなプレイヤーが時間をかけて作った他のプレイヤーのエリアにダメージを与えたり「グリーフ」したりすることができます。BentoBoxを使うと、プレイヤーは自分のアイランドを持ち、保護システムによって他のプレイヤーがこのスペースでできることが防止または制限されます。

保護は実行できるコマンドの制限にも及びます。例えば、管理者はプレイヤーが落下中にテレポートコマンドを実行して落下ダメージを不正に回避するのを防ぐことができます。

### WorldGuardについて
WorldGuardは保護機能を提供する保護プラグインです。BentoBoxはWorldGuardを使用せず、衝突を避けるためにBentoBoxワールドではWorldGuardをオフにすることを推奨します。管理者はBentoBoxワールドでWorldGuardを使用することもできますが、2つのシステム間で衝突が発生する可能性を考慮する必要があります。

## BentoBoxでの保護の管理
BentoBoxは「フラグ」の概念を使って保護設定を管理します。フラグには3種類あります：

 1. **保護フラグ** - ワールドまたはアイランド保護のある側面を許可または拒否するために明示的に設計されています。
 2. **設定フラグ** - 一般的にtrue/falseまたはオン/オフの設定で適用できます。保護を提供する場合があります。
 3. **ワールド設定フラグ** - ゲームワールド全般での動作を決定する設定フラグです。

### 保護されているエリア
BentoBoxには2つの保護エリアがあります：

 1. プレイヤーのアイランド
 2. それ以外のすべての場所（ワールドの残り）

これらのエリアは一般的に独立して処理されますが、特定のワールド設定がプレイヤーのアイランドに適用される場合があります。アイランドオーナーは一般的に自分のアイランドの設定を行えますが、管理者はそれ以外のすべての設定を行います。管理者はゲームモードの`config.yml`を調整することで、アイランドのデフォルト設定も決定できます。

プレイヤーのアイランド保護エリアはゲームモードの`config.yml`でデフォルトが設定され、管理者コマンドまたはプレイヤーがパーミッションを持つことでゲーム内で拡大または縮小できます。最大保護サイズもゲームモードの`config.yml`で設定されるアイランド間の距離によって決まります。

### 設定の変更
BentoBoxはアイランドオーナーにアイランド設定GUIを提供し、アイランドの設定を確認できます。管理者は管理者設定GUIを通じて表示されるアイランドの設定を制限できます。管理者はプレイヤーがパーミッションを通じて設定を変更できるようにできます。デフォルトではプレイヤーは見えるすべての設定を変更できます。

## 提供される保護
保護フラグは多数あり、定期的に新しいものが追加されます。保護はランクによって制限でき、メンバーにはできないことをトラストされたプレイヤーに許可できます：

 - ビジター
 - コープ
 - トラスト
 - メンバー
 - サブオーナー

オーナーは常にすべてを行えます。

プレイヤーが保護されたエリアで何かをしようとするたびに、BentoBoxはそれを行う権利があるかどうかを確認します。権利がない場合はブロックされ、理由が伝えられます。

### 何かができるまたはできない理由を調べる方法
BentoBoxは管理者診断ツール`why <player>`コマンドを提供します。例：`/bsb why tastybento`。アクティブな場合、サーバーコンソールはそのプレイヤーが行うすべてのアクションの理由をログに記録します（許可またはブロック、どのフラグが原因か）。これにより設定ミスの特定が容易になります。

`why`コマンドがプレイヤーが何かを*できる*と表示しているにもかかわらず、ゲーム内ではできない場合、それは別のプラグインまたはサーバー自体がアクションをブロックしていることを示しており、BentoBoxではありません。

### 保護されているもの

- ブロックのブレイクと設置
- ブロックインタラクション：コンテナ、溶鉱炉、作業台、エンチャントテーブル、アンビル、醸造台、カルドロン、樽、巣箱、コンポスター、ジュークボックス、音符ブロック、レバー、ボタン、ドア、トラップドア、ベッド、ビーコン、ドラゴンエッグ、アイテムフレーム、ゲート、ケーキ、ベリーブッシュ
- レッドストーン関連ブロック
- 動物の繁殖
- バケツの使用
- 染料、卵、エリトラの使用
- 乗り物：ボート、トロッコ、騎乗可能な動物
- 村人との取引
- ネームタグの使用
- アイテム/経験値の拾得とアイテムのドロップ
- 火：着火、延焼、燃焼、落雷
- モブと動物へのダメージまたは殺傷
- リード台座の使用
- ポータルの使用
- 羊毛の刈り取り
- テレポート（コーラスフルーツ、エンダーパール）
- ポーションを含むアイテムの投擲
- TNTやその他の爆発ダメージ

## アイランドオーナーが変更できる設定

アイランドオーナーは`/island settings`で設定GUIを開きます。管理者は特定の設定をプレイヤーから非表示にして、中央で管理することができます。

| 設定 | 機能 |
|---|---|
| **PVP（プレイヤー対プレイヤー）** | プレイヤーがそのアイランドで互いに攻撃できるかどうか。デフォルトではオフ。 |
| **葉の朽ち** | 丸太が取り除かれた際に葉ブロックが自然に朽ちるかどうか。 |
| **モブのスポーン** | スポーナーブロックからを含め、アイランド上でモンスターや動物がスポーンできるかどうか。 |

### アイランド外でワールドのルールを確認する { #viewing-the-world-rules-off-island }

BentoBox 3.22.0 以降、`/island settings`はプレイヤーがアイランド上に立っておらず、アイランドを所有してもいない場合 — 未開の地にいる場合や、そもそもプレイヤーがアイランドを所有しないゲームモードの場合 — でも動作するようになりました。

その場合、パネルは読み取り専用の**ワールド保護**タブ 1 つだけを表示し、各保護フラグがそのワールドで有効か無効かを一覧します。これはアイランド外のプレイヤーを実際に支配しているものです。足元にアイランドがなければ、保護フラグはランクではなくワールドのオン/オフスイッチで解決されます。クリックできる項目はなく、設定するアイランドが存在しないためアイランド設定タブは表示されません。

アイランド上にいる、またはアイランドを所有しているプレイヤーには、これまでとまったく同じパネルが表示されます。

## 管理者がコントロールするワールド設定

これらの設定はゲームモードワールド全体に適用されます。管理者のみが`/[admin_command] settings`から変更できます。プレイヤーはサーバーのルールを理解するために読み取り専用モードで（変更はできませんが）確認できます。

| 設定 | 機能 | デフォルト |
|---|---|---|
| **チェストの爆発ダメージ** | 爆発（クリーパー、TNT、ウィザー、ガスト）によるチェストの破壊を保護します。グリーフを防ぎますが、チェストを使って爆発防止部屋を作ることができます。 | オン |
| **スーパーフラットのクリーン** | ワールドジェネレーターが停止すると、新しいチャンクがフラットな草として生成されます。この設定はそれらのチャンクを検出して修復します。この問題がある場合を除いてオフにしてください。リソースが集約的です。 | オフ |
| **荒い土の耕作** | プレイヤーがクワを使って荒い土を通常の土に変換することを防ぎます。ほとんどのゲームモードで土は貴重ですが、砂利が簡単に入手できる場合、荒い土の耕作を悪用してそれを安価に生成できます。 | オフ（防止オン） |
| **クリーパーの爆発** | クリーパーの爆発によるアイランドブロックへのダメージを防ぎます。クリーパーはアイランド破壊の最も一般的な原因です。これを防ぐとゲームが簡単になりますが、管理者のサポート負担が軽減されます。 | オン |
| **クリーパービジター点火** | 他人のアイランドでビジターがクリーパーをプライムするためにフリント&鋼を使用することを防ぎます。これはよくあるグリーフ方法です。 | オン |
| **エンダーチェスト** | ゲームモードのワールド間でアイテムを密輸できるエンダーチェストへのアクセスと作成をブロックします。ワールド別エンダーチェストプラグインを使用する場合は無効にしてください。 | オン（ブロック） |
| **エンダーマンのブロック盗難** | エンダーマンがアイランドからブロックを拾うことを防ぎます。これがないと、プレイヤーが自分では取り除いていないブロックを失うことになります。 | オン |
| **モブの地理的制限** | 特定のモブ（例：ウィザー、飛行モブ）がスポーンしたアイランドを離れるのを防ぎます。境界を越えると削除されます。 | オン |
| **ビジター保護** | ビジターを他のプレイヤーのアイランドでほとんどの種類のダメージから保護します。ビジターが虚空に落ちた場合も安全な場所にテレポートします。 | オン |
| **アイテムフレーム保護** | 非メンバーによるアイテムフレームの破壊やアイテムのノックアウトを防ぎます。 | オン |
| **グローバルモブスポーン** | ワールド内どこでもスポーンできるモブタイプを設定し、他のすべてのスポーン設定を上書きします。例：ファントムをサーバー全体で無効化します。 | 様々 |
| **アイランド外の液体フロー** | 溶岩と水がアイランド保護境界を越えて流れるのを停止し、アイランド間の丸石形成や洪水を防ぎます。 | オン |
| **アイランド外のモブスポーン** | アイランド間のエリアでモブがスポーンするのを防ぎ、スポーンをアイランドゾーン内に集中させます。AcidIslandでは不自然に見えるため推奨しません。 | オフ |
| **黒曜石のすくい取り** | 孤立した1つの黒曜石ブロックを空のバケツで右クリックして溶岩を回収できます。丸石ジェネレーターのセットアップ中に誤って黒曜石を作った新しいプレイヤーを助けます。 | オン |
| **オフライン植物成長** | ビジターがチャンクをロードしていても、チームメンバーがオンラインでないときにアイランドで作物や植物が育つのを停止します。 | オフ |
| **オフラインレッドストーン** | チームメンバーがオンラインでないときにアイランドのレッドストーン回路を無効にします。 | オフ |
| **境界外ピストン** | ピストンがアイランドの保護境界を越えてブロックを押し出すのを停止します。隣接するアイランドへのグリーフの一般的な悪用手段です。 | オン |
| **テレポート時のモブ削除** | プレイヤーがアイランドホームにテレポートする際に周囲の敵対モブをクリアし、到着時の不意打ちによる死を防ぎます。 | オン |
| **スポーナータイプ保護** | プレイヤーがスポーンエッグを使ってスポーナーブロックのモブタイプを変更するのを防ぎます。スポーナーが報酬として与えられる場合に便利です。 | オン |
| **木の成長境界** | 木がアイランドの保護境界を越えて成長するのを防ぎます。これがないと、木が他のアイランドに侵入したり、届かないブロックが作られたりすることがあります。 | オン |
| **ウィザーダメージ** | ウィザーがアイランド上および間で引き起こす破壊を制限します。 | オン |
