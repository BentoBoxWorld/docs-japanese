# ブループリント（カスタムスターターアイランド）

プレイヤーが新しいアイランドを作成する際、BentoBoxは事前に構築されたスターターアイランドをペーストします。これらのテンプレートを**ブループリント**と呼びます。デフォルトでは各ゲームモードに基本的なスターターアイランドが付属していますが、自分でデザインすることもできます。

## なぜスターターアイランドをカスタマイズするのですか？

- サーバーに独自の外観と雰囲気を与える
- プレイヤーがどのリソースから始めるかを正確にコントロールする
- 複数の難易度ティア（簡単スターター、難しいスターター）を作成してプレイヤーが選べるようにする
- 新しいプレイヤーへの歓迎サインとヒントを追加する

## 簡単な仕組み

ブループリントはゲーム内でのみ作成されます。基本的なプロセスは：

1. プレイヤーにスタートさせたいアイランドをワールドのどこかに建設します。
2. 管理者ブループリントコマンドを使用してエリアを選択し、コピーして保存します。
3. ブループリントマネージャーGUIを使用して**バンドル**（名前付きスターターアイランドセット）に割り当てます。
4. プレイヤーが新しいアイランドを作成する際に利用可能なバンドルが表示され、選択できます。

同じバンドル内でオーバーワールド、ネザー、エンド用の異なるブループリントを持てます。

!!! tip
    スターターアイランドは小さくしておきましょう。Skyblock系ゲームの楽しさは成長するための努力にあります。最初からリソースが多すぎると課題が失われます。

## ブループリントマネージャー

ブループリントマネージャーはゲーム内GUIで、以下で開きます：
```
/[admin_command] blueprint
```

ここから新しいバンドルを作成し、ブループリントを割り当て、アイコンを設定し、説明を追加し、特定のバンドルにパーミッション要件を設定できます（例：VIPスターターアイランド）。

## パフォーマンス

ブループリントのペーストは非同期で行われます。ブループリントがどんなに大きくてもサーバーがフリーズすることはありません。アイランド作成中にラグが気になる場合は、BentoBoxの`config.yml`の`paste-speed`設定を下げてください。
