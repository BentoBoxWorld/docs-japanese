# 管理者ツール

BentoBoxはサーバー管理者にゲームの管理、問題の調査、スムーズな運営のためのさまざまなツールを提供します。ファイルを手動で編集する必要はありません。

## 管理パネル

メインの管理ハブは**管理パネル**で、以下で開きます：
```
/bentobox manage
```
（エイリアス：`/bbox manage`）

ここから実行中のすべてのゲームモード、アクティブなアイランド、基本的なサーバーの状態を一目で確認できます。

## `/bentobox`コマンド

すべての最上位BentoBox管理は`/bentobox`（エイリアス：`/bbox`）を通じて行われます：

| コマンド | 機能 |
|---|---|
| `/bentobox version` | BentoBoxのバージョンとロードされているすべてのアドオンを表示します。**バグを報告する際は必ずこれを含めてください。** |
| `/bentobox manage` | 管理パネルGUIを開きます |
| `/bentobox reload` | サーバーの完全な再起動なしにBentoBoxの設定ファイルとロケールをリロードします |
| `/bentobox catalog` | アドオンカタログを開きます |
| `/bentobox perms` | BentoBoxとすべてのアドオンの有効なパーミッションを表示します |
| `/bentobox rank` | カスタムランクのリスト表示、追加、削除を行います |

## ゲームモードごとの管理者コマンド { #per-game-mode-admin-commands }

各ゲームモードには独自の管理者コマンドがあります。BSkyBlockでは`/bsb`、AcidIslandでは`/acid admin`などです。これらはそのゲームモードに特有のコントロールを提供します：

| コマンド | 機能 |
|---|---|
| `/[admin] info <player>` | プレイヤーのアイランドの詳細情報を表示します。*(3.22.4)* プレイヤーがワールド内に複数のアイランド（自分のものとチームのもの）を持っている場合、すべてのアイランドが各アイランドの名前付きで一覧表示されます |
| `/[admin] info <player> [island name]` | *(3.22.4)* 指定されたアイランドのみを表示します。アイランド名とホーム名を受け入れ、寛容にマッチし（大文字小文字を区別せず、一意なプレフィックス）、タブ補完対応。不明な名前は有効な名前のリストを表示します |
| `/[admin] delete <player>` | プレイヤーのアイランドを削除します |
| `/[admin] delete` | *(3.19.0)* プレイヤー引数なしで、あなたが**立っている**アイランドをソフト削除します（チームがまだある場合は拒否されます） |
| `/[admin] undelete` | *(3.19.0)* あなたが**立っている**アイランドの削除待ち状態をクリアし、リージョンファイルが消去される前に所有されていない状態にします |
| `/[admin] register <player>` | 所有されていないアイランドをプレイヤーに登録します。削除待ち中のアイランドでは確認プロンプトを表示し、拒否の代わりに削除をキャンセルします |
| `/[admin] setrank <player> <rank> [island owner | x,y,z]` | *(3.23.0)* チームメンバーのランクを設定します。コンソールから機能します。ランクはキーワード（`member`、`sub-owner`、`trusted`、`coop`、またはアドオンランク（`ranks.`プレフィックス除外））、翻訳されたランク名、またはその番号で指定でき、大文字小文字を区別しません。不明なランクは有効なランクのリストを表示します。アイランド引数がない場合、プレイヤーが**メンバー**であるアイランドで動作します（所有しているものではなく）。所有者を降格させることはできません。島の所有者の名前を指定するか、その中心を`x,y,z`として指定して、特定のアイランドを選択します。`owner`、`mod`、`admin`ランクは拒否されます — 所有権を移譲するには`team setowner`を使用してください |
| `/[admin] setrange <player> <range>` | プレイヤーのアイランド保護範囲を変更します |
| `/[admin] range removebonus <player> [id]` | 単一アイランドからすべてのボーナス保護範囲を削除するか、特定のIDのもののみを削除します |
| `/[admin] range purgebonus <id>` | ボーナス範囲IDを世界のすべてのアイランドから削除します — ボーナス範囲を付与したアドオンをアンインストール後に理想的です。スキャンは非同期に実行されるため大規模サーバーをフリーズさせません |
| `/[admin] settings` | 管理者向けワールド設定パネルを開きます |
| `/[admin] settings <player>` | 特定のプレイヤーのアイランド設定パネルを開きます |
| `/[admin] why <player>` | プレイヤーが何かできる/できない理由の追跡を開始します（下記参照） |
| `/[admin] reload` | ゲームモードの設定をリロードします |
| `/[admin] blueprint` | ブループリントマネージャーGUIを開きます |

正確な管理者コマンドのプレフィックスはゲームモードの設定によって異なります。詳細はゲームモードのドキュメントを確認してください。

## 「Why」診断ツール

最も便利な管理者ツールの1つが`why`コマンドです。プレイヤーがアイランドで何かできない（またはできてはいけないことができる）と報告した場合は：

```
/[admin_command] why <player>
```

その後、サーバーコンソールはそのプレイヤーが行うすべてのアクションの理由をログに記録します。許可されたかブロックされたか、どの保護フラグが原因かが記録されます。これにより推測なしに設定ミスのパーミッションを診断できます。

追跡を停止するには、コマンドを再度実行してください。

## 管理者設定パネル

管理者設定パネル（`/[admin] settings`で開く）はワールド全体のデフォルトを制御します。1つのアイランドだけでなく、ゲームモードのワールド全体に適用される設定です。これには以下が含まれます：

- 新しいアイランドのデフォルト保護フラグ
- ワールド全体の制限（例：クリーパーの爆発ダメージ、ピストンの動作）
- プレイヤー設定パネルの表示設定（変更させたくないフラグを非表示にする）

フラグシステムの詳しい説明は[保護](Protections.md)をご覧ください。

## パーミッションベースのコントロール

BentoBoxは大いにパーミッションベースです。プレイヤーが持てるホームの数から飛行できるかどうか、アイランドのサイズまで、ほぼすべてのことがパーミッションプラグイン（例：LuckPerms）を通じてパーミッションを付与または拒否することでコントロールできます。

!!! tip
    コンソールで`/bentobox perms`を実行すると、BentoBoxとそのアドオンによって登録されたすべてのパーミッションのリストがYAML形式で表示されます。パーミッションプラグインを設定する際に便利です。

## データベース管理

BentoBoxはアイランドとプレイヤーデータの保存に複数のデータベースバックエンドをサポートしています：

- **JSON（フラットファイル）** — デフォルト。セットアップが簡単で追加ソフトウェア不要
- **MySQL**（5.7以降）
- **MariaDB**（10.2.3以降）
- **MongoDB**（3.6以降）
- **SQLite**（3.28以降）
- **PostgreSQL**

データベースタイプはBentoBoxの`config.yml`で設定されます。データを失わずに1つのデータベースタイプから別のタイプに移行するには：
```
/bentobox migrate
```

!!! warning
    データベースを移行する前に必ず完全なバックアップを取ってください。

## 再起動なしのリロード

設定ファイルを変更した後、サーバーを完全に再起動せずに適用できます：
```
/bentobox reload
```
これはBentoBoxとすべてのアドオン（ロケールを含む）をリロードします。一部の変更（ワールド生成設定など）は常に完全な再起動が必要です。

??? note "v3.22.4 の新機能"
    **リリース:** 2026-09-06

    バグ修正とパフォーマンスのリリースです。互換性：Paper Minecraft 1.21.x～26.2、Java 25+。

    - 🔡 **`/[admin] info <player>` がすべてのアイランドを表示。** ワールド内でプレイヤーが持つすべてのアイランド（所有・チーム）が、それぞれアイランド名を見出しにして一覧表示されます。新しい任意引数 `[island name]` で 1 つだけを選べます — 上記の[コマンド表](#per-game-mode-admin-commands)を参照してください。名前の照合は寛容で（完全一致、次に大文字小文字・空白を無視、次に一意な前方一致）、複数語の名前に引用符は不要です。タブ補完でプレイヤーのアイランド名とホーム名が候補に出ます。
    - ⚙️ **アイランド履歴の上限。** `config.yml` の新オプション `island.history.max-entries` で、各アイランドが保持する履歴（ログ）エントリ数の上限を設定できます。古いものから削除されます。デフォルトの **`0`** は無制限なので、既存サーバーの動作は変わりません。古い `JOINED` エントリが削除されると、過去メンバー数のプレースホルダーが少なく数えられることがあります。
    - 🐛 **パージがクラッシュしなくなりました。** `/[admin] purge <days> confirm` が最初に完全に回収されたアイランドで `IslandEvent may only be triggered synchronously` により失敗し、データベースの行が残っていました。非同期のリージョン削除の後、アイランドイベントはメインスレッドで発火するようになりました。
    - 🐛 **サブコマンドのラベルが変わらなくなりました。** `/ob h` のようなエイリアスを入力すると、共有の `go` コマンドが全員のタブ補完とヘルプで `h` に改名されていました（3.22.0 の Brigadier 登録以降さらに目立っていました）。修正済みで、`home` / `h` エイリアスは変わりません。
    - 🐛 **プレイヤーヘッドをサーバー経由で解決。** オンラインのプレイヤーのヘッドはライブのプロフィールから、それ以外は mc-heads や Mojang にフォールバックする前に Paper 自身のプロフィールキャッシュから取得されます。これにより TopBlock などのパネルで、レート制限後も Steve ではなく本物のヘッドが表示されます。
    - ⚡ パフォーマンス：境界チェックでメモリを割り当てなくなり、マップの走査にイテレーターを使用し、呼び出しごとの生成の代わりに共有の GSON インスタンスを使用します。

    🔡 **ロケール注記。** `commands.admin.info.parameters` が `<player> [island name]` になり、新しいキー `commands.admin.info.island-name` が追加されました。同梱の 24 ロケールすべてが更新済みです。カスタムロケールファイルを使っている場合は新しいキーを追加してください。追加しないと、管理者の info 表示でアイランド名の行に生のキーが表示されます。

    [Release v3.22.4](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.22.4)

??? note "v3.22.3 の新機能 — bStats のオプトアウトと Paper 26.2"
    **リリース:** 2026-08-22

    主にバグ修正と API リリースです。互換性：Paper Minecraft 1.21.5～26.2、Java 25+。

    - ⚙️ **bStats メトリクスのオプトアウト。** `config.yml` に新しい `general.metrics` オプション（デフォルト**`true`**）が追加され、BentoBox の匿名で集計された使用統計を、`plugins/bStats/config.yml` のグローバルスイッチに触れることなく無効化できます。グローバルスイッチを使うと、サーバー上のすべてのプラグインで bStats が無効になります。`false` に設定して**再起動**してください。コレクターは起動時に登録されるため、`/bbox reload` では十分ではありません。個人情報は決して送信されません。[プライバシーとデータ収集](../Privacy.md) を参照してください。
    - 🔺 **Paper 26.2 と Adventure 5 に対応。** アドオン作者向け：Adventure 5 は `Component` をシール（Mockito が再度モックできない）し、`ClickEvent.value()` を `payload()` に置き換えます。26.2 サーバーに既にデプロイされているアドオンは実行時に影響を受ける場合があります。BentoBox 3.22.3 に対して再コンパイルすると、コンパイル時に問題が表面化します。[PR #3067](https://github.com/BentoBoxWorld/BentoBox/pull/3067) を参照してください。サーバー管理者は何もする必要ありません。
    - 🔲 **アドオン開発者向けダイアロググリッドレイアウト。** `DialogBuilder#columns(int)` は、複数アクションダイアログのボタンをデフォルトの 2 列リストではなくグリッドにレイアウトし、`DialogButton` は幅（1～1024）と `withWidth(int)` を持つようになりました。既存の呼び出し元は影響を受けません。
    - 🐛 **プレイヤーヘッドの 429 スパムが修正されました。** プレイヤーヘッド（トップテンリスト等）を含むパネルを開くと、`sessionserver.mojang.com` から HTTP 429 エラーでコンソールがあふれていました。テクスチャデータなしでデリバリーされたヘッドが毎回再解決されていたためです。テクスチャなしのヘッドは通常のヘッドに格下げされ、失敗したフェッチはキャッシュされた機能ヘッドを削除しなくなりました。
    - 🐛 **YAML 数値が宣言されたフィールド型にロードされるようになりました。** 小数点を含まずに書かれた `20` などの設定値が、`double`、`float`、`long` フィールドに正しくロードされるようになり、`ClassCastException` が発生しなくなりました。
    - 🐛 **パネルのリテラル色名。** 色のリファクター後、管理パネルに `whiteChallenges` のようなアドオン名が表示されていました。修正されました。
    - 📄 `.blueprint` とブループリント束ファイル形式の JSON スキーマ（draft 2020-12）を公開しました。

    [Release v3.22.3](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.22.3)

    - 🐛 **`Island.setFlag` が書き込みを破棄しなくなりました。** そのフラグのエントリをまだ持たないアイランド — つまり新規作成されたすべてのアイランド — に保護ランクを設定しても、静かに何も起きていませんでした。`SETTING` と `WORLD_SETTING` フラグは影響を受けていませんでした。
    - 🐛 **繰り返しの警告が正しく抑制されるようになりました。** 2 種類の異なる制限メッセージを交互に受け取るプレイヤーは、4 秒の通知クールダウンを完全に回避できていました。個々のメッセージが独立して抑制されるようになりました。
    - 🐛 **BlueMap のマーカーセットが自分のワールドに留まるようになりました。** アドオンのマーカーセットがサーバー上の他のすべてのマップのサイドバーに表示されることがなくなり、`/bluemap reload` 中に `createMarkerSet()` / `removeMarkerSet()` が例外を投げることもなくなりました。
