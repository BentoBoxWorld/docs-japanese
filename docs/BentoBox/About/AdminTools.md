# 管理者ツール

BentoBoxはサーバー管理者にゲームの管理、問題の調査、スムーズな運営のためのさまざまなツールを提供します。ファイルを手動で編集する必要はありません。

## 管理パネル

メインの管理ハブは**管理パネル**で、以下で開きます：
```
/bentobox manage
```
（エイリアス：`/bbox manage`）

ここから実行中のすべてのゲームモード、アクティブなアイランド、基本的なサーバーの状態を一目で確認できます。

## `/bentobox`コマンド

すべての最上位BentoBox管理は`/bentobox`（エイリアス：`/bbox`）を通じて行われます：

| コマンド | 機能 |
|---|---|
| `/bentobox version` | BentoBoxのバージョンとロードされているすべてのアドオンを表示します。**バグを報告する際は必ずこれを含めてください。** |
| `/bentobox manage` | 管理パネルGUIを開きます |
| `/bentobox reload` | サーバーの完全な再起動なしにBentoBoxの設定ファイルとロケールをリロードします |
| `/bentobox catalog` | アドオンカタログを開きます |
| `/bentobox perms` | BentoBoxとすべてのアドオンの有効なパーミッションを表示します |
| `/bentobox rank` | カスタムランクのリスト表示、追加、削除を行います |

## ゲームモードごとの管理者コマンド

各ゲームモードには独自の管理者コマンドがあります。BSkyBlockでは`/bsb`、AcidIslandでは`/acid admin`などです。これらはそのゲームモードに特有のコントロールを提供します：

| コマンド | 機能 |
|---|---|
| `/[admin] info <player>` | プレイヤーのアイランドの詳細情報を表示します |
| `/[admin] delete <player>` | プレイヤーのアイランドを削除します |
| `/[admin] setrange <player> <range>` | プレイヤーのアイランド保護範囲を変更します |
| `/[admin] range removebonus <player> [id]` | 単一アイランドからすべてのボーナス保護範囲を削除するか、特定のIDのもののみを削除します |
| `/[admin] range purgebonus <id>` | ボーナス範囲IDを世界のすべてのアイランドから削除します — ボーナス範囲を付与したアドオンをアンインストール後に理想的です。スキャンは非同期に実行されるため大規模サーバーをフリーズさせません |
| `/[admin] settings` | 管理者向けワールド設定パネルを開きます |
| `/[admin] settings <player>` | 特定のプレイヤーのアイランド設定パネルを開きます |
| `/[admin] why <player>` | プレイヤーが何かできる/できない理由の追跡を開始します（下記参照） |
| `/[admin] reload` | ゲームモードの設定をリロードします |
| `/[admin] blueprint` | ブループリントマネージャーGUIを開きます |

正確な管理者コマンドのプレフィックスはゲームモードの設定によって異なります。詳細はゲームモードのドキュメントを確認してください。

## 「Why」診断ツール

最も便利な管理者ツールの1つが`why`コマンドです。プレイヤーがアイランドで何かできない（またはできてはいけないことができる）と報告した場合は：

```
/[admin_command] why <player>
```

その後、サーバーコンソールはそのプレイヤーが行うすべてのアクションの理由をログに記録します。許可されたかブロックされたか、どの保護フラグが原因かが記録されます。これにより推測なしに設定ミスのパーミッションを診断できます。

追跡を停止するには、コマンドを再度実行してください。

## 管理者設定パネル

管理者設定パネル（`/[admin] settings`で開く）はワールド全体のデフォルトを制御します。1つのアイランドだけでなく、ゲームモードのワールド全体に適用される設定です。これには以下が含まれます：

- 新しいアイランドのデフォルト保護フラグ
- ワールド全体の制限（例：クリーパーの爆発ダメージ、ピストンの動作）
- プレイヤー設定パネルの表示設定（変更させたくないフラグを非表示にする）

フラグシステムの詳しい説明は[保護](Protections.md)をご覧ください。

## パーミッションベースのコントロール

BentoBoxは大いにパーミッションベースです。プレイヤーが持てるホームの数から飛行できるかどうか、アイランドのサイズまで、ほぼすべてのことがパーミッションプラグイン（例：LuckPerms）を通じてパーミッションを付与または拒否することでコントロールできます。

!!! tip
    コンソールで`/bentobox perms`を実行すると、BentoBoxとそのアドオンによって登録されたすべてのパーミッションのリストがYAML形式で表示されます。パーミッションプラグインを設定する際に便利です。

## データベース管理

BentoBoxはアイランドとプレイヤーデータの保存に複数のデータベースバックエンドをサポートしています：

- **JSON（フラットファイル）** — デフォルト。セットアップが簡単で追加ソフトウェア不要
- **MySQL**（5.7以降）
- **MariaDB**（10.2.3以降）
- **MongoDB**（3.6以降）
- **SQLite**（3.28以降）
- **PostgreSQL**

データベースタイプはBentoBoxの`config.yml`で設定されます。データを失わずに1つのデータベースタイプから別のタイプに移行するには：
```
/bentobox migrate
```

!!! warning
    データベースを移行する前に必ず完全なバックアップを取ってください。

## 再起動なしのリロード

設定ファイルを変更した後、サーバーを完全に再起動せずに適用できます：
```
/bentobox reload
```
これはBentoBoxとすべてのアドオン（ロケールを含む）をリロードします。一部の変更（ワールド生成設定など）は常に完全な再起動が必要です。

## 変更履歴

!!! note "v3.22.0 の新機能 — Brigadier コマンド"
    **リリース:** 2026-08-01

    コマンドと可視性に関するリリースです。互換性: Paper Minecraft 1.21.5～26.2、Java 25+。

    - ⚙️ 🔺 **コマンドが Paper の Brigadier API で登録されるようになりました。** プレイヤーが入力している*最中*に BentoBox のサブコマンドと補完が表示されます — `/island t…` と打つとチャット欄に `team` が提示されます。従来のように、エンターや TAB を押すまでクライアントが何も知らないということがなくなりました。サブコマンドツリーは深さ 4 まで通知されます。それより深いサブコマンドも動作しますが、事前には提示されません。エイリアスと `plugin:label` 形式は、ツリーを複製せずリダイレクトとして送信されます。`config.yml` に新しい `general.brigadier-commands` オプションが追加され、デフォルトは**オン**です。他のプラグインと競合する場合は `false` にして `/bbox reload` を実行すると、従来のコマンドマップ方式に戻せます。レジストラにフックできない場合、BentoBox は自動的にフォールバックします。
    - 🔺 **構造物を生成しないワールドでは、構造物の探索が自動的に抑制されます。** 村人の地図製作者が探検家の地図の取引を引き当てたとき — あるいはエンダーアイ、イルカ、宝の地図でも — 同期的な構造物探索が実行されていました。ボイドワールドでは決して成功しないため、半径の上限までスキャンし続け、60 秒のウォッチドッグを超過します。BentoBox はワールドのジェネレーターが構造物を配置するかどうかを確認し、配置しない場合は探索をスキップするようになりました。**設定は不要です。** AOneBlock と BSkyBlock は自動的にこの保護を受けます。SkyGrid、Boxed、CaveBlock、AcidIsland は構造物を生成するため影響はありません。ワールドごとの `structures` 設定で `true` を指定すれば個別に強制的に有効化でき、既存の構造物を含む変換済みワールドの逃げ道になります。これは 3.20.0 で追加されたオプトイン方式の `world.disabled-structures` リストを補完するものです。
    - **`/island settings` がワールド上でも開けるようになりました。** どのアイランドにもいない、またはアイランドを所有していないプレイヤーには、これまで「アイランドを持っていません！」と表示されていました。パネルは読み取り専用の**ワールド保護**タブとともに開き、そのワールドでどの保護フラグが有効かを表示します。これはまさに、プレイヤーが立っている場所を支配しているルールです。[保護](Protections.md#viewing-the-world-rules-off-island)を参照してください。
    - 🐛 **シャットダウン中にキューへ入れられたアドオンのデータが破棄されなくなりました。** アドオンが `onDisable()` から保存したものは、すでにドレインを停止したデータベースのパイプラインへキューされていたため、再起動のたびに静かに、断続的に失われていました。バンドルされた 9 個のアドオン（Boxed、AOneBlock、Raft、Challenges、Limits、DragonFights、CheckMeOut、ControlPanel、InvSwitcher）が無効化時に保存を行います。InvSwitcher では、古い保存済みインベントリが参加時に再適用されるため、単なる書き込みの喪失ではなくロールバックになっていました。シャットダウン時の書き込みは、データベースを閉じる前にドレインされるようになりました。
    - 🐛 **NPC・看板・GUI プラグインから BentoBox のコマンドが再び使えるようになりました。** Brigadier での登録により、他のプラグインがディスパッチに使う Bukkit のコマンドマップから BentoBox のコマンドが外れていたため、NPC が `/oneblock go` を実行してもサーバーの権限エラーが返され、何も実行されませんでした。コマンドマップにも登録されるようになりました。これは 3.22.0 の開発ビルドにのみ影響していた問題です。
    - 🐛 **`Island.setFlag` が書き込みを破棄しなくなりました。** そのフラグのエントリをまだ持たないアイランド — つまり新規作成されたすべてのアイランド — に保護ランクを設定しても、静かに何も起きていませんでした。`SETTING` と `WORLD_SETTING` フラグは影響を受けていませんでした。
    - 🐛 **繰り返しの警告が正しく抑制されるようになりました。** 2 種類の異なる制限メッセージを交互に受け取るプレイヤーは、4 秒の通知クールダウンを完全に回避できていました。個々のメッセージが独立して抑制されるようになりました。
    - 🐛 **BlueMap のマーカーセットが自分のワールドに留まるようになりました。** アドオンのマーカーセットがサーバー上の他のすべてのマップのサイドバーに表示されることがなくなり、`/bluemap reload` 中に `createMarkerSet()` / `removeMarkerSet()` が例外を投げることもなくなりました。
    - 🐛 **Multiverse の整理。** BentoBox のワールドは、Multiverse がすでにそのワールドを知っている場合でも `auto-load: false` が設定されるようになり、廃止されたシードワールド（`<world>/bentobox`）の登録も削除されました。既存の残存エントリには引き続き `/mv remove` が必要です。
    - 🐛 **依存関係の欠如で除外されたアドオンのフラグが後始末されるようになりました。** ハード依存が存在しないアドオンは、除外される前にすでにフラグとリスナーを登録していたため、存在しないワールドに対してリスナーが発火し続けていました。
    - **6 つの新しい bStats チャート**により、アドオンとゲームモードのバージョン、アドオンの API レベル、デフォルトから変更された設定、コマンドがどこでどのように失敗したかが分かります。送信されるのは失敗の種類と、パーミッションから導出された安定したコマンドキーのみで、引数やプレイヤー名は一切含まれません。
    - 🔡 **繁体字中国語（`zh-TW`）ロケール**が @qwe664 によって追加されました。既存のロケールキーに変更はないため、カスタムロケールファイルへの対応は不要です。

    [Release v3.22.0](https://github.com/BentoBoxWorld/BentoBox/releases/tag/3.22.0)

??? note "v3.20.0 の新機能 — コマンド補完 & コア構造抑制"
    **リリース:** 2026-07-11

    利便性改善リリースです。互換性: Paper Minecraft 1.21.5～26.2、Java 25+。オプトインしない限り、アップグレード時に何も変更されません。

    - 🔡 ⚙️ **「Did you mean」コマンド提案機能。** `/teams`や`/island invit Floris`のようにタイプミスしたコマンドは、ヘルプテキストをダンプする代わりに、最も近いマッチするBentoBoxコマンドをクリック可能な形で提案します（または30秒以内に`yes`/`y`とタイプして受け入れられます）。提案はすべてのコマンドツリーにわたってラベルとエイリアスにマッチし、パーミッションでフィルタリングされ、プレイヤーが立っているゲームモードワールドを使用して曖昧さを排除します。`config.yml`の`general.did-you-mean`下に2つの新しいトグル — `unknown-commands`と`subcommands` — があり、両方ともデフォルトは**オン**です。いずれかを`false`に設定して`/bbox reload`を実行すると無効化できます。
    - ⚙️ 🔺 **すべてのゲームモード向けコアバニラ構造抑制。** バニラ構造を無効化することは、アドオンごとのジョブではなく、単一のコア設定になりました。`config.yml`の新しい`world.disabled-structures`リスト（すべてのBentoBoxオーバーワールド/ネザー/エンドに適用）は、リストされた構造の生成を停止し、構造検索でそれらをスキップします — `/locate`、目玉の辺境の地、探検家/トレジャーマップ、イルカと村人の地図商人の取引 — 長年の`/locate`メインスレッドフリーズとスポーン近辺の構造リークを修正します。キーは大文字小文字とセパレータに対して区別されません（`trial_chambers`、`ancient-city`）。ゲームモードは構造ごとにリストをオーバーライドできます。**リストはデフォルトで空なので、オプトインするまで動作は変わりません。**
    - 🔌 **Nexoフック。** BentoBoxは、他のカスタムアイテム統合と共に、[Nexo](https://nexomc.com/)カスタムブロックとアイテムを配置・検出できるようになりました。
    - 🔌 **Oraxenブロック配置。** `OraxenHook.placeBlock`は、他のカスタムブロックフックに合わせて、Oraxenカスタムブロック配置をアドオンに公開します。
    - 🔡 **ロケール情報：** 3つの新しい`general.did-you-mean`キーがすべての22個のバンドルロケールに追加され、すでに存在していた欠落キー`commands.admin.team.setowner.specify-island`がすべての英語以外のファイルで埋められました。カスタムロケールファイルを再生成または更新してください。

??? warning "v3.19.0 の新機能 — ベッド/アンカーのリスポーンが尊重されるようになりました"
    **リリース:** 2026-07-08

    互換性: Paper Minecraft 1.21.5～26.2、Java 25+。

    - 🔡 **新しい `FISHING` 保護フラグ。** アイランド外からプレイヤーが保護エリアに向けて釣りをするのを防ぎます（フラグは釣り針の位置をチェックします）。デフォルトは訪問者ランクなので、引き上げるまで何も変わりません。

    - 🐛 **エンド脱出ポータルでワールドスポーンに放り出されなくなりました。** エンド脱出ポータルを通ると、複数ゲームモードのサーバーでは安全なアイランドのホームへ移動するようになりました。
    - 🐛 **額縁と絵画がブループリントで保持されます。** 額縁は向きと中身を保持し、絵画は元のアートワークを復元します。外れたり間違った向きになったりしなくなりました。
    - 🔡 **削除予定のアイランドの復旧。** 新しい `/[admin] undelete`、（プレイヤー引数なしで）立っている場所で実行する `/[admin] delete`、および `/[admin] register` の確認プロンプトにより、リージョンファイルが消去される前にソフト削除されたアイランドを復旧できるようになりました（上記のゲームモードごとの管理者コマンドテーブルを参照）。
    - ⚙️ **BlueMap のアイランドレイヤーがリロード後も保持されます。** `/bluemap reload` 後にオーナーピンとエリアボックスが消えなくなりました。`config.yml` の新しい `bluemap` セクションに `island-markers` と `island-areas` トグル（両方ともデフォルト `true`）が追加され、Dynmap のトグルをミラーリングし、マーカーのカスタマイズも可能です。
    - ⚙️ **チームパネルのボタンアイコンとメンバー/候補者テキストを設定可能に。** チームパネルの STATUS、RANK フィルター、INVITE ボタンが `team_panel.yml` で設定した `icon:` を尊重するようになり、メンバー/候補者ボタンの名前と説明はロケールキーで制御されるようになりました。デフォルトは従来の外観を正確に再現します。
    - ⚡ **設定 GUI のクリック連打で MSPT が急増しなくなりました。** `/is settings` の連打は、パネルのインプレース更新と翻訳キャッシュにより、約30～40 MSPT からごくわずかに低減しました。

??? warning "v3.18.0 の新機能 — Minecraft 26.2 サポートは Java 25 (サーバー) が必須です"
    **リリース:** 2026-06-27

    - 🔺 **Minecraft 26.2 対応 + Java 25。** BentoBoxはMinecraft 26.xラインで実行でき（実行時に26.2対応）、ビルドはJava 25ツールチェーンに移行しました。**26.xラインの場合、サーバーはJava 25対応のPaperビルドで実行する必要があります。** 既にビルドされたアドオンJARは変わらず動作します — このリリースに対して再コンパイルするアドオン*開発者*のみが独自のビルドをJava 25に移行する必要があります。互換性: Paper Minecraft 1.21.5～26.2、Java 25+。
    - ⚙️ **Dynmapアイランドマーカー/エリアトグル。** `config.yml`の新しい`dynmap`セクションが`island-markers`（各アイランド中央のハウスアイコン）と`island-areas`（保護エリア枠）スイッチを追加します。両方ともデフォルトは`true`で、既存の動作を保持しています。いずれかを`false`に設定して`/bbox reload`を実行すると、密集したアイランドがマップを埋め尽くすサーバーでオーバーレイを非表示にできます。
    - **管理者範囲ボーナス管理。** 新しい`/[admin] range removebonus`と`/[admin] range purgebonus`コマンドは、単一アイランドまたはすべてのアイランドからボーナス保護範囲をクリアします — ボーナス範囲を付与したアドオンをアンインストール後に理想的です（上記のゲームモードごとの管理者コマンドテーブルを参照）。
    - 🐛 `/is team setowner`は、既存のチームメンバーへの転送時にアイランド制限によってブロックされなくなりました。
    - 🐛 Vaultフックは、アドオン有効化後に再試行するようになり、読み込み順序に依存した経済統合を修正します。
