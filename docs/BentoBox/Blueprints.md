# スターターアイランド（ブループリント）

プレイヤーがアイランドを作成するとき、BentoBoxはスターターアイランドをペーストします。これらのスターターアイランドは**ブループリント**で、ゲーム内で構築して保存します。**バンドル**は、オーバーワールド、ネザー、エンドブループリントを1つの選択肢に、アイランド作成メニューでグループ化します。独自のアイコン、名前、説明を持ちます。

各ゲームモードは数個のバンドルが付属しています。変更できます、追加、VIP専用アイランドの提供、有料化、選択時にコマンドを実行。

!!! info "このページのコマンド"
    コマンドはBSkyBlock（`/bsbadmin`）用に表示されます。ゲームモードの管理者コマンドを代わりに使用します。例えばAOneBlockの場合は`/oba`、AcidIslandの場合は`/acid`。`blueprint`は`bp`に短縮可能。

## スターターアイランドを作成

1. **構築します。** ゲームモードのワールド内にアイランドを構築します。他のアイランドから離れた場所。**基岩**ブロックを最低1つ配置：最も高い基岩ブロックがアイランドの中心になります。BentoBoxはブループリントを保存する際に1つが必要です。
2. **サイン追加（オプション）。** プレイヤーが表示される場所に、最初の行が`[spawn_here]`のサインを配置。サインが直面している方向でプレイヤーは見えます。最初の行が`[start]`のサインを追加してウェルカムメッセージを表示。[サイン](#signs)を参照。
3. **選択します。** 1つのコーナーに立って`/bsbadmin bp pos1`を実行。反対のコーナーで`/bsbadmin bp pos2`を実行。WorldEditの選択を使用しないでください。
4. **コピー。** `/bsbadmin bp copy`。アイランドが水または石にペーストされる場合（AcidIsland、CaveBlock、Poseidon）、`air`を追加します。周囲の空気もペーストされます。`biome`を追加してバイオームを保持、または`nowater`を追加して水ブロックを除外。
5. **チェック。** 空の場所に行って`/bsbadmin bp paste`を実行。コピーされたものを確認。
6. **保存。** `/bsbadmin bp save <name>`。例えば`/bsbadmin bp save vip_island`。
7. **プレイヤーに提供。** `/bsbadmin bp`を開いてブループリントをバンドルに配置（次のセクション）。

ゲームモードのデフォルトアイランドを新しく追加する代わりに置き換えるには、ブループリントを上書き保存（通常`island`、`nether-island`、`end-island`）。確認を求められます。

!!! tip "小さく保つ"
    アイランドゲームモードの楽しさは、ほとんど何もない状態から成長することです。プレイヤーは開始するのに十分なブロックとアイテムだけを使ってください。

**WorldEditスキーマティックの変換：** ブループリントはスキーマティックではありませんが、WorldEditでスキーマティックをペーストし、基岩とサインを追加してから、ブループリントコマンドで選択、コピー、保存できます。各ネザーとエンドアイランドで実行。

## バンドル：アイランド作成メニューでの選択肢

ブループリントマネージャーを**`/bsbadmin bp`**で開きます。バンドルをリスト表示します。1つをクリックして編集。

| 実行すること | 方法 |
|---|---|
| バンドル作成 | 緑のバナーをクリック、その後チャットに名前を入力 |
| ブループリントをバンドルに配置 | 下部のブループリントをクリックして光ります。その後、緑（オーバーワールド）、赤（ネザー）、または黄（エンド）スロットをクリック |
| スロットを空にする | 右クリック |
| バンドルのアイコンを変更 | 自分のインベントリ内のアイテムをクリック |
| 名前変更 | バンドルをリストで右クリック、その後チャットに名前を入力 |
| 説明を変更 | バンドル内、アイコン（左上）をクリック、その後チャットに入力。`&c`のようなカラーコードが動作 |
| メニュー内で表示される場所を選択 | スロットアイコンを左クリックして後ろに移動、右クリックして前に移動 |
| VIP専用にする | ペインティングをクリックして権限を要求。権限はアイコンに表示されます。例えば`bskyblock.island.create.vip_island` |
| 有料化 | ゴールドインゴットをクリック：左/右クリックで1追加/削除、shift クリックで100。Vaultと経済プラグイン必要 |
| バンドル選択時にコマンド実行 | コマンドブロックをクリック、その後チャットにコマンドを入力 |
| プレイヤーが選択できる回数を制限 | 時計をクリック。プレイヤーが複数アイランドを所有できるときのみ表示 |
| 削除 | TNTを右クリック |

すべてのゲームモードは`default`というバンドルを持ちます。削除できません。プレイヤーが選択しないとき使用（例えば最初のログイン時に自動的にアイランドが作成されるとき）。

バンドル**必須** オーバーワールドブループリントを持ちます。ない場合、デフォルトアイランドが使用され、エラーはログされます。ネザーとエンドブループリントはオプション。ない場合、それらのワールドにアイランドはペーストされません。

**バンドルとブループリントをマネージャーで、または`/bsbadmin bp rename`で名前変更**。ファイルを名前変更しないでください。

### バンドル選択時にコマンド実行

コマンドはバンドルでアイランドが作成されるたびに実行。例えばスターターキットを付与またはランクを設定。`[player]`と`[owner]`はプレイヤーの名前に置き換えられます。コマンドはコンソールから実行される。`[SUDO]`で始まるものはプレイヤーとして実行。

```
lp user [player] parent add skyblock-starter
[SUDO] kit starter
```

### バンドルの有料化

ゴールドインゴットでバンドルにコストを設定。プレイヤーはそれでアイランドを作成またはリセットするとき支払い、余裕がない場合は選択できません。これには`use-economy: true`がBentoBoxの`config.yml`と必要。Vaultと経済プラグイン。ないとゴールドインゴットは表示されません。

## サイン

| サインの最初の行 | 何が起こるか |
|---|---|
| `[spawn_here]` | プレイヤーはこのスポットに現れます。サインが直面する方向でプレイヤーは見えます。サインは削除。ネザーとエンドブループリントでも動作 |
| `[start]` | ゲームモードのロケールファイルからウェルカムテキストで置き換え（`bskyblock.sign.line0`から`line3`）。所有者の言語で。そのテキストの`[name]`は所有者の名前になります |
| その他 | 書かれた通りペーストされます |

**名前付きモブ：** アンビルで名前タグを名前付け。`[name]`を含まれます。アイランド内のモブに配置。アイランドがペーストされるとき、モブはアイランド所有者に名前付けられます。

## すべてのブループリントコマンド

| コマンド | 内容 |
|---|---|
| `/bsbadmin bp` | ブループリントマネージャーを開く |
| `/bsbadmin bp pos1`、`pos2` | コピー領域のコーナーを設定 |
| `/bsbadmin bp copy [air] [biome] [nowater]` | 領域をクリップボードにコピー |
| `/bsbadmin bp origin` | ペースト原点を見ているブロックに設定 |
| `/bsbadmin bp paste` | クリップボードを立っている場所にペースト |
| `/bsbadmin bp save <name>` | クリップボードをブループリントとして保存 |
| `/bsbadmin bp load <name>` | ブループリントをクリップボードに読み込んで変更 |
| `/bsbadmin bp list` | ブループリントをリスト表示 |
| `/bsbadmin bp rename <name> <new name>` | ブループリントを名前変更 |
| `/bsbadmin bp delete <name>` | ブループリント削除 |
| `/bsbadmin bp sink` | このブループリントがペーストされるとき海底に沈むかどうかを切り替え |

## ファイル

ブループリントとバンドルはゲームモードごとに`plugins/BentoBox/addons/<GameMode>/blueprints/`に保存。

- `<name>.blueprint`：ブループリント、プレーンJSON。古い`.blu`ファイル（圧縮）はまだ読み込み。
- `<bundle>.json`：バンドル、プレーンJSON。

これらのファイルをサーバー間でコピー、バージョン管理に保持、編集できます。すべてのフィールドについては、[ブループリントファイル形式](Blueprint-Format.md)を参照。

## ペースト速度

コピーとペーストは少しずつ行われます。大きなアイランドはサーバーをフリーズしません。大きなアイランドには数秒かかる可能性があります。アイランド作成がラグを引き起こす場合、`paste-speed`（ティックあたりのブロック）を、BentoBoxの`config.yml`で低くしてください。

## トラブルシューティング

**「ブループリントに最低1つの基岩ブロックが必要です。」**
アイランドに基岩ブロックを追加、もう一度コピー、その後保存。

**プレイヤーは間違った場所に表示されるか、落ちます。**
`[spawn_here]`サインを追加。プレイヤーの上に空気があることを確認。

**アイランドは水（または石）のギャップで囲まれています。そうすべきではありません**。またはワールドからの水は流れ込みます。
`air`で空気がブループリントの一部になるようにコピー。選択を密に保つ。空気はファイルを大きくします。

**新しいバンドルはアイランド作成メニューに表示されません。**
オーバーワールドブループリント、プレイヤーが欠ける権限要件がない。使用制限がある場合、プレイヤーは使用済み。BentoBoxの`config.yml`で`hide-used-blueprints: true`。使用済みバンドルは非表示。

**ウェルカムサインが`[start]`を表示。**
`[start]`テキストはゲームモードのロケールファイルから来ます。`<gamemode>.sign.line0`から`line3`がそこに存在することを確認。
