# ASkyBlock から BSkyBlock へのコンバーターアドオン

## 互換性

コンバーターは BentoBox と BSkyBlock の最新バージョンと共に使用してください。コンバーターは BentoBox の addons フォルダにダウンロードして配置するアドオンです。変換を実行するには、これらの説明を全て読んでください。

## はじめに

コンバーターは ASkyBlock のデータファイルを取得し、BSkyBlock/BentoBox データベース内に新しいバージョンを作成します。以下の項目が変換されます:

* プレイヤーとチーム
* アイランド
* ワープ
* ほとんどの Config.yml 設定
* チャレンジ

以下は変換されません:

* スキーマティック - BSkyBlock ではサポートされていません。代わりに BentoBox のブループリントを使用してください。
* バイオーム - BSkyBlock 自体ではサポートされていません。Biome アドオンを使用してください。
* マジック溶岩 - BSkyBlock 自体ではサポートされていません。このためのアドオンが開発中です。
* 酸性の水や雨の設定 - BSkyBlock ではサポートされていません。
* チームチャット - BSkyBlock ではサポートされていません。
* コープ変換 - コープは BSkyBlock で異なる方法で扱われるため、プレイヤーが手動でやり直す必要があります。
* レベル関連の設定 - BSkyBlock 自体ではサポートされていません。Level アドオンを使用してください。

## バックアップ

**警告！** このソフトウェアは保証なしで現状のまま提供されます。自己責任でご使用ください。必ずサーバーファイルとフォルダのバックアップコピーを作成してください。これは非常に重要です！

## 変換の準備

**注意:** ASkyBlock のワールドはサーバーを最新バージョンにアップグレードする以外は変更されません。変換後も BSkyBlock で同じワールドを使用します。つまり同じ名前のワールドになります。

現在のサーバーが 1.12.2 で動作している場合は、サーバーを最新バージョンの Minecraft にアップグレードする必要があります。

## 手順

**注意:** ワールドが大きい場合は、変換中にウォッチドッグタイマーがサーバーを停止しないように、サーバーのタイムアウトを変更する必要があります。

*バックアップを作成したことを確認しましたか？*

0. spigot.yml を編集し、**timeout-time:** を 60000 などの大きな値に変更して、変換中にウォッチドッグタイマーがサーバーを停止するのを防ぎます。
1. サーバーを停止し、Spigot 1.14.4（またはそれ以降）のサーバー jar をサーバーフォルダに追加します。
2. plugins フォルダから ASkyBlock.jar を削除します。ASkyBlock フォルダやワールドは削除しないでください。
3. BentoBox バージョン 1.12.0（またはそれ以上）を plugins フォルダにインストールします。
4. **--forceUpgrade** オプションを付けて新しいサーバーを起動します。これで全てのワールドが新しい形式にアップグレードされます。
5. 全てが完全に読み込まれ、BentoBox のロゴが表示されたら、サーバーを停止します。
6. **BSkyBlock** アドオン、**Challenges** アドオン、**Warps** アドオン、**Converter** アドオンを BentoBox の addons フォルダに配置します。
7. **--forceUpgrade** オプションを付けてサーバーを再起動します。
8. サーバーが読み込まれ BentoBox のロゴが表示されたら、コンソールで **bsb convert** と入力して変換を開始します。
9. 変換が完了したら、サーバーを停止します。**非常に重要。サーバーを停止してください！リロードしないでください！！！** これで正しいワールドジェネレーターが登録されます。
10. BSkyBlock の config.yml を希望通りに編集します。
11. spigot.yml を編集し、**timeout-time:** を 60 などの小さな値に戻します。
12. コンバーターアドオンと作成されたデフォルトの BSkyBlock ワールドフォルダを削除します。
13. サーバーを再起動します。forceUpgrade オプションはもう必要ありません。BSkyBlock アドオンは ASkyBlock のワールドを使用します。

**注意:** BentoBox はプレースホルダーに PAPI または MVdW を使用します。プレースホルダーの使用に興味がある場合は、プレースホルダーに関するドキュメントをお読みください。

**注意:** チャレンジと Warps は必須ではありません。コンバーターはそれらなしで動作できますが、データは変換されません。
