# Greenhouses

Greenhouses はアイランドワールドをパワーアップする BentoBox アドオンです！プレイヤーが天気、友好的なモブのスポーン、独自の植物成長、さらにはブロックの侵食を備えた自分だけのバイオームグリーンハウスを建てられるようにします！

グリーンハウスはガラスで作られており、有効であるためにはバイオームレシピに含まれるブロックを含む必要があります。レシピの GUI があります。作成後、グリーンハウスでは骨粉を使って植物を育てることができ、バイオーム固有のモブがスポーンすることがあります。水の入ったホッパーを含める場合、雨が降るときにグリーンハウス内に雪が降ります。ホッパーに骨粉を入れると、バイオーム固有の植物が育ちます。一部のブロックは「侵食」によって時間の経過とともに変化することもあります。

作成・メンテナンス: [tastybento](https://github.com/tastybento)

## 機能

* アイランド（または好みであれば他の場所）に自己完結型のバイオームグリーンハウスを作る
* グリーンハウスでは通常育てられないヒマワリなどの植物も育てられます
* グリーンハウスが上手く設計されていれば友好的なモブがスポーンします - スライムが欲しいですか？沼地のグリーンハウスを作りましょう！
* ブロックはバイオームに応じて時間の経過とともに変化します - 砂漠では土が砂になり、川では土が粘土になるなど。
* グリーンハウスは複数のワールドで動作できます。
* 使いやすい GUI でグリーンハウスのレシピを表示します（例: **/is greenhouses**）
* 管理者はバイオームとレシピを完全にカスタマイズできます

## グリーンハウスの建て方

この例は BSkyBlock ワールドでの操作です。AcidIsland では /island の代わりに /ai を使用してください。

1. ガラスブロックを作成し、平らな屋根を持つ長方形の壁を建てます。
2. 壁または屋根にホッパーを設置します。
3. 中に入ったり出たりできるようにドアを壁に設置します。
4. **/island greenhouses** と入力し、希望するグリーンハウスのルールを読みます。
5. GUI を閉じてブロック、水、溶岩、氷を配置して目的のバイオームを作ります。
6. **/island greenhouses** を再び入力してバイオームを作るためにクリックします。
7. **/island greenhouses help** と入力して他のオプションを確認します。

### 作成後:

* グリーンハウス内の草ブロック上の小さな植物をすぐに骨粉で育てます。
* またはホッパーに骨粉を入れて、グリーンハウスが自動的に骨粉を撒くようにします。後で戻って何が育ったか確認しましょう！
* ホッパーにバケツ一杯の水（または複数）を入れると、寒いバイオームで雪が降るようになります。ワールドで雨が降ると雪が降ります。一度の降雪で水バケツ一つが消費されます。
* バイオーム固有の友好的なモブがグリーンハウスにスポーンすることがあります - 通常のルールが適用されます（24ブロック以上離れている必要があります）。

## よくある質問

* 色付きガラスを使えますか？ はい、使えます。きれいですよ。
* グリーンハウスを水で満たせますか？ はい。それは海になります。
* スイカがそこにスポーンしますか？ たぶん...実際にはそうです、十分に大きな海であれば。
* 壁が全部ガラスなのに、壁の高い位置にドアを設置するにはどうすれば？ ホッパーの上に設置してください。
* ホッパーにドアを設置するには？ しゃがんでから設置してください。
* 金属ドアを使えますか？ はい。
* トラップドアを使えますか？ はい。
* これで沼地の花を育てられますか？ はい。沼地バイオームを作って骨粉を使ってください。
* 植物を育てるのにどれくらいの骨粉が使われますか？ 植物が成功して育つごとに1本。
* ホッパーに雪を降らせるのにどれくらいの水が必要ですか？ 雨が降るたびにバケツ一杯の水（水だけ）が消費されます。これは寒いバイオームでのみ起こります。
* ネザーグリーンハウスを建てられますか？ 試してみてください...（実際には権限が必要かもしれません）
* ネザーにグリーンハウスを建てられますか？ はい。それらを使ってネザーを植民地化できます。
* バイオームにはどんなモブがスポーンしますか？ 予想通りのものです。寒い針葉樹林ではオオカミ、平原では馬など。

## 必要プラグイン

このバージョンの Greenhouses は BentoBox のアドオンであり、スタンドアロンでは動作しません！

1. BentoBox - 最新バージョンを使用していることを確認してください！

## インストールと設定

1. BentoBox をダウンロードしてインストールします（まだの場合）
2. アドオンをダウンロードします
3. BentoBox の addons フォルダに配置します
4. サーバーを再起動します
5. アドオンは greenhouses というデータフォルダを作成します。そのフォルダを開きます。
6. **config.yml** を確認して希望通りに編集します。ワールド名のリストに注意してください。
7. 必要であれば **biomes.yml** を設定します（上級者向け）。
8. ゲーム内で **/bsbadmin greenhouses reload** と入力して設定をリロードするか、サーバーを再起動します。
9. 完了！

最初のグリーンハウスを作るには、ガラスの箱を建てて **/is greenhouses make** と入力して、どんなグリーンハウスになるか確認してください。**/is greenhouses** と入力してレシピを確認してください。

## プレイヤーコマンド

/island、/ai に以下のコマンドを追加します:

* **greenhouses help** - これらのコマンドの一覧を表示します
* **greenhouses make**: 最初に有効なレシピを見つけてグリーンハウスを作ろうとします
* **greenhouses remove**: 立っているグリーンハウスを（オーナーであれば）削除します
* **greenhouses list**: 利用可能な全レシピの一覧を表示します
* **greenhouses recipe**: レシピ GUI を表示します - レシピをクリックするとグリーンハウスを作ろうとします

## 管理者コマンド

/bsb や /acid などのゲームモード管理者コマンドの後に使用します

* **greenhouses reload** : 設定ファイルをリロードします
* **greenhouses info <player>**: プレイヤーのアイランドグリーンハウスに関する情報を提供します
* **greenhouses info**: 現在いるグリーンハウスに関する情報を提供します

## 権限

権限の完全なリストは[こちら](Permissions)にあります。

特定のバイオームを使用する権限は biomes.yml で追加できます。

例えば、ネザーバイオームの権限は **greenhouses.biome.nether** であり、ここで設定されています:

 NETHER:

    permission: greenhouses.biome.nether

権限はランク権限 **myserver.VIP** など、任意のものを設定できます。

### 一般権限:

  greenhouses.player:

     description: プレイヤーコマンドへのアクセスを付与します
     default: true

  greenhouses.admin:

     description: 管理者コマンドへのアクセスを付与します
     default: op
