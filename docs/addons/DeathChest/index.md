# DeathChest

**DeathChest**はプレイヤーがボックスに死ぬ代わりに、地面にアイテムをドロップするチェストをプレイヤーのアイテムを入れます—そして、一般的なマルチパーパスデスチェストプラグインと異なり、それはアイランドがどこにあるかを知っています。

作成・管理者：[tastybento](https://github.com/tastybento)。

## アイランド固有のデスチェストアドオンが必要な理由

従来のデスチェストプラグインは2つのことを想定しています。プレイヤーがチェストを配置できるどこかで死んだこと、そしてその後、それに戻ることができること。アイランドサーバーではどちらも想定が成り立ちません。

- **ボイド。**プレイヤーがアイランドから落ちると、空の空間で死亡します。多くの場合、世界の床下。墓を建てるブロックがないので、従来のプラグインはいずれかのチェストをボイドに落とし、あきらめるか、基岩レベルで置きます。そこに達することはできません。
- **オーシャン。**AcidIslandで、アイランドの周りのスペースは海です。地面が存在しますが、100ブロック下であり、水中です—技術的には有効なスポット、実際には失われたチェスト。
- **他のプレイヤーのアイランド。**訪問者が死亡することはできず、多くの場合、チェストを壊すことはできません。多くの場合、それを開くこともできません。
- **野生。**アイランド間のスペースは保護されても到達可能でもありません。飛行せずに。

だから通常のアドバイスは「ただ`keepInventory`をオンにします」—そしてそれで、死ぬことは全く重要ではなくなります。

DeathChestは、代わりに配置の問題を解決し、すべてを失うことなく死ぬことができますが、何か費やすことができます。

## チェスト位置の選択方法

アドオンは3つのステージを通じて動作し、成功するものを最初に停止します。

1. **プレイヤーが死んだ場所**—ただし、彼らがアイランドの*保護された*部分内で死んだ場合、彼らはメンバーであり、到達可能な地面がある：自由ブロック、その下に固いもの、`chest.search-depth`ブロック以内、水没しない。これは通常のケースです。あなたのアイランドで死んだので、あなたのもの。
2. **彼らのアイランド上** — 彼らのアイランドホームの隣。ボイド死、海死、溶岩死、誰かの訪問中の死と野生での死はすべてここに着陸し、プレイヤーもここで再スポーンする場所です。
3. **アドオンで保有** — プレイヤーがアイランドを全く持たない場合、アイテムはアドオンのデータベースに入り、`/[player command] deathchest claim 1`で回復されます。

!!! info "なぜ「到達可能な地面」が重要なのか"
    固い地面内での任意の固い地面ではなく、到達可能な地面を要求することは、チェストを役に立たない場所に終わらせるのを防ぎます。ボイドに落ちるプレイヤーはまだアイランドの柱内にいるので、無制限の下向き検索は幸せに基岩を見つけ、そこにチェストを残します。オーシャンゲームモードでは、海底を見つけます。このチェックに失敗することはエラーではありません—それはプレイヤーが実際に歩くことができるステージ2にチェストを送信する信号です。

## インストール

1. アドオンjarを`plugins/BentoBox/addons`フォルダーに入れます
2. サーバーを再起動（アドオンを有効にし、`config.yml`ファイルが生成されます）
3. `config.yml`で設定をカスタマイズ（オプション）
4. `/bentobox reload`を実行するか、サーバーを再起動して新しい設定を適用します

!!! warning "DeathChestは`keepInventory`がオンの間、何もしません"
    `keepInventory`ゲームルールがプレイヤーのインベントリを保つ場合、保存するドロップはなく、アドオンは脇に身を引きます。デスチェストがプレイヤーのアイテムを保存するものにしたい場合は、ゲームモードワールドで`keepInventory`をオフにしてください。

## コマンド

!!! tip
    `[player command]`と`[admin command]`は、実行しているゲームモードによって異なります。
    ゲームモードの`config.yml`は、それらを変更できる設定を含みます。
    例えば、BSkyBlockでは、デフォルト`[player command]`は`island`で、デフォルト`[admin command]`は`bsbadmin`です。

### deathchest
**コマンド**: `/[player command] deathchest`
**エイリアス**: `deaths`, `grave`
**説明**: あなたのデスチェストをリストします、最新順、各チェストは どこにあるか、どのくらい残っているか。
**権限**: `[gamemode].deathchest`. デフォルト: `true`.

チェストがプレイヤーではなくアドオンで保有されている場合、座標で表示される代わりに「保有」として表示されます。

### deathchest claim {number}
**コマンド**: `/[player command] deathchest claim {number}`
**説明**: アドオンが保有しているアイテムと保存されたエクスペリエンスをハンドオーバーします。プレイヤーのインベントリに合わないアイテムは、彼らの足に落ちます。
**権限**: `[gamemode].deathchest`. デフォルト: `true`.
**例**: `/[player command] deathchest claim 1`

これは、プレイヤーが世界に配置できなかったチェストを回復する方法です。また、任意のオーバーフロー—[アイテムの保存方法](#how-items-are-stored)を参照—を収集します。

### deathchest tp {number}
**コマンド**: `/[player command] deathchest tp {number}`
**説明**: プレイヤーをそのデスチェストにテレポート。
**権限**: `[gamemode].deathchest.teleport`. デフォルト: `true`.
**例**: `/[player command] deathchest tp 1`

`config.yml`で`commands.allow-teleport`が`true`である必要があります。世界にブロックがないチェストは訪問できません—代わりにクレームしてください。

### admin deathchest
**コマンド**: `/[admin command] deathchest`
**説明**: サーバーに保存されているデスチェストの数を報告します。
**権限**: `[gamemode].admin.deathchest`. デフォルト: `op`.

### admin deathchest {player}
**コマンド**: `/[admin command] deathchest {player}`
**エイリアス**: `deathchests`
**説明**: プレイヤーのデスチェストをリストします。チェストはどこにあり、どこで死んだかを表示します。それらの2つは、チェストがアイランドに移動されたときに異なります。これにより、ボイドまたは海での死を簡単に確認できます。
**権限**: `[gamemode].admin.deathchest`. デフォルト: `op`.
**例**: `/[admin command] deathchest tastybento`

### admin deathchest purge
**コマンド**: `/[admin command] deathchest purge`
**説明**: すでに期限切れのすべてのチェストを期限切れにする、すぐに、次のチェックを待つ代わりに。
**権限**: `[gamemode].admin.deathchest`. デフォルト: `op`.

!!! tip
    `[gamemode]`は、実行しているゲームモードによって異なるプレフィックスです。
    プレフィックスはゲームモードの小文字名です。例えば、BSkyBlockを使用している場合、プレフィックスは`bskyblock`です。
    同様に、AcidIslandを使用している場合、プレフィックスは`acidisland`です。

## 権限

| 権限 | デフォルト | 説明 |
|---|---|---|
| `[gamemode].deathchest` | `true` | `/[player command] deathchest`を使用してチェストを一覧表示し、保有アイテムをクレーム |
| `[gamemode].deathchest.teleport` | `true` | `/[player command] deathchest tp {number}`を使用 |
| `[gamemode].admin.deathchest` | `op` | 管理者コマンドを使用 |

## アイテムの保存方法

チェストブロックがアイテムを保有します。プレイヤーのインベントリは、鎧とオフハンドを含む41スロット、チェストは27です。なので**オーバーフロー通常より一般的**です。

収まらないものはアドオンで保有され、プレイヤーがそれを閉じるたびにチェストに自動的に移動されます。だからプレイヤーはチェストを空にし、閉じて、次のアイテムが表示される—何もなくなるまで。チェストとアドオンのストア両方が両方とも空になったら、チェストブロックはそのレコードとともに消えます。

チェストブロックがアドオンが引き起こさなかった理由のために消える場合—ワールドエディット、ロールバック、手動`/setblock`—レコードは生存し、`deathchest claim`で回復できる保有チェストになります。

## 保護

所有者のみが自分のデスチェストを開いたり、壊したりすることができます。その他の人は拒否され、チェストが誰のものかを告げられます。

- `chest.team-access`はそれをアイランドチームメンバーに拡張しますが、チェストが所有者と他のプレイヤーの両方が属するアイランドに座っている場合のみ。
- `chest.protect-from-explosions`はデスチェストをクリーパー、TNT、ベッド爆発ブロックリストから保ちます。
- アイランドがリセットまたは削除されるとレコードが削除されます。ブロックは一緒に削除されるので。

!!! warning "ホッパーはブロックされていません"
    デスチェストの下のホッパーはそれを排出します。チェストは所有者のアイランドにあるので、これは略奪の代わりに自分で引き起こされます。しかし、プレイヤーがアイランドホームの近くにソートシステムを構築する場合、それは知る価値があります。[issue #5](https://github.com/BentoBoxWorld/DeathChest/issues/5)として追跡。

## 設定

`config.yml`ファイルは以下の設定を含みます。表示されている値がデフォルトです。

### ゲームモードを無効にする
DeathChestはデフォルトでBentoBoxサーバー上のすべてのゲームモードワールドで動作します。
ゲームモードを無効にするには、その名前を新しい行に書いて、`-`で開始します。

例えば、BSkyBlockを無効にするには：

```yml
disabled-gamemodes:
  - BSkyBlock
```

デフォルト値：

```yml
disabled-gamemodes: []
```

### チェスト素材
デスチェストに使用されるブロック。

`CHEST`はクラシックな見た目です。`BARREL`は、直接上のブロックがあってもオープンできるので、狭いアイランドに良い選択です。

素材はコンテナである必要があります。ない場合—または名前が実際の素材ではない場合—アドオンはエラーをログして、プレイヤーのアイテムを保有することにフォールバックします。

```yml
chest:
  material: CHEST
```

### 死亡位置にあるプレース
プレイヤーが死んだ場所にチェストを配置します。到達できて構築できる場所が必要な場合。

ステージ2（アイランドホーム）に常にチェストを送信するために`false`に設定します。

ボイド、構築可能エリア外、または到達不可能なスポットでの死は、この設定に関係なくアイランドホームにフォールバックします。

```yml
chest:
  place-at-death-location: true
```

### 検索半径
チェストを置く自由なスポットを**横に**、ブロック単位で見る距離。範囲1〜32。

```yml
chest:
  search-radius: 8
```

### 検索深度
チェストを置く地面を見つけるために**下向き**に見る距離、ブロック単位で。範囲1〜64。

これはプレイヤーから離れて遠く着陸するチェストを停止する—オーシャンワールドの海底、または地形に埋まった。この距離内に地面が見つからない場合、チェストはプレイヤーのアイランドに行きます。通常はあなたが望む場所です。

それを上げると、チェストは地面に長い落下を追跡します。下げると、より多くの死がアイランドに送信されます。

```yml
chest:
  search-depth: 16
```

### 有効期限分
デスチェストが期限切れになるまでの分数。`0`は決して意味します。

```yml
chest:
  expiry-minutes: 60
```

### 有効期限アクション
デスチェストの有効期限が切れたときに何が起こるか。

- `DROP` — チェストを壊し、アイテムが地面に落ちるようにします。他の落ちたアイテムのように消えます。
- `DELETE` — チェストとその内容を削除します。

```yml
chest:
  expiry-action: DROP
```

### 有効期限チェック秒
期限切れのチェストをチェックする頻度。秒単位。最小5。

```yml
chest:
  expiry-check-seconds: 60
```

### プレイヤーあたりの最大
プレイヤーが一度に持つことができるデスチェストの最大数。超過すると、プレイヤーの最古のチェストは早く期限切れになり、上記の`expiry-action`に従います。`0`は無制限を意味します。

これは、死ぬのを続けるプレイヤーがアイランドにチェストを散らかすのを防ぎます。

```yml
chest:
  max-per-player: 3
```

### チームアクセス
アイランドチームメンバーが互いのデスチェストを開くことができます。

所有者のみが自分のチェストを開くべき場合は`false`に設定します。

```yml
chest:
  team-access: true
```

### 爆発から保護
デスチェストがクリーパー、TNTなどで爆破されるのを防ぎます。

```yml
chest:
  protect-from-explosions: true
```

### 経験を保存
プレイヤーがドロップした経験をチェストと一緒に保存し、それが開かれたときに戻します。

```yml
experience:
  store: true
```

### 経験パーセント
プレイヤーがドロップした経験のパーセンテージを保存します。0〜100。残りは失われます。これは死ぬことで何か費やします。

`experience.store`が`true`の場合のみ適用されます。

```yml
experience:
  percent: 100
```

### 死で通知
プレイヤーが死ぬときにデスチェストがどこにあるかを教え、どのくらい続くか。

メッセージは、ゲームモードのフレンドリー名を使用してワールドに名前を付け、死亡がオーバーワールドにない場合は`Nether`または`The End`を追加します。

```yml
notify:
  on-death: true
```

### テレポートを許可
`/[player command] deathchest tp {number}`がプレイヤーをチェストにテレポートすることを許可します。

プレイヤーはまだ`[gamemode].deathchest.teleport`権限が必要です。

```yml
commands:
  allow-teleport: true
```
