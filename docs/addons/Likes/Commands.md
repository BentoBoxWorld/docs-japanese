**利用可能なコマンド（バージョン 1.7.0 時点）**

| コマンド | 権限 | 説明 |
|------|------|------|
| /[gamemode_user] likes | [gamemode].likes | 他のプレイヤーのアイランドにいいねを追加したり、自分のアイランドのいいねを確認するための GUI を開きます |
| /[gamemode_user] likes view | [gamemode].likes.view | 自分のアイランドのいいね一覧を表示する GUI を開きます |
| /[gamemode_user] likes view <player> | [gamemode].likes.view.others | 対象プレイヤーのアイランドのいいね一覧を表示する GUI を開きます |
| /[gamemode_user] likes top <type> | [gamemode].likes.top | 指定した種類のアイランドトップを表示する GUI を開きます |
| /[gamemode_admin] likes | [gamemode].likes.admin | 管理者 GUI を開きます |
| /[gamemode_admin] likes settings | [gamemode].likes.admin.settings | アドオン設定 GUI を開きます |
| /[gamemode_admin] likes view <player> | [gamemode].likes.admin | 対象プレイヤーのアイランドのいいね一覧を表示する GUI を開きます |
