## **Limits** (addon.yml)

[gamemode] をゲームモード名（例: bskyblock、acidisland など）に置き換えてください。

| **権限**                            | **有効にするユーザー** | **説明**                               |
|-------------------------------------|----------------|----------------------------------------|
| [gamemode].mod.bypass               | op             | プレイヤーが制限をバイパスできます |
| [gamemode].limits.admin.limits      | op             | プレイヤーが管理者用 limits コマンドを使用できます |
| [gamemode].limits.player.limits     | true           | プレイヤーが limits コマンドを使用できます |
