# Stranger Realms: BentoBoxゲームモード

見慣れた世界が恐ろしい逆転次元に覆われた、身震いするような新しいサバイバル体験。*Stranger Realms*はネザーを暗く荒廃したオーバーワールドのコピー——**アップサイドダウン**——に置き換えるカスタムBentoBoxゲームモードです。

## 🌌 ゲームコンセプト：アップサイドダウンへようこそ

現実が歪んだ世界へ飛び込もう。人気テレビ番組に登場する戦慄の次元からインスパイアされたアップサイドダウンは、絶え間ない暗闇と危険の次元です。

  * **反転:** アップサイドダウンは、オーバーワールドのブロックをそのまま複製した暗く荒廃した次元です。プレイヤーが初めてその場所に入るとき、動的に生成されます。
  * **汚染されたモブ:** オーバーワールドの動物たちが汚染されています。ほとんどのオーバーワールドモブはネザーの対応するモブに変化し、独特で危険な遭遇を生み出します。
  * **グリマー（次元リンク）:** 操作するものには注意してください！アップサイドダウンでレバーを引いたりボタンを押したりすると、オーバーワールドの対応するブロックで同じ動作が引き起こされることがあります。この危険なつながりは隠れた自動化に利用することもできますし、向こう側に潜む邪悪なものにあなたの位置を露わにしてしまうこともあります。

## ✨ 主な機能

### 保護されたクレーム（BentoBoxコア）

BentoBoxゲームモードとして、サバイバルはワールドの一画を確保することにかかっています。

  * **セキュリティ:** クレームは保護された正方形エリアで、デフォルトの一辺は64ブロックです。
  * **カスタマイズ:** 強力なBentoBox設定GUIを使用してクレームの権限を細かく調整できます——訪問者がブロックを破壊できるか、コンテナを使用できるか、またはアクセスを完全に制限するかなど。
  * **次元をまたいだ保護:** クレームはオーバーワールドとアップサイドダウンの**両方**、そしてエンドでも保護されます！
  * **協力的な成長:** クレームは大きくなります！他のプレイヤーをメンバーとしてクレームに追加することでサイズが拡大します。メンバーあたりのクレーム成長量は設定可能です。

### ワープドコンパス

  * **チャンク再生成:** **ワープドコンパス**のカスタムレシピを発見しましょう。プレイヤーがこの強力なアイテムを持ちながらネザーポータルを通過すると、すべての方向のチャンクが強制再生成され、常にオーバーワールドを元にした新しい領域を探索できるようになります。

### ダイナミックワールドボーダー（管理者機能）

ダイナミックワールドボーダーオプションでプレイヤーをサーバーに誘い込み、成長させましょう。

  * **適応サイズ:** 管理者は現在のオンラインプレイヤー数に基づいて自動的に拡大・縮小するワールドボーダーを設定できます。サーバーに人が集まれば、プレイ可能エリアが広がります！
  * **クレームの保持:** ワールドボーダーが縮小した場合でも、プレイヤーのクレームが新しいボーダーの外に出ても保持されます。ただし、ボーダーの外に出ると既存のクレームの保護境界内でのみ活動できるようになり、戦略的な土地所有が促されます。

## 🔨 コマンド

*Stranger Realms*は堅牢なBentoBoxコマンド体系を使用しています。コマンドの一覧は[こちら](Commands)をご覧ください。

メインのプレイヤーコマンドは`/strange`または`/st`で、管理者コマンドは`/stranger`です。

| コマンド        | 説明                                                                                                            |
|:---------------|:-----------------------------------------------------------------------------------------------------------------------|
| `/st claim`    | 現在地にクレームを作成します（余裕がある場合）。                                                                           |
| `/st info`     | 現在立っているクレームの情報を表示します。                                                                       |
| `/st settings` | クレーム権限（訪問者のブロック破壊、チェストアクセスなど）を管理するGUIを開きます。                                   |
| `/st team`     | チームGUIを開き、プレイヤーをクレームのメンバーとして招待できます。参加するとクレームサイズも増加します。 |

## 他のアドオンとの併用

すべてのBentoBoxゲームモードと同様に、他のアドオンを読み込むことができます。以下のアドオンが推奨されます：

* Warps - プレイヤーがクレームにワープサインを設置して他のプレイヤーがテレポートできるようにする
* InvSwitcher - ゲームモード間でインベントリやその他のプレイヤーデータを分離する

Stranger Realmsでは*Border*アドオンを使用しないでください。競合が発生します。Stranger Realmsは独自のボーダーを管理しています。

## ⚙️ 設定

ゲームの核となるメカニクスとクレーム機能は、BentoBoxの設定ファイルまたはGUIで柔軟に設定できます。このゲームモードの主な設定ファイルは`config.yml`です。
