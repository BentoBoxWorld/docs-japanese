# CaveBlock

**CaveBlock**では~~ドワーフ~~プレイヤーが地下でサバイバルします。採掘して、クラフトして、穴を掘ろう（*掘れ掘れ穴を掘れ*）！

作成・メンテナンス: [BONNe](https://github.com/BONNe)

{{ addon_description("CaveBlock") }}

## インストール

0. BentoBoxをインストールし、データフォルダを生成するためサーバーを少なくとも1回起動します。
1. このjarファイルをBentoBoxプラグインのaddonsフォルダに配置します。
2. サーバーを再起動します。
3. アドオンがワールドとデータフォルダを作成し、フォルダ内にconfig.ymlが生成されます。
4. サーバーを停止します。
5. config.ymlを希望通りに編集します。
6. ワールドの生成に関わる設定を変更した場合は、初回起動で作成されたワールドフォルダを削除します。
7. サーバーを再起動します。

## 設定

メインの`config.yml`ファイルには、ゲームモードアドオンのセットアップに関する基本情報が含まれています。

### config.yml

アドオンが正常にインストールされると、config.ymlファイルが作成されます。このファイルのすべての設定にはコメントが付いています。詳細はファイルをご確認ください。

最新の設定ファイルはこちら: [config.yml](https://github.com/BentoBoxWorld/CaveBlock/blob/develop/src/main/resources/config.yml)

!!! info "ワールド生成が1.21.0で再設計されました"
    **1.21.0**以降、オーバーワールドはMinecraftの独自のバニラ1.18+ノイズジェネレーターで彫刻され、島は本物のチーズ、スパゲッティ、ラッシュ、鐘乳石、深暗洞窟 — バニラの鉱石、装飾、構造、地下バイオーム全てを備えています。各列の上にはワールドが堅い岩のままで空が開かないようにキャップされています。サーバーはいま彫刻、鉱石、バイオームを処理するため、古いブロック置換生成オプション（`generation-tries`、`use-new-material-generator`、次元別の`blocks`リスト、および`natural-*`トグル）は削除されました。ネザーとエンドは新しい鉱石脈ポピュレーターで充填・装飾アプローチを保持します。アップグレード前に、このページの下部の変更履歴を参照してください。

=== "world.world-depth"
    !!! summary "説明"
        ワールドの深さは、ワールドでブロックが生成される高さを示します。-64に設定すると、基本的な虚空ワールドが作成されます。

        洞窟の上に新鮮な空気を作ることができます。

=== "world.normal.roof"
    !!! summary "説明"
        オーバーワールドの最上部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合は石になります。

=== "world.normal.floor"
    !!! summary "説明"
        オーバーワールドの最下部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合は石になります。

=== "world.normal.main-block"
    !!! summary "説明"
        バニラで生成された地形の上の空のギャップを埋めるために使用されるメインブロック。バニラ洞窟彫刻、鉱石、構造、地下バイオーム（ラッシュ洞窟、鐘乳石洞窟、深暗）はサーバーによって生成されます；この設定は表面層を充填するために使用されるマテリアルのみに影響します。AIRに設定すると洞窟の上に空が開いたままになります。

=== "world.nether.roof"
    !!! summary "説明"
        ネザーの最上部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合はネザーラックになります。

=== "world.nether.floor"
    !!! summary "説明"
        ネザーの最下部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合はネザーラックになります。

=== "world.nether.main-block"
    !!! summary "説明"
        ネザーワールド生成に使用されるメインブロックを設定できます。AIRに設定すると虚空ワールドが作成されます。鉱石脈（古代デブリ、ネザークォーツ、黒曜石、グロウストーンなど）は脈ポピュレーターによってこれの上に配置されます。

=== "world.end.roof"
    !!! summary "説明"
        エンドの最上部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合はエンドストーンになります。

=== "world.end.floor"
    !!! summary "説明"
        エンドの最下部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合はエンドストーンになります。

=== "world.end.main-block"
    !!! summary "説明"
        エンドワールド生成に使用されるメインブロックを設定できます。AIRに設定すると虚空ワールドが作成されます。鉱石脈は脈ポピュレーターによってこれの上に配置されます。

## コマンド

!!! tip
    `[player_command]`と`[admin_command]`は実行中のゲームモードによって異なるコマンドです。
    
    ゲームモードの`config.yml`ファイルにはこれらの値を変更するオプションがあります。
    
    例えば、CaveBlockでは、デフォルトの`[player_command]`は`cave`、デフォルトの`[admin_command]`は`cba`です。
    
    このアドオンではアドオンの`config.yml`ファイルでプレイヤーコマンドのエイリアスを変更できることに注意してください。


BentoBox GameModeアドオンには標準のサブコマンドセットが付属しており、CaveBlock固有のサブコマンドも追加されています。

## 変更履歴

!!! warning "v1.21.0 の新機能 — Breaking: ワールド生成が再設計"
    **リリース日:** 2026-06-27

    大規模な生成オーバーホール。CaveBlockは**Java 21上のPaper 1.21.11**と**BentoBox 3.14 API**を対象としています。

    - 🔺 **バニラ洞窟ワールド生成。** オーバーワールドはMinecraftの独自の1.18+ノイズジェネレーターに委譲されるため、島は本物のチーズ、スパゲッティ、ラッシュ、鐘乳石、深暗洞窟で彫刻され、バニラの鉱石、装飾、構造（鉱山、ダンジョン、試験の部屋、紫水晶地柱、古代都市）、地下バイオームが完備されています。空は石でキャップされるため、ワールドはベドロックから屋根まで堅い岩のままです。
    - 💎 **再設計されたネザー＆エンド鉱石脈。** ネザーとエンドは充填と装飾アプローチを保持し、単一ブロックの代わりに適切にサイズ設定された鉱石塊（古代デブリ、クォーツ、黒曜石、グロウストーンなど）を配置する新しい脈ポピュレーターがあります。
    - ⚙️ **設定クリーンアップ。** ワールド生成設定が再設計され、無効なオプションが削除されました — `generation-tries`、`use-new-material-generator`、ディメンションごとの`blocks`リスト、`natural-surface`/`natural-caves`/`natural-bedrock`トグル、古い`netherBlocks`/`endBlocks`/`debug`設定がなくなりました。アドオンに新しいデフォルトを書かせる前に、既存の`config.yml`をバックアップしてください。
    - 🔡 **MiniMessageロケール。** すべてのロケールファイルがレガシーカラーコードからMiniMessageに移行され、高さ制限メッセージキーは`caveblock.general.errors.cave-limit-reached`に改名されました。カスタマイズしたロケールファイルがある場合は、再生成してください。
    - 🧪 生成、高さ制限、アドオンのライフサイクルを保護するために、完全なJUnit 5 + MockBukkitテストスイートが追加されました。

    🔺 **ワールド生成が変更されました:** 新しく生成されたオーバーワールドチャンクはソリッド充填彫刻の代わりにバニラノイズ洞窟を使用するようになります。既に生成されたチャンクは変更されていませんが、ワールドのエッジの新しい地形は古い領域と異なります。これが重要な場合は、最初にコピーでテストしてください。

    [Release v1.21.0](https://github.com/BentoBoxWorld/CaveBlock/releases/tag/1.21.0)
