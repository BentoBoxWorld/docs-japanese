# CaveBlock

**CaveBlock**では~~ドワーフ~~プレイヤーが地下でサバイバルします。採掘して、クラフトして、穴を掘ろう（*掘れ掘れ穴を掘れ*）！

作成・メンテナンス: [BONNe](https://github.com/BONNe)

{{ addon_description("CaveBlock") }}

## インストール

0. BentoBoxをインストールし、データフォルダが作成されるまでサーバーで少なくとも1回起動します。
1. このjarファイルをBentoBoxプラグインのaddonsフォルダに配置します。
2. サーバーを再起動します。
3. アドオンがワールドとデータフォルダを作成し、フォルダ内にconfig.ymlが生成されます。
4. サーバーを停止します。
5. config.ymlを希望通りに編集します。
6. 変更内容がワールドに影響する場合は、デフォルトで作成されたワールドを削除します。
7. サーバーを再起動します。

## 設定

メインの`config.yml`ファイルには、ゲームモードアドオンのセットアップに関する基本情報が含まれています。

### config.yml

アドオンが正常にインストールされると、config.ymlファイルが作成されます。このファイルのすべての設定にはコメントが付いています。詳細はファイルをご確認ください。

最新の設定ファイルはこちら: [config.yml](https://github.com/BentoBoxWorld/CaveBlock/blob/develop/src/main/resources/config.yml)

=== "world.world-depth"
    !!! summary "説明"
        ワールドの深さは、ワールドでブロックが生成される高さを示します。-64に設定すると、基本的な虚空ワールドが作成されます。

        洞窟の上に新鮮な空気を作ることができます。

=== "world.generation-tries"
    !!! summary "説明"
        メインの次元ブロックを鉱石ブロックに変更するための試行回数を指定できます。

=== "world.use-new-material-generator"
    !!! summary "説明"
        改良されたマテリアルジェネレーターは、バニラに近い鉱石の塊、花崗岩、閃緑岩、凝灰岩のパッチを生成し、一部の深層岩を使用します。

        ただし、次元ブロック設定を通じて追加するカスタマイズが無効になります。

=== "world.normal.roof"
    !!! summary "説明"
        オーバーワールドの最上部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合は石になります。

=== "world.normal.natural-surface"
    !!! summary "説明"
        ワールドジェネレーターが土と草ブロックを使用した自然に見える表面を生成するかどうかを切り替えられます。
        現在、自然に見える表面とは土と草のブロック層のことです。

        このオプションは`world.normal.roof`オプションを無効にします。

=== "world.normal.natural-caves"
    !!! summary "説明"
        ワールドジェネレーターがバニラのワールドと同様の自然な洞窟を生成するかどうかを切り替えられます。
        洞窟はすべてのブロックとバイオームと共に生成されます。

=== "world.normal.floor"
    !!! summary "説明"
        オーバーワールドの最下部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合は石になります。

=== "world.normal.natural-bedrock"
    !!! summary "説明"
        オーバーワールドのベドロックをバニラのワールドと同様に4ブロックの高さで生成するかどうかを切り替えられます。

=== "world.normal.main-block"
    !!! summary "説明"
        オーバーワールドの生成に使用するメインブロックを設定できます。AIRに設定すると虚空ワールドが作成されます。

=== "world.normal.blocks"
    !!! summary "説明"
        ランダムな確率でメインブロックを置き換えるブロックです。
        ブロックはメインブロックのみを置き換え、文字列で設定されたパックを作ろうとします。スポーン確率も必要です。
        
        マテリアルの場合、最初の文字列はMATERIAL、エンティティの場合はENTITYでなければなりません。
        
        ジェネレーターでスポーンしたエンティティはデスポーンから保護されません。
        現在、高さ2のモブにのみ対応しています。

    !!! example "例"
        ```yaml
            blocks:
                - MATERIAL:DIAMOND_ORE:100:5 
        ```        
        これはダイヤモンドが100%の確率でスポーンし、サブチャンクあたり最大5個のパックを形成することを意味します！

=== "world.nether.roof"
    !!! summary "説明"
        ネザーの最上部ブロックをベドロックにするかどうかを切り替えられます。それ以外の場合はネザーラックになります。

## コマンド

!!! tip
    `[player_command]`と`[admin_command]`は実行中のゲームモードによって異なるコマンドです。
    
    ゲームモードの`config.yml`ファイルにはこれらの値を変更するオプションがあります。
    
    例えば、CaveBlockでは、デフォルトの`[player_command]`は`cave`、デフォルトの`[admin_command]`は`cba`です。
    
    このアドオンではアドオンの`config.yml`ファイルでプレイヤーコマンドのエイリアスを変更できることに注意してください。


デフォルトでは、BentoBox GameModeアドオンにはデフォルトのサブコマンドセットが付属していますが、各アドオンにはさらに多くのサブコマンドがある場合があります。

[CaveBlockコマンドの完全一覧](Commands)

## パーミッション

!!! tip
    CaveBlockアドオンのすべての場所で`[gamemode]`プレフィックスは`caveblock`に置き換える必要があります。

デフォルトでは、BentoBox GameModeアドオンにはデフォルトのサブパーミッションセットが付属していますが、各アドオンにはさらに多くのサブパーミッションがある場合があります。
