# AcidIsland

**AcidIsland** は、プレイヤーが酸の海に囲まれた島でサバイバルしなければならないゲームモードです。

作成・メンテナンス: [tastybento](https://github.com/tastybento)

{{ addon_description("AcidIsland") }}

## ストーリー
あなたは酸の海に浮かぶ島にいます！スカイブロックが好きなら、新しい挑戦としてAcidIslandを試してみてください！

これはスカイブロックのバリエーションです。落下する代わりに、島を拡張する際には酸の水に気をつけなければなりません。また、プレイヤーはボートで互いの島に移動することができます。

## インストール

0. BentoBoxをインストールし、データフォルダが作成されるまでサーバーで少なくとも1回起動します。
1. このjarファイルをBentoBoxプラグインのaddonsフォルダに配置します。
2. サーバーを再起動します。
3. アドオンがワールドとデータフォルダを作成し、フォルダ内にconfig.ymlが生成されます。
4. サーバーを停止します。
5. config.ymlを希望通りに編集します。
6. 変更内容がワールドに影響する場合は、デフォルトで作成されたワールドを削除します。
7. サーバーを再起動します。
