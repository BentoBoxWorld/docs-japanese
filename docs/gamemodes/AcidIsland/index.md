# AcidIsland

**AcidIsland** は、酸の海に囲まれた島でプレイヤーが生き残りを賭けるゲームモードです。

作成・メンテナンス: [tastybento](https://github.com/tastybento)

{{ addon_description("AcidIsland") }}

## ストーリー
酸の海に浮かぶ小さな島から始まりましょう！スカイブロックが好きなら、新たな挑戦としてAcidIslandがぴったりです。

スカイブロックの変種ですが、虚空の代わりに危険な酸の海があなたを待っています。落ちれば只では済みません。また、ボートで他のプレイヤーの島に渡ることもできます。

## インストール

0. BentoBoxをインストールし、データフォルダを生成するためサーバーを少なくとも1回起動します。
1. このjarファイルをBentoBoxプラグインのaddonsフォルダに配置します。
2. サーバーを再起動します。
3. アドオンがワールドとデータフォルダを作成し、フォルダ内にconfig.ymlが生成されます。
4. サーバーを停止します。
5. config.ymlを希望通りに編集します。
6. ワールドの生成に関わる設定を変更した場合は、初回起動で作成されたワールドフォルダを削除します。
7. サーバーを再起動します。

### 浄化された水

!!! new "AcidIsland 1.22.0で追加"
    酸の海は相変わらず危険ですが、ついに水を**浄化**できるようになりました。酸の水入り瓶を飲むとバニラの毒エフェクトがかかり、浄化された水入り瓶を飲むと体力が回復します。どのアイテムが安全かひと目で分かるよう、水アイテムには色付きの説明文が付きます。水を浄化する方法は4通り ― かまどで水入り瓶や水バケツを精錬する、醸造台で水入り瓶を石炭と組み合わせる、鍾乳石の滴を大釜に集める ― のどれでもお好みで。

??? note "acid.purified-water.enabled"
    浄化された水の機能全体のマスタースイッチです。`false` にすると、タグ付け、かまど/醸造の介入、大釜の追跡がすべて停止します。

    デフォルト: `true`

??? note "acid.purified-water.heal-amount"
    浄化された水入り瓶を飲んだときに回復するハートの半分単位の量です。`4.0` はハート2個分になります。

    デフォルト: `4.0`

??? note "acid.purified-water.bucket-furnace-enabled"
    かまどで水バケツを精錬して浄化された水バケツを作ることを許可します。精錬時間は100秒（瓶の5倍）です。サーバーのバランス上「簡単すぎる」と感じる場合は `false` に設定してください。

    デフォルト: `true`

??? note "acid.purified-water.nether-enabled"
    このアドオンのネザーワールド（島型・バニラ型どちらも）で浄化された水の仕組みを有効にします。

    デフォルト: `true`

??? note "acid.purified-water.end-enabled"
    このアドオンのエンドワールド（島型・バニラ型どちらも）で浄化された水の仕組みを有効にします。

    デフォルト: `true`

### 硫黄の海

!!! new "AcidIsland 2.0.0 で追加"
    Minecraft 26.2 以降では、酸の海は酸性の緑色をした硫黄水になり、あちこちで泡立つ硫黄噴出孔が水面に吐き気のガスを漂わせ、周期的に間欠泉として噴出します。海底は砂・砂利・砂岩・凝灰岩を重み付けで混ぜたものにマグマブロックが泡立ち、26.2 以降ではさらに硫黄と辰砂が散りばめられます。同じ jar は Minecraft 1.21.x のサーバーでも引き続き動作し、その場合 26.2 の機能は自動的に無効になり、水は従来の温暖な海にフォールバックします。

!!! warning "これらはワールド生成の設定です"
    以下の3つのオプションはすべて、チャンクが生成される時点で焼き込まれます。BentoBox はこれらをゲーム中に変更することをサポートしていません — 既存のチャンクは現在の見た目のままなので、新しいワールドで始めない限り、古いチャンクの境界で見た目の継ぎ目が生じることを想定してください。

??? note "world.default-biome"
    オーバーワールドのデフォルトバイオームです。`SULFUR_CAVES`（Minecraft 26.2 以降）にすると、酸性の緑色をした水とそれに合った緑色の霧になります。それより古いサーバーではこのバイオームが存在しないため、代わりに `WARM_OCEAN` が使用されます。

    デフォルト: `SULFUR_CAVES`（2.0.0 より前は `WARM_OCEAN`）

??? note "world.sulfur-vent-chance"
    海面のすぐ下に硫黄噴出孔が生成される、チャンクあたりの確率（0～100）です。噴出孔は濃硫黄をマグマブロックの上に重ねた構造で、泡立ち、ガスを出し、間欠泉として噴出します。形状は煙突型・マウンド型・双子型・とがった岩塊型の4種類の自然な形があり、ランダムに変化します。Minecraft 26.2 以降が必要で、それより古いサーバーでは無視されます。

    デフォルト: `10`

??? note "world.make-structures"
    ワールドにバニラの構造物を生成します。トライアルチャンバーなどの地下構造物は海底の下に埋まった状態で生成されるため、プレイヤーが地下を掘り進める理由になり、スターターキットのトライアルキーを実際に使えるようになります。

    デフォルト: `true`（2.0.0 より前は `false`）

## 変更履歴

!!! warning "v2.0.0の新機能 — 硫黄の海（ワールド生成の変更）"
    **リリース日:** 2026-07-20

    AcidIsland は Minecraft 26.2 の硫黄プールを、酸の海を象徴する見た目として取り入れます。互換性: BentoBox API 3.14.0 · Minecraft 1.21.11 – 26.2（硫黄関連の機能には 26.2 以降が必要）· Java 21。

    - ⚙️ **酸性の緑色をした硫黄水。** オーバーワールドのデフォルトバイオームが `SULFUR_CAVES` になり、すべての水が酸性の緑色に、霧もそれに合った緑色になります。26.2 より古いサーバーではこのバイオームが存在しないため、ワールドは `WARM_OCEAN` にフォールバックします。
    - ⚙️ **硫黄噴出孔と間欠泉。** 海面のすぐ下に濃硫黄の噴出孔が生成されます。泡が立ち、水面には吐き気のガス雲が漂い、周期的に間欠泉が噴出します。形状は4種類の自然な形があり、ランダムに変化します。チャンクあたりの確率は新しい `world.sulfur-vent-chance` オプション（デフォルト 10%）で設定します。Minecraft 26.2 以降が必要です。
    - **変化に富んだ海底。** これまで殺風景な砂だけだった海底が、砂・砂利・砂岩・凝灰岩を重み付けで混ぜたものになり、マグマブロックが泡立ち、26.2 以降ではさらに硫黄と辰砂が加わります。それより古いサーバーでは、26.2 のブロックの代わりに砂利と凝灰岩が使われます。
    - **新しいスターター島「Sulfur Spring Refuge」。** 逞しいトウヒの露頭に落ち葉、アイブロッサム、ウィザーローズ、ポドゾル、その下に凝灰岩の聖域、そしてヤギが1匹。スターターキットは桜の林の島と同じ実用的な内容です。すべて 1.21 で安全に使えるブロックだけで作られています。
    - ⚙️ **構造物がデフォルトで有効に。** `world.make-structures` のデフォルトが `true` になり、トライアルチャンバーなどの地下構造物が海底の下に埋まった状態で生成されます。

    🔺 **ワールド生成の変更です。** 新しい水のバイオーム、噴出孔、海底、構造物はすべてチャンク生成時に焼き込まれます。既存のワールドでは、探索済みのチャンクは現在の見た目のままです。2.0.0 を完全に体験するには新しいワールドで始めるか、古いチャンクの境界で見た目の継ぎ目が生じることを想定してください。

    ⚙️ **既存の設定は変更されません。** お使いの `config.yml` は保存されている値をそのまま保持します。既存の環境で新しいデフォルトを採用するには、`default-biome: SULFUR_CAVES` と `make-structures: true` を設定し、`sulfur-vent-chance: 10` を追加するか、設定ファイルを削除して再生成してください。

    🔺 **既存環境での新しいブループリント。** BentoBox は同梱のブループリントを、ブループリントフォルダが*存在しない*場合にのみ展開します。既存の環境で新しい島の選択肢を表示するには、`sulfur-spring.blueprint` と `sulfur_spring.json` を jar から `plugins/BentoBox/addons/AcidIsland/blueprints/` にコピーしてください。

    [Release v2.0.0](https://github.com/BentoBoxWorld/AcidIsland/releases/tag/2.0.0)

??? note "v1.22.1の新機能"
    **リリース日:** 2026-06-28

    メンテナンスリリースです。設定やロケールの変更は不要です。

    - 🐛 **`addon.yml` の重複したパーミッションキーを修正しました。** 複数のコマンドが1つのパーミッションノードを共有するのは正当なことですが — `/ai ban`、`/ai unban`、`/ai banlist` はいずれも `acidisland.island.ban` を使います — これらが同じキーを持つ別々のYAMLエントリとして書かれていました。YAML は重複したキーのうち最後のものだけを残すため、先に書かれたパーミッションの説明が何も告げずに失われ、サーバーは読み込みのたびに `duplicate keys found` を出力していました。共有されるノードはそれぞれ、説明をまとめた1つのエントリになり、起動時の警告はなくなりました。
    - 公開されているゲームバージョンの一覧に Minecraft 26.2 を追加しました（26.1.2 も遡って追加）。

    [Release v1.22.1](https://github.com/BentoBoxWorld/AcidIsland/releases/tag/1.22.1)

??? note "v1.22.0の新機能 — 浄化された水の仕組み"
    **リリース日:** 2026-04-15

    酸の水を浄化して、安全に飲んだり、農業に使ったり、瓶詰めにして持ち歩けるようになりました。すべての水アイテムには <span style="color:red">Acid Water</span> または <span style="color:green">Purified Water</span> の色付きの説明文が付き、大釜はサーバー再起動をまたいで中の水の状態を覚えています。

    - ⚙️ **浄化された水を追加** — 浄化方法は4通り。かまどで水入り瓶を精錬する（10秒）、醸造台で水入り瓶と石炭を組み合わせる、かまどで水バケツを精錬する（100秒、オン/オフ切替可能）、または鍾乳石の滴を大釜に集める。
    - ⚙️ **飲用時の効果** — 酸の水入り瓶はバニラの毒エフェクトを付与し、浄化された水入り瓶は体力を回復します（回復量は `acid.purified-water.heal-amount` で調整可能）。
    - ⚙️ 新しい設定ブロック `acid.purified-water.*` を追加（詳細は上の「設定」セクションを参照）。マスタースイッチ、回復量、水バケツのかまど精錬の切替、ネザー/エンドごとの切替を含みます。
    - 🔡 `acidisland.purified-water.*` 以下の新しいロケールキーを2つ追加。18言語すべてに同期済みです。
    - **新しいイベント** — 他のプラグインからフックできるよう、`ItemFillWithAcidEvent` と `PlayerDrinkPurifiedWaterEvent` を追加しました。
    - コード整備: パターンマッチングの `instanceof` 採用、`Math.clamp` の利用、`onPlayerMove`/`getWorld`/`findEntities`/`makeNetherRoof` の複雑度削減、テストの最新化など。

    [リリース v1.22.0](https://github.com/BentoBoxWorld/AcidIsland/releases/tag/1.22.0)
