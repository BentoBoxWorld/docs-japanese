# AcidIsland パーミッション

AcidIslandパーミッションは`acidisland.`で始まります。すべてのパーミッションは[パーミッションリファレンス](../../BentoBox/Permissions.md)に`acidisland`の代わりにリストされています。より大きなチーム、アイランド、より多くのホームなどのVIP特典については、[パーミッション&VIP特典](../../BentoBox/Permissions-Guide.md)を参照してください。

## プレイヤーコマンド：デフォルトで誰が持っているか

これらのデフォルトはAcidIslandの`addon.yml`から来ています。**全員**とは、除外しない限りすべてのプレイヤーが権限を持つことを意味します。**オペレーター**とは、パーミッションプラグインでプレイヤーに与える必要があることを意味します。コンソールで`/bentobox perms`を実行して、サーバーのデフォルトを確認してください。

| パーミッション | コマンド | デフォルト |
|---|---|---|
| `acidisland.island` | プレイヤーコマンド自体 | 全員 |
| `acidisland.island.create` | `create` | 全員 |
| `acidisland.island.home` | `go` | 全員 |
| `acidisland.island.homes` | `homes` | 全員 |
