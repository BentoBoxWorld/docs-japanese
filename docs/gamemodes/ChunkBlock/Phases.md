# マジックブロックとフェーズ

ChunkBlockのマジックブロックはAOneBlockエンジンで、意図的に変更されていません。フェーズファイル——重み付きブロックとモブプール、`fixedBlocks`、ホログラム、チェスト、希少性、カスタムブロック、バージョンゲート、開始・終了コマンド、要件、フェーズインデックス——はAOneBlockで行うのとまったく同じように動作し、ファイル形式は同一です。

つまり：

- **コミュニティフェーズパックが逐字的に動作。** AOneBlockの場合書かれたフェーズファイルはChunkBlockの`phases`フォルダにドロップして実行。
- **あなた独自のAOneBlockフェーズをコピー可能**編集なし。
- **上流からの修正と機能が到着**、エンジンはフォークされるのではなく進歩に保ち。

!!! abstract "完全フィールド参照：[AOneBlockフェーズのカスタマイズ](../AOneBlock/Phases.md)"
    このガイドは完全な説明——すべての数値の意味、重み付きラッフルがどのように実例と動く、チェスト、カスタムブロック、バージョンゲート、スクラッチからフェーズ構築。すべてが変わらず適用します。

    唯一の**コマンド名**は異なる：`/oba`を`/chadmin`と読む、`/ob`を`/ch`全体。

このページはChunkBlock固有をカバー。

## ファイルが住んでいる場所

```
plugins/BentoBox/addons/ChunkBlock/
├── config.yml
├── phases_index.yml          ← order, length, enabled, version gate
├── panels/
│   └── phases_panel.yml      ← the /ch phases GUI template
└── phases/
    ├── 0_plains.yml          ← blocks, mobs, holograms, commands
    ├── 0_plains_chests.yml   ← the loot for that phase
    ├── 700_underground.yml
    └── …
```

`phases/`内のファイルは**決して上書きされない**アップグレード中、だからあなたの編集は生き残る。新しいフェーズは後のarで出荷、自動的にインデックスに復元、統合。

## フェーズインデックス

`phases_index.yml`はどのフェーズがロード、順序でか、各フェーズの長さ、各フェーズがどの Minecraft バージョンを必要とするかの信頼できる情報源。これは**前に**読まれるあらゆるフェーズファイルは解析、だから新しい Minecraft バージョンが必要なフェーズはそのYAMLなしでスキップ——またはその中のいかなるアイテム。

各エントリはこれらフィールドを取る：

| Field | Meaning |
|---|---|
| `file` | `phases`フォルダ内のフェーズファイルのベース名、`.yml`なし。チェストファイルは`<file>_chests.yml`。 |
| `section` | フェーズファイル内のトップレベルキー（歴史的には開始ブロック）。 |
| `name` | 表示名、ログと`/chadmin phases`パネルで使用。 |
| `length` | フェーズのブロック数。 |
| `enabled` | 任意、デフォルト`true`。`false`でフェーズを残す。 |
| `requiredMinecraftVersion` | 任意。フェーズはスキップこのバージョンより古いサーバーで——ブロックをすべて取らず。 |

スタートブロックは**計算**：上のいかなるフェーズの長さの実行の合計、開始0。フェーズは自由に再注文、スキップされたフェーズは進行から崩れ出す。

トップレベル`adminLengths: true`は自動的に書き込まれた最初の時間あなたが長さをパネルで編集。その後、整合処理は決して長さを再計算、だからあなたの値は後のファイル追加、リネーム、アップグレード生き残る。

### 整合処理

インデックスは整合されたディスク上の実際のファイルに対して、すべてのロード上、あらゆる保存から管理パネル、だからどのような`/chadmin phases`ショーはあなたのサーバーが実際に実行する。スタートアップログで`Phase index:`で始まる行を見てください——彼らは正確に何が変わったかを言う。

- エントリはそのファイルが**名前を変更アドオンバージョン間**は再ポイントされたあなたのファイルにフェーズ名の。
- エントリはそのファイル**見つからず jar で出荷**は自動的に復元。これはどのように新しいフェーズはアップグレードされたサーバーに現れ、与えて`phases/`は決して上書きない。
- **カスタムフェーズファイル**フォルダにドロップされたは自動的に追加。数値キーはそのレガシースタートブロックにスロット。他は何でも末尾に追加パネルで配置するのはあなた。
- エントリのその中のファイルは永遠に消えると警告で削除。

!!! warning "フェーズ削除"
    フェーズを永遠に削除するには、そのファイルを削除するか`/chadmin phases`でオフにトグル。削除だけそのインデックスエントリはどうにか動作しない——整合処理はフォルダ内の見つけるあらゆるフェーズファイルを再追加。

    誤ったインデックスフォールバック直接ファイル読み込みに、だから悪い編集はアドオンは固着。

!!! tip "ファイル名の数字は任意"
    カスタム`desert.yml`と`desert:`セクションは非常に同じ。チェストファイルは引き続き対応ファイル名で（`<file>_chests.yml`）。出荷ファイルの数字は歴史的：インデックスが電荷すると、パネルのスタートと長さ値が真。

## フェーズ順序エディター

`/chadmin phases`（権限`chunkblock.admin.phases`、OPデフォルト）ショーはあらゆるフェーズが順序で計算スタートブロック、長さ、状態で。これは編集`phases_index.yml`、ドロップとトグルはインデックスを保存・リロードフェーズ即座に。

- **左クリック**フェーズピックアップ——残りは左収縮。クリックどこ、それが行くべきドロップを押下、または使用ドロップ末尾スロット。どこでもクリック他、またはパネルを閉じ、それを戻す編集なし。
- **右クリック**トグルフェーズオン・オフ。
- **Shift-左クリック**セットフェーズ長。パネルはクローズ、チャットプロンプトはショーすること現在の長さ。全体数を入力適用、またはキャンセルを保つ。入力無効は再プロンプト、プロンプトはタイムアウト60秒後。最初の長さ編集は書き込み`adminLengths: true`を、インデックス。

無効フェーズはグレイグラス表示、バージョンロック者をバリア——どちらもまだ再注文できます。フェーズ設定アイコンなしはそれの最初のブロックを使用。

## プレイヤーとフェーズ

- `/ch count` ——現在のブロックカウントとフェーズ、チャットで。
- `/ch phases` ——フェーズGUI。`chunkblock.phases`が必須、**デフォルトオフ**。
- `/ch setcount <number>` ——既に到達したフェーズをリプレイ。`chunkblock.island.setcount`が必須（OPデフォルト）、`set-count-cooldown`設定値に従う、5分デフォルト。
- `/ch check` ——マジックブロックがなくなった場合リスポーン、またはパーティクルを表示それを見つけるのを助ける。
- `/ch bossbar` / `/ch actionbar` ——プログレスディスプレイをトグル、もし`bossbar` / `actionbar`は設定で有効。

ホログラムはマジックブロック上のはデフォルトで（`world.holograms: true`）、native Minecraft テキストエンティティを使用、消える後`hologram-duration`秒。

## 管理フェーズツール

- `/chadmin setcount <player> <number> [lifetime]` ——プレイヤーのブロックカウントを設定、またはそれらの生涯カウント。
- `/chadmin setchest <phase> <rarity>` ——簡単な方法ビルドルート。ゲーム内でチェストを埋め、何が必要か見て、コマンドを実行フェーズ名と、希少性`COMMON`、`UNCOMMON`、`RARE`またはEPIC。チェストは書き込まれてそのフェーズのチェストファイルへ、使用の準備。削除チェストは依然として編集を意味ファイルと再ロード。
- `/chadmin sanity [<phase>]` ——レポートフェーズの確率をコンソールに、だからあなたは見える何を体重は本当に合計。
- `/chadmin phases` ——順序エディターは上で説明。

## ChunkBlock固有のノート

!!! warning "マジックブロックは中央チャンク、常に"
    中央チャンクは決してロックできない、だからマジックブロックは常にリーチ可能。これは保証されたデータモデルより、チェック：クレームリスト常に中央チャンク開始及び再ロックは決して削除することはできません。

!!! note "モブスポーン・ブロック・クリアリングはボーダーを尊重"
    `mobs-clear-blocks: true`は、プレイヤーが箱入りするスポーン・モブが部屋を壊す破壊を許可——チート予防はAOneBlockから運ば、だからプレイヤーは箱入りマジックブロックとすべてを窒息させることはできません。ロック済みチャンクは決して修正、だからこれは常にあなた独自の領土に影響。

!!! tip "フェーズと領土は互いに対して引っ張る"
    ブロックはマジックブロック生産は上げアイランドレベル、アイランドレベルはチャンクを買う——だから太っ腹なフェーズも速く拡張フェーズ。拡張はあなたのサーバーで速い感じの場合、上昇`levels-per-chunk`は通常より良いレバーより再衡量フェーズ体重。

!!! note "ネザーとエンドフェーズはまだ実行"
    ネザーとエンドフェーズは進行の一部関係のない場合でもネザーとエンド*ワールド*は生成（両者はデフォルトでオフ）。彼らは、ネザーとエンドブロックとモブを配信を通じてOverworld マジックブロック。
