# ゲームモードの選び方

どのゲームモードをサーバーで運用すればよいか迷っていますか？このページでは、BentoBoxの公式ゲームモードをすべて比較し、選択の参考にしていただけます。

**複数のゲームモードを同時に**運用することも可能です。多くのサーバーでは、プレイヤーが好みの体験を選べるよう、2〜3つのゲームモードを提供しています。

---

## クイック比較

| ゲームモード | 舞台 | 難易度 | メインの課題 | マルチプレイ重視度 |
|---|---|---|---|---|
| **BSkyBlock** | 空（浮遊島） | 普通 | 虚空に浮かぶ小さな島から拡張する | 普通 |
| **AOneBlock** | 空（虚空） | 普通 | 尽きることのない魔法のブロック1個を掘り続ける | 低〜普通 |
| **AcidIsland** | 海（酸の海） | 普通〜難しい | 危険な酸の水がある中でのスカイブロック | 普通 |
| **CaveBlock** | 地下 | 普通 | 石だけの世界を掘り開いて空間を作る | 普通 |
| **SkyGrid** | 空（散在するブロック） | 難しい | グリッド状に配置された1個ずつのブロックから資源を集める | 低 |
| **Boxed** | 通常ワールド | 易しい〜普通 | 実績を達成して閉じた空間を広げる | 普通 |
| **Poseidon** | 海洋 | 普通 | 完全に水中で生き残る | 普通 |
| **StrangerRealms** | オーバーワールド＋逆さまの次元 | 普通〜難しい | 危険な鏡像次元を管理しながら土地を確保する | 普通〜高 |

## どれを選べばよいか？

### 最も人気があり知名度の高い体験を望む場合
**BSkyBlock** — クラシックスカイブロックはほとんどのプレイヤーが既に知っています。コミュニティが最大で、リソースも豊富、どのサーバーにも安心して導入できます。

### 新鮮だが親しみやすい体験を望む場合
**AOneBlock** — 「魔法のブロック1個」というコンセプトはわかりやすく、すぐに楽しめます。フェーズ進行システムにより、プレイヤーは長期間モチベーションを維持できます。

### より難しいスカイブロックを望む場合
**AcidIsland** — BSkyBlockと似た感覚ですが、海に落ちると本当に危険です。通常のスカイブロックが簡単すぎると感じたプレイヤーに最適です。

### 地下／採掘テーマを望む場合
**CaveBlock** — 空に向かって建築するのではなく、プレイヤーは固い地面を掘り進めます。BentoBoxの仕組みを共有しながらも、まったく異なる体験が得られます。

### 上級者／ハードコアプレイヤー向けにしたい場合
**SkyGrid** — 散在するブロックの世界は容赦ありません。資源は広く分散し、移動も危険で、生き残るには本物のスキルが必要です。新規プレイヤーがいるサーバーで唯一の選択肢にするのはお勧めしません。

### バニラの進行と連動した体験を望む場合
**Boxed** — 実績による拡張システムがゲームをバニラのMinecraftの目標と直接結びつけます。構造化された進行が好きなプレイヤーに最適です。

### 独自のビジュアルテーマを望む場合
**Poseidon** — 完全な水中世界は見た目が素晴らしく、プレイスタイルもまったく異なります。視覚的に個性的なものを求めるプレイヤーへのサブオプションとして最適です。

### ストーリー性のある複雑な仕組みの体験を望む場合
**StrangerRealms** — 逆さまの次元が戦略の層を加えます。Minecraftに慣れており、より深い体験を求めるプレイヤーに向いています。

## ゲームモード別機能サポート

ほとんどのBentoBoxアドオンはすべてのゲームモードで動作します。一部は特定の互換性要件があります。

| Levelアドオン | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Challenges | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Warps | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| InvSwitcher | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

## 複数のゲームモードの運用

各ゲームモードは完全に独立して動作します — ワールド、島データベース、設定ファイルがそれぞれ別々です。プレイヤーは各ゲームモードで同時に島を持つことができます。

複数のゲームモードを運用する場合、**InvSwitcher**アドオンの導入を強くお勧めします。これがないと、プレイヤーはすべてのゲームモードのワールドでインベントリ、経験値、体力を共有することになり、混乱や不正利用の原因になる可能性があります。
