# AOneBlock プレースホルダー

利用可能なプレースホルダーは以下の通りです:

|プレースホルダー|説明|
|--- |--- |
|%aoneblock_my_island_blocks_for_phase%|自分の島の現在のフェーズのブロック数|
|%aoneblock_my_island_blocks_to_next_phase%|次のフェーズまでのブロック数（次のフェーズがない場合は「infinite」）|
|%aoneblock_my_island_count%|自分の島のブロック数|
|%aoneblock_my_island_done_scale%|自分の島のフェーズ完了スケール|
|%aoneblock_my_island_lifetime_count%|自分の島の累計ブロック数|
|%aoneblock_my_island_next_phase%|自分の島の次のフェーズ|
|%aoneblock_my_island_percent_done%|フェーズの完了率|
|%aoneblock_my_island_phase%|自分の島のフェーズ|
|%aoneblock_visited_island_blocks_to_next_phase%|現在立っている島の次のフェーズまでのブロック数|
|%aoneblock_visited_island_count%|現在立っている島のブロック数|
|%aoneblock_visited_island_done_scale%|現在立っている島のフェーズ完了スケール|
|%aoneblock_visited_island_lifetime_count%|現在立っている島の累計ブロック数|
|%aoneblock_visited_island_next_phase%|現在立っている島の次のフェーズ|
|%aoneblock_visited_island_percent_done%|現在立っている島のフェーズの完了率|
|%aoneblock_visited_island_phase%|現在立っている島のフェーズ|
