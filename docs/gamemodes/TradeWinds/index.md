# 🌬️ TradeWinds

作成・管理者：[tastybento](https://github.com/tastybento)。

**TradeWinds**はBentoBoxの海上交易ゲームモードです。手続き的に生成された無限の海洋には、NPC交易島が散在しています。プレイヤーは何もない状態でゲームを開始します。ボートと一握りの石炭だけが手元にあり、ボートはカーゴホールド（貨物室）そのものです。農業島では安く買い、工業港では高く売り、金を稼ぎましょう。あるいは密輸、賞金稼ぎ、海賊活動という近道を選び、その結果に対処しましょう。

*Elite*や*TradeWars 2002*に一週末を棒に振った経験があれば、このゲームはそれを再構築したものです。そうでなければ、あなたのプレイヤーたちは今、それがなぜそうなるのかを知ることになります。

## 🧭 プレイヤーが夢中になる理由

- 🏝️ **無限のシード付きオーシャンワールド。**すべての島の位置、タイプ、技術レベル、セキュリティバンド、バイオーム、名前は1つのシードから派生しています。プレイヤーは探索して新しい場所を見つけることができます。デフォルトシードを使うか、新しいものを選んで独自の世界を作成してください。シードを共有すれば、別のサーバーは全く同じ交易海を手に入れます。
- ⛵ **ボートはカーゴホールドそのもの。**カーゴボートに積まれ、船は**20階級のハル**（竹のいかだ → ペールオークチェストボート）でアップグレード可能で、船を失うことは*何か意味があります*。1人のプレイヤーに1隻のボート—全てのハル選択が重要です。
- 📈 **読む価値のある市場。**8つの島のパーソナリティ（農場、鉱山、漁港、森、工業、高級、冷凍港...）があり、それぞれが異なる方法で売り買いし、すべての取引が現地価格をシフトさせます。良いルートは*投稿*ではなく*発見*されます。
- ⚡ **2つの移動方法、どちらも公平。**ボート漕ぎは無料でゆっくり、無法水を通りますが、潜在的な富があります。ワープは即座ですが、ホールドから燃料を消費します—デフォルト5%の悪質なジャンプは、あなたを**インタースティス**（敵対的なネザー海）にあなたを投げ出します。どちらの方法ももう片方に厳密に勝つことはありません。その緊張感がゲームなのです。
- 🗺️ **チャート、星、ランク。**チャートを上げると、すべてをチャートした場所のホログラムコンパスが浮かび上がります。プレイヤーがチャートした全ての島は**シーファーラダー**に登ります—デッキハンドからミスティックマリナーまで19階級で、組み込みトップテンリーダーボードとスコアボード用のプレースホルダーが付いています。
- 🏠 **自分自身で獲得したアイランド。**まず**タイドキャプテン**（36の島をチャート）に達して、真面目な現金を持ち、見つけた野生の小島は自分のものになることができます。保護、チーム、ホームポイント、メンバー限定ワープノード、そして星による夜空ナビゲーションホーム。先着順です。
- 🚨 **あなたを危険に追い込む犯罪が報われます。**密輸品は法律が薄い場所でしか売れません。犯罪歴はあなたを安全な市場から閉め出し、他のプレイヤーが合法的に回収できる懸賞金をあなたの頭に付けます。最も裕福な密輸業者は構造的に地図の危険な端に向かって押し出されます—海賊がすでにいる場所です。
- 🐡 **押し返す海。**昼間の守衛ピケット、夜間の溺死した襲撃者、ファントム、深い恐怖、ボート生まれの海賊乗組員、海の魔女—スケーリングは水がどれだけ無法かによります。安全なレーンでさえ時々フグの浅瀬に出くわします。

**難易度は地理です。**スポーン近くの水は哨戒され、落ち着きがあります—新しく若いプレイヤーは平和に取引できます。危険、密輸、PvP懸賞スペースはすべて*他の場所*であり、そこに行くことは常に選択です。これはTradeWindsを、ファミリーサーバーと覇権的なものの両方で機能する数少ない経済ゲームの1つにします。同じ設定からです。

## ⚓ セッションの気分

スポーン港から3スロットのカーゴと予感を持ってキャストオフします。東の2つの島の漁村は小麦の2倍を支払っていました。最初の脚を漕ぎます—燃料は金です—そして道中新しい小島をチャートします。タイドキャプテンへの1つ高いステップです。ボーダーカーテンでは、ワープダイアログが14ユニットの石炭の交差を提供します。太陽が沈んでいて、溺死した襲撃者がここの夜を所有しているので、それを取ります。市場は支払い、ホールドは安い鱈で補充され、チャートホームの上で、あなたは今までアクセスするのをためらっていた赤いバンドの島が*愚かな*価格で魚を買っていることに気づきます。それは1つの静かな実行だけかかります...

そのループ—計画、帆、取引、前回より少しリスク—がゲーム全体であり、それは手放しません。

## 🔧 セットアップ

!!! warning "Vaultとエコノミープラグインは必須です"
    すべての取引はVaultを通じて実行されます。最初のローンチの前に、Vaultプラス任意のVault互換エコノミー（EssentialsX Economy、CMIなど）をインストールしてください。TradeWindsは`config.yml`の`economy.currency-symbol`を使用して、独自にお金をフォーマットします—セント分なし、全コイン。BentoBoxのオプションを希望する場合は、InvSwitcherとお金をオンにして使用します。それはBentoBoxのエコノミーです。

1. **TradeWindsアドオンをダウンロード**して、`/plugins/BentoBox/addons/`に配置します。
2. **サーバーを起動**—`tradewinds_world`（海洋）と`tradewinds_world_nether`（インタースティス）が自動生成されます。意図的に**エンドワールドはありません**。
3. **Opでログインして見回す**：`/twadmin islands`は最も近い交易島を一覧表示し、`/twadmin tpisland <#>`はそこにあなたをテレポートします。
4. **ワールドシードを選択***(オプション、プレイヤーが参加する前)*：`config.yml`で`ocean.seed`を設定します。すべての島の位置、タイプ、名前はこの1つの数字から流れ出します—後で変更して、それは別の海です。
5. **エコノミーを好みにチューン***(オプション)*：価格、ボート代、ワープ燃料率、犯罪、エンカウンターテーブルはすべて`config.yml`にあり、意図されたデフォルトはすでに実装されています。

!!! tip "推奨される仲間"
    - **InvSwitcher**—インベントリ、ヘルス、空腹感をあなたの他のゲームモードから分離しておきます。エコノミーを含みます。
    - **Bank**—要求されたプレイヤーアイランドは、インストールされている場合、Bankアドオンに自動的に接続されます。チームメンバー間での金銭の統合を可能にします。

## 🎮 コマンド

プレイヤーコマンドは`/tw`（または`/tradewinds`）です。管理者コマンドは`/twadmin`です。ベアの`/tw`は帆を張ります—それは海への入り口であり、ゲームの1つの注意深いテレポートです。あなたが去った水に戻り、あなたが自分のアイランドに立っている場合、あなたのホームポイントにあなたをステップ、そして他の場所では、それは**方位と距離**をホームに教えてくれますが、乗車を与えません。TradeWindsの何もカーゴをテレポートしません。

完全なコマンドリファレンスは[ここ](Commands.md)です。

## ⚙️ 設定

すべてのゲームプレイ形の設定は`config.yml`に住んでいます。段階的に導入され、各デフォルトがどのような形であるかを説明するコメントがあります。すべての管理者がローンチ前に見るべき1つの設定：

```yaml
ocean:
  # オーシャンシード。すべての島の位置、タイプ、セキュリティバンド、バイオーム、名前と
  # ルートコストはこの1つの数字から決定論的に派生しています。共有すればもう1つの
  # サーバーは同じ取引海を得ます。0は：ワールドシードを使う。
  seed: 20260729
```

他のセクション価値のあるスキム：`boats`（ハルラダーと価格）、`travel.warp`（燃料代とミスジャンプ確率）、`ranks`（シーファーラダー）、`claims`（プレイヤーアイランドの価格）、`crime`（法律層全体にマスタースイッチがある）、および`encounters`。
