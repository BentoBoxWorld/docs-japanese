# 🧭 船乗りのハンドブック

プレイヤーが最初の数週間で発見するすべて、1つの場所に—そしてゲームの全体像がどのように組み合わさっているかについての、すべての管理者が知る必要があること。TradeWindsはシンプルなルールで複雑な結果があるゲームです。ルールは下記、結果はあなたのプレイヤーに任せます。

## ⛵ 最初の1時間

あなたは**スポーン港**にスターターOakボート—3スロットのカーゴ、タンクに石炭はすでに入っています—と繰り返す価値のある忠告を得る。*ボートはあなたのホールドとあなたの生活手段です。それを近くに保ってください。*

1. **ボートを右クリック**してホールドを開きます。カーゴと燃料はここに住んでいます—ポケットには決して住みません。どのマーケットでも取引することは、ホールドから直接商品を出し入れします。
2. **プラザのトレーダーと話す**。すべての島は買値と売値を投稿します。スプレッドがゲームです。
3. **帆を張る**そして島から離れてボートを漕ぎます。十分に離れたら、ワープを選ぶか、ボート漕ぎを続けるかを選択できます。新しい島の水を渡ることで、それを恒久的にあなたのマップで**チャート**し、シーファーラダーで少しステップアップします。
4. **高く売る。**おめでとうございます：あなたはトレーダーです。このハンドブックの他のすべては、より速く、より大きく、そして端に近い、これをすることについてです。

## 🚢 1隻のボート、20個のハル

あなたのボートはあなたの唯一のホールドであり、あなたはちょうど1つです。そのハルはあなたのカーゴスロットを決定します：

| | | |
|---|---|---|
| 竹のいかだ: 2 | Oakボート: 3 | Spruceボート: 4 |
| 竹のチェストいかだ: 5 | Birchボート: 6 | Oakチェストボート: 7 |
| ジャングルボート: 8 | Spruceチェストボート: 9 | Acaciaボート: 10 |
| Birchチェストボート: 11 | Dark Oakボート: 12 | ジャングルチェストボート: 13 |
| マングローブボート: 14 | Acaciaチェストボート: 15 | Cherryボート: 16 |
| Dark Oakチェストボート: 17 | Pale Oakボート: 18 | マングローブチェストボート: 19 |
| Cherryチェストボート: 20 | Pale Oakチェストボート: 21 | |

- **造船所は販売**島の技術レベルが構築できるすべてのハル、あなたがすでにセイルしているサイズを除いて。あなたの船を埠頭に連れてきて、より大きく購入する：それは**トレードイン**：同じホールド、同じカーゴ、より多くのスロット、そしてあなたの下のハル（またはあなたのバックパックに、またはドッグに係留）視覚的に新しいタイプになります。あなたの船を購入すると、海の向こう側にあり、それは**全体的な購入**：新しいボート、古いボート**未所有**どこにあろうと、カーゴを積んで、先着順。ダイアログはあなたのお金が動く前にあなたに警告します。
- **ボートはキャプチャされることができます。**あなたのものではないハルをボードまたはピックアップします。ボート（あなたの船を放棄）を取得、それだけのカーゴを取得（あなた自身の船が十分に近い場合のみ—カーゴは決してテレポートしない）、またはそれを残します。合法的な島の保護内に駐車された所有者のボートは手に入りません。同じボートが無政府主義的水に駐車されているのは異なります。
- **死は終わりではありません。**あなたのボートはあなたがそれを去った場所で浮かんでいて、まだあなたのもので、チャートはそれをマークします。もしあなたが*運ぶ*の場合、難破船のサイトがマークされます。ボートレスを再スポーンし、港はリカバリー行のイカダを貸します。
- **溶岩は唯一の真の破壊者です。**他のすべてはちょうどハルを保有している人を変えます。
- **エンドゲームはエクスパンダーです。**トップテック港はホールドをラダーを超えて成長させるカーゴエクスパンダーを販売します—インストールされた単位あたり2倍になる価格で。財布は唯一のキャップです。

## 🏝️ 海洋を読む

すべての取引島は**タイプ**（何が成長し、掘り、建築—したがって何が安く売り、何を特に買っているか）、**技術レベル**（造船所が何を構築でき、装備品が在庫に置いているか）、**セキュリティバンド**を持っています：

| バンド | 水 | ルール |
|------|-----------|-----------|
| **安全** | スポーン周辺 | 哨戒、敵対的スポーンなし、関税が鋭い |
| **警察** | 取引レーン | 法律がある、密輸はリスク、守衛が昼間にピケット |
| **フロンティア** | 長いルート | 薄い法律、より良い利幅、悪い会社 |
| **無政府主義** | 端 | 法則なし—密輸金、海賊乗組員、その他のプレイヤー |

価格は地理に従います。安全から遠いほど、良い取引が多い—法律の両側。購入と売却も**ローカル価格を流す**ので、ルートは使い尽くされ、放棄されたポートはひっそりと金鉱になることができます。

## 🗺️ 周辺を取得

**ボート漕ぎ**は無料ですべてをチャートします。**ワープ**は島の境界で起こります—目に見えるカーテンにセイルしてください。ダイアログは、すべてのチャート目的地を燃料価格で提供しています（約100ブロックあたり1燃料ユニット）。燃料は燃えるすべてのもので、感覚的に評価されます。ログ1、ケルプブロック4、石炭と炭8、燃焼棒12、石炭ブロック80、溶岩バケット100—すべてホールドの燃料行で運ばれ、カーゴスペースを食う。そのトレードオフはプレイヤーが作る必要があります。

- `/tw chart`は**ホログラムコンパス**を上げます。チャート島、ドック軸受、あなたのボート、そして—あなたが所有している場合—ホーム。
- `/tw starchart`はあなたのチャート世界を**マップアイテム**に引き出します。それを出し入れできます。
- `/tw rank`はあなたのシーファーランクと、チャートされた島のトップテン船乗りを表示します。

!!! danger "ミスジャンプ"
    すべてのワープはデフォルトで5%のわずかな確率を持ち、**インタースティス**にあなたを落とします—焦げた空の下の暗いネザー海。元の目的地へのワープの再発は**常に無料**...ですが、インタースティスはゲーム内の唯一の場所で、ネザー疣がソウルサンドの浅瀬で成長し、燃焼ピケットがそのカラスの巣で男を務め、枯れた塔が迂回する価値のある戦利品を保つ場所です。事故として始まるものは目的地になります。TradeWindsではネザーポータルはありません—海は独自の方法を持っています。そして岸の伝説の本は、なぜポータルが照明を拒否するのかを説明しています。

## 🎖️ ランクとラダー

島のチャートは、ゲームのオドメーターであり、19のシーファーランクが距離をマークします—スタートで**デッキハンド**；10で**ベイエクスプローラー**；20で**チャートメーカー**；36で**タイドキャプテン**、クレーミングは解放；56で**塩辛いコモドア**；100で**ミスティックマリナー**すべて。`/tw rank`トップテンと`%tradewinds_rank%` / `%tradewinds_top_name_1%`プレースホルダーはサーバーにリーディボード文化がすぐにできます。管理者は`/twadmin rank`で昇進、降格、またはリセットできます。

## 🏠 あなた自身のアイランド

取引島の間に散在しているのは**野生の小島**—小、未所有、クレーム可能：

- **ゲート：**小島に立ち、**タイドキャプテン**ランクを保持し、価格を払う（デフォルト**$150,000**—ハルラダーの上にあるため意図的に）。先着順です。
- **あなたが得ること：**標準フラグGUIを持つBentoBox保護、チーム、ベースの周りに`/tw sethome`と`/tw home`、そしてあなたが島に立っているとき`/tw go`はあなたを家に見送ります。Bankアドオンがインストールされている場合、あなたのアイランドは自動的にアカウントを得ます。
- **海を越えて家に帰る：**あなたのクレームは、すべてのボーダーダイアログで**メンバーのみのワープノード**になります。セイルを好みますか？`/tw go`が海で**ホームコース**を設定する。昼間は粗い羅針盤軸受、そして夜—星が出る時—正確な距離と進捗。子供たちに夜空で航行するよう教えてください。それは機能します。
- **チームメンバーはランクを必要としません。**クレーマーのみがゲートを通過します。タイドキャプテンは乗組員全員をホームに連れて行くことができます。
- **クレームを取り消すことは意図的に傷つきます。**所有者のみ、チームを最初に空にし、払い戻しはありません—すべてが正確に左の状態で、次のキャプテンのための野生に戻ります。

## 🚨 法と無法

犯罪層（config内のマスタースイッチ1つ）は、地図の地理を物語に変えるものです：

- **レピュテーション**は正直から**逃亡者**まで実行されます。関税は合法的なポートで密輸をスキャンします。十分に行われた場合、安全な市場はあなたに彼らのドアを閉じます。
- **密輸**（砂糖、設定可能）は、貧困が合法である場所では無価値で、誰も質問しないところでは無価値です。スキャンリスク—価格ではなく—は密輸のコストです。
- **罰金**（`/tw fine`）は、まだあなたと話す価値のあるポートで、あなたの記録を磨きます。
- **懸賞金**（wanted players on）は誰でも、合法的に、逃亡者が取引することを強制される水で回収できます。警察の暴徒は合法的な島で平和を強制します—そして決して戦利品をドロップしないので、物を農業する何もありません。

デザインは意図的です。犯罪は報われ、それはあなたを*危険に*対して報われます。最も裕福な密輸業者は、海賊乗組員と賞金稼ぎがすでにいるところでまさに取引をすることになります。

開いた水はスケーリングされたエンカウンターをロール—ドックからの距離とあなたがいるバンド：

| エンカウンター | 水 | 時 |
|-----------|--------|------|
| 🐡 フグの浅瀬 | 安全—警察 | いつでも—刺し、待ち伏せではなく、決してファーム価値がない |
| 🔱 守衛ピケット | 警察+ | 昼 |
| 🧟 溺死した襲撃者 | 警察+ | 夜—いくつかは三叉槍を運びます |
| 👻 ファントムフライト | フロンティア+ | 夜、マストの上 |
| 🦑 深い恐怖 | フロンティア+ | キールの下 |
| 🏴‍☠️ 海賊乗組員 | 無政府主義 | ボートで生まれる、彼らはデッキから戦う |
| 🧪 海の魔女 | 無政府主義 | ボートで生まれ、距離を保つ |

エンカウンターは**戦利品**をキルします—ホールドに直接スタンプされたカスタムズセルベージ。海が支払う唯一のお金。すべての名簿、パックサイズ、チャンスは、configの`encounters`にあります。

## 🛠️ ハンドルのかじを取る管理者向け

- **シードは世界です。** configymlをデータベースでバックアップします。`ocean.seed` *is* your world。プレイヤーが理論的なルートでDiscordを推し進めたい場合は発行し、探検家を見たい場合は秘密にします。
- **ボートの記録**（`boats.logbook`、デフォルトではオン）はボートのライフサイクルイベントごとに1つのコンソール行を書きます—配置、破棄、キャプチャ、購入、その船乗りで失われました—座標で。プレイヤーが*「私のボートはどこに行きましたか？」*と尋ねると、答えはログに含まれています。
- **`/twadmin boat <player>`** は、データベースから直接ボート記録を読んでください。カーゴ、燃料、最後に見られた位置、ハルが実際にそこに浮かんでいるか、誰かのバックパックに入っているか、アンロードされたチャンクに座っている。`restore`は、本物のハルが読み込まれている間は、本物のハルが読み込まれている間は、失われたボート、カーゴを再構成します。複製に使用することはできません。
- **`/twadmin islands` / `tpisland`** ツアー用、**`customs`** 任意のスポットの法執行機関の見解を見る、**`priceaudit`** すべての商品が価格を持つことを確認する、**`warpfail`** インタースティスをオンデマンドでテストする。
- **ドロップされたボートのクリーンアップ**：放棄されたボート*アイテム*（およびそれらのカーゴレコード）は設定可能なTTLの後に期限切れになります。ボート*エンティティ*は決して期限切れにはなりません—放棄された船は誰かがそれを取得するまで、世界の一部のまま。
