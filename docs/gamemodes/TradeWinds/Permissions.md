# TradeWinds パーミッション

デフォルトは、バニラインストールが意図されたゲームを権限プラグインなしでプレイするように選択されています。セーラーが必要とするすべては`true`です。セイリングをスキップするショートカットは`op`で、実際のゲート（要求ランク、要求価格）は権限ではなく`config.yml`に住んでいます。

## プレイヤーパーミッション

| パーミッション | 説明 | デフォルト |
|------------|-------------|---------|
| `tradewinds.island` | TradeWindsプレイヤーコマンドの使用を許可 | `true` |
| `tradewinds.island.spawn` | `/tw go`を許可—海への入り口、ルール内で帰宅する道。外から戻ると、プレイヤーは去った水に返されます。彼らのアイランドにあるとき、彼らのホームポイントにステップしてください。海のどこかで、それはホームへの方向と距離を教えてくれます。決して海を越えた乗客。 | `true` |
| `tradewinds.island.chart` | チャート表示を許可（ホログラム浮遊、リスト岸） | `true` |
| `tradewinds.island.starchart` | スターチャートマップを受け取ることを許可 | `true` |
| `tradewinds.island.rank` | シーファーランクの表示と、チャート島トップテンの表示を許可 | `true` |
| `tradewinds.island.claim` | 野生の小島をプレイヤーアイランドとしてクレームすることを許可。実際のゲートは設定にある—シーファーランク（`claims.minimum-rank`）と価格（`claims.price`）—なのでこれはデフォルトではオンのままです。クレーミング全体を無効にするにはオフにします。 | `true` |
| `tradewinds.island.sethome` | あなたのアイランドのホームポイント設定を許可—保護範囲内に立っている場合のみ（所有者またはチームメンバー）。 | `true` |
| `tradewinds.island.home` | ホームポイントへのテレポートを許可—あなたのアイランドに立っているときのみ。ベースの周りの便利さであり、海を越えた帰宅の方法ではありません。 | `true` |
| `tradewinds.island.unclaim` | 所有者がクレーム済みの小島を野生に戻すことを許可。チームを最初に空にする必要があります。払い戻しなし。すべてのブロックは左の通りのままです。 | `true` |
| `tradewinds.island.fine` | ポートで犯罪歴を解決することを許可。デフォルトではオン—払い方法のない評判を持つプレイヤーは、待つ以外に帰る方法がありません。 | `true` |
| `tradewinds.island.restart` | 取引キャリアの再開始を許可（設定上限） | `true` |
| `tradewinds.island.prices` | トレーダーの記録を許可—あなたが呼んだポート、どのくらい前だったか。価格は市場にアクセスするか、港のレポートを購入することでのみ入ります。なので、これはプレイヤーの知識を読み戻します。 | `true` |
| `tradewinds.island.info` | アイランド情報コマンド使用を許可 | `true` |
| `tradewinds.island.settings` | アイランド設定表示を許可（編集はランク制限） | `true` |
| `tradewinds.island.language` | 言語コマンド使用を許可 | `true` |
| `tradewinds.island.warp` | ショートカット：アイランド水のどこからでもワープダイアログを開く。デフォルトではオフ—意図されたパスは、ボーダーカーテンに帆を張ること。セイリングをバイパスする場合は許可。 | `op` |
| `tradewinds.island.trade` | ショートカット：アイランド保護範囲内のどこからでもマーケットを開く。デフォルトではオフ—意図されたパスはドッキングとトレーダーを右クリックしています。ウォークをバイパスする場合は許可。 | `op` |

## 管理者パーミッション

| パーミッション | 説明 | デフォルト |
|------------|-------------|---------|
| `tradewinds.admin` | TradeWinds管理コマンド使用を許可 | `op` |
| `tradewinds.admin.islands` | 最も近い取引島の一覧を許可 | `op` |
| `tradewinds.admin.tpisland` | 取引島へのテレポートを許可 | `op` |
| `tradewinds.admin.boat` | プレイヤーのボート記録を検査—カーゴ、燃料、最後に見られた位置、ハルが実際に読み込まれているかどうか—そして、データベースから失われたアクティブボートを回復します。 | `op` |
| `tradewinds.admin.rank` | プレイヤーのシーファーランクを検査または設定—実のチャート数の上で調整を保存するため、昇進、降格、リセットがすべて機能し、要求ゲートとリーダーボード従う。 | `op` |
| `tradewinds.admin.customs` | あなたの位置で関税状態を表示（密輸品、スキャン確率、パトロール） | `op` |
| `tradewinds.admin.priceaudit` | 価格カバレッジ監査と`price-audit.txt`へのレポート書き込み | `op` |
| `tradewinds.admin.warpfail` | プレイヤーの次のワープをインタースティスにフェイル、インタースティスにドロップ | `op` |
| `tradewinds.admin.reflag` | すべての島にセキュリティバンドフラグを再適用することを許可 | `op` |
| `tradewinds.admin.*` | すべてのTradeWinds管理パーミッション | `op` |
