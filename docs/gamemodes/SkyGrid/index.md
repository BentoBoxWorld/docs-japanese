# SkyGrid

**SkyGrid**は、4ブロックのグリッド上に浮遊するブロックで埋め尽くされたマップです。すべての方向に4ブロックおきに実際のブロックが存在し、それ以外はすべて空気です。オリジナルSkyBlockの作成者であるSethBlingが2012年にSkyGridを公開し、Minecraftで最も人気のあるマップのひとつとなっています。

SkyGridでプレイ（そして生き残る）するための目標とテクニックがあり、このゲームをとても楽しくするためのオンラインヘルプやヒント、方法は豊富にあります！

作成・メンテナンス: [tastybento](https://github.com/tastybento)。

## インストール

0. BentoBoxをインストールし、少なくとも一度サーバーで起動してデータフォルダを作成します。
1. このjarをBentoBoxプラグインのaddonsフォルダに配置します。
2. サーバーを再起動します。
3. アドオンがワールドとデータフォルダを作成し、フォルダ内にconfig.ymlが生成されます。
4. サーバーを停止します。
5. config.ymlを好みに合わせて編集します。
6. 変更によって影響が出るデフォルトで作成されたワールドを削除します。
7. サーバーを再起動します。
